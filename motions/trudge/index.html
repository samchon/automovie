Motions/Movement and position/Gait

trudge

A named row of the gait family: an action with some parameters fixed, fitted, refused and checked as that action is.

Loading the take.

Performed alone after a half-second stand.

Write it

const { trudge } = HumanGait;
const Chain = HumanChain.extend({
  trudge,
});
Chain.subject("a")
  .trudge({ to })

A row is registered in the performance's laws too.
