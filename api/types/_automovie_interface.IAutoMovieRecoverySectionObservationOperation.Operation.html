    Observe and fit every contour on one fixed private section. An optional collection name prefixes curve identities; an optional acquisition observer receives copied original face incidence after local fitting, including rejected contours. Observer exceptions escape the fitting catch.

            Acquisition-only copied accepted trace, delivered outside the fitter failure catch. Observer exceptions escape. Acceptance does not itself imply the original fit met tolerance, and no historical accepted trace is asserted.

          • OptionalonSourceLineage?: (observation: IAutoMovieRecoverySourceLineage) => void

            Optional synchronous acquisition observer; copied records belong to the caller and callback exceptions escape fitting.

          • policy: Pick<IAutoMovieRecoveryInput, "cornerDegrees" | "toleranceMm" | "maxSpans">
