      • direction: AutoMovieVector3Tuple

        Tangent direction in the curve's declared frame, with magnitude ignored by the directional constraint.

      • kind: "tangent"

        Where the curve passes the named datum, its tangent is parallel to direction with the same sense (G1 to that direction). direction is a unit vector in the spec's frame; its length carries no speed.

      • datum: string

        Name of the previously declared datum that constrains this curve.

      • interval: [number, number]

        Inclusive interval of the curve's declared parameter on which this constraint applies.

      • kind: "extremum"

        The curve's extremum along the unit axis (spec frame) on the parameter interval lies at the named datum: sense "max" means no point of the interval reaches farther along axis than the datum, "min" the reverse. value is the datum's coordinate along axis from the frame origin, calibration mm.

        Which extremum or direction of monotonic change the curve must have.

      • value: number

        Required coordinate along the declared constraint axis, millimetres.

        Inclusive interval of the curve's declared parameter on which this constraint applies.

      • kind: "curvature-sign"

        The signed curvature of the curve projected on the plane with unit normal (spec frame) keeps sign over the parameter interval: +1 turns counter-clockwise about normal, -1 clockwise. A straight interval satisfies neither sign.

      • normal: AutoMovieVector3Tuple

        Plane normal in the curve's declared frame; its direction defines the constraint plane.

      • sign: 1 | -1

        Required signed curvature orientation relative to the declared normal.
