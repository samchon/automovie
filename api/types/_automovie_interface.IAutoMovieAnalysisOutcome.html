    What one analysis run actually produced.

    Only the solved arm may carry results. unsupported means the host has no adapter for what was asked; not-run means an adapter exists but its input was not supplied. Both carry a reason and a remedy and have no field for a metric, a sample or a warning, so an absent analysis cannot be dressed as a clean one.

    The shape matches IAutoMovieDesignAnalysisOutcome with observed renamed to solved, because a solver computes rather than observes; the two negative arms keep the same spelling in both contracts.
