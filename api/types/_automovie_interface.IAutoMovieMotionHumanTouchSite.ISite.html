    ISite:
        | { out?: number; up?: number }
        | { draw: number }
        | { rule: "reach"; within: number }
        | { along: number }

    A site on a region: an offset stated in metres, a place drawn by the seed within a radius, or the place within a radius the rule chooses. reach is the place nearest the touching arm's shoulder, the shortest reach (#3357's reach rule).
