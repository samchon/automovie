    Type Alias Placement

    Placement: (IAutoMovieRigidTransform | { at: IAutoMovieVector3; yaw: number }) & {
        fixed?: boolean;
    }

    Where the scene puts an object: a rigid world frame, or the floor point under its origin and the heading its own +Z faces, degrees about +Y; fixed sets it as a fixture, which hands grip and never carry (IAutoMovieMotionHumanProp.fixed).

    Type Declaration

    • IAutoMovieRigidTransform
    • { at: IAutoMovieVector3; yaw: number }
      • at: IAutoMovieVector3

        World floor point beneath the object's origin, metres; the object builder places its origin above this floor point.

      • yaw: number

        Object yaw in degrees about world +Y.

    • Optionalfixed?: boolean

      Whether the object is immovable; omitted leaves the normal movable placement behavior.
