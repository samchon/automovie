    Type Alias IResult

    Prepared canonical curves, coefficient identities and complete edge uses. Matching four-ID tuples transport one explicit oriented interval to unbound incident sides. Their legacy render-normal owner remains separate from explicit normal fans. Every constructed coefficient is shared by its declared ID before tessellation; independently evaluated conflicting assignments omit only incident patches. Exact positions validate existing relations and never create identities. Equal restricted nets with different named intervals retain their finite fields; inter-authority tessellation sharing remains an explicit unqualified relation. Inputs must remain immutable until the returned closures are released. Maps and cached tuples are shared implementation state; preserve them until the entire atlas run is complete. Conflicts are reported without a replacement assignment and cause incident patch omission in the planning consumer.
