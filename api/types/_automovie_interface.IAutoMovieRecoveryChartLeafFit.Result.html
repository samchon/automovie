    Physical source-area quadrature population and its independent qualification.

    Type Declaration

    • integratedAreaMm2: number | null

      Area represented by accepted quadrature, in square millimetres; null means unavailable.

    • maximumRelativeAreaDiscrepancy: number | null

      Largest dimensionless relative mismatch between source and integrated child area; null means unavailable.

    • quadratureMinimumRows: number

      Minimum row population needed to integrate the complete current chart partition.

    • qualified: boolean

      Combined numerical and declared observation acceptance, without an embedding claim.

    • reason: string | null

      Actual termination or qualification reason; null, where allowed, means no local failure was recorded.

    • rows: number

      Actual quadrature row population retained for the current chart solve.

    • sourceAreaMm2: number

      Area of the supplied physical source triangles, in square millimetres.
