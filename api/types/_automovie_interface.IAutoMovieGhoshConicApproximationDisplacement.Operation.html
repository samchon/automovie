    Operation: (
        coordinate: { normal: readonly number[]; value: readonly number[] },
        rho: number,
    ) => number | undefined

    Intersect a Euclidean unit normal with a compactified bitangent conic family. The barycentric point and normal use the endpoint tangent triangle; normal coordinates have inverse-millimetre units. For rho=w/(1+w), the implicit conic is (1-rho)^2l1^2-4rho^2l0l2=0. At rho=1 this is the union of the triangle's two tangent edges, used only as a boundary search limit. A finite normal displacement is returned only for a unique intersection in the positive tangent triangle. Two distinct valid roots remain unsupported; a double algebraic root is one geometric intersection. No shape is emitted.
