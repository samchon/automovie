    Finalized shot data borrowed by compilePerformShotCameras to produce hero movement, lens intent, alternate takes and clearance reports.

    The live camera's frame moves, already sorted by start, compile through compileCameraMove into the clip cam:<scope>; with no move the camera is locked off and the clip is null. Each move's intent carries its framing, move, focal length and focus, the focus resolved to the world point the input gate accepted; the solve never reads the intent, a render host does. Each coverage job plays its one framing across the whole beat from its own staged camera, as the clip cam:<scope>:<camera>, so a host can cut to the angle at any instant, with no focus or focal length invented for it. Every subject is measured by one createPerformShotSubjectFramer, so hero and coverage frame the same subject. compileCameraClearanceReports then reports any take whose physical envelope is obstructed into the context's collector.
