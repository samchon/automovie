    Immutable normalized millimetre courses at increasing physical stations. planAutoMovieLocalHermite64 admits names, tolerance and safe budgets, then AutoMovieLocalHermiteField64.prepare admits matching stations and open continuous courses. Keep the input unchanged until completion or cancellation because field and planning closures retain these arrays and policy values.
