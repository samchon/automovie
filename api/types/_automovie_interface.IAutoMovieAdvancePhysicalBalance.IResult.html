    Advance one body's generic recovery controller from actual floor manifolds. Root tracking is withdrawn on unrecoverable support loss. Recovery requests use the shared support-swing interpolator and bounded endpoint motors; their completed placements remain offsets on subsequent authored goals, so the planner and physical support do not snap apart at landing.
