    Observe bounded multiscale Harris points and oriented gradient histograms. Harris derivative sigma 1, integration 1.5 and average-gradient orientation sigma 4.5 follow Brown, Szeliski and Winder (2005): https://www.microsoft.com/en-us/research/wp-content/uploads/2005/06/cvpr05.pdf A 448 trilinear histogram, unit normalization and .2 clipping follow Lowe's descriptor construction, while this remains a Harris detector, not full SIFT: https://www.cs.ubc.ca/~lowe/papers/ijcv04.pdf The 35-pixel oriented window, 10-pixel bins and Gaussian sigma 20 define the declared experimental descriptor chart. All positions return in original integer-pixel-centre coordinates; no point is a verified material identity.
