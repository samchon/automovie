    Type Alias IAutoMovieRecoveryPendingChartObservation

    Prepared chart awaiting the common boundary-network fit and atlas publication. The slab bounds are registered millimetres and interval/component are observation ordinals. Source faces and construction metadata remain private; outcomes is the same mutable array held by the observation ledger.
