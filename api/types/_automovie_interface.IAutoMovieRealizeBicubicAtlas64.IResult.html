    • IResult

    Type Alias IResult

    Realize the public metre-valued bicubic recipe through its owning engine. The polynomial kernel receives millimetres once and returns model metres. Complete prior chunks survive a declared output budget; no source mesh is read. Shared physical identities and actual global indices remain unchanged. complete describes the retained patch domain, while approximationQualified separately states whether the requested field-to-triangle estimate was met. Retained coarse cells can preserve a complete domain with approximation false; source-fit and normal qualifications remain independent of both fields. After streaming ends, unreferenced render vertices left by a local omission are compacted out. Triangle ordinals and physical domain/ID pairs remain the same; only the returned render indices and source-table slots are remapped. Requested triangle parameters retain actual chart coordinates per corner, aligned with triangle ordinals and primitiveRanges, through that compaction. A shared render vertex can have different incident chart coordinates; these records are not per-vertex UV0, skin weights or semantic surface addresses. Optional patch coefficients are the actual post-binding kernel grids in mm, filtered to patches with retained triangles. They let construction consume that same field instead of re-evaluating a pre-binding recipe. Omitted/false retains no coefficient snapshots; invalid retention flags reject before work.
