    Type Alias IAutoMovieChannel

    IAutoMovieChannel: IAutoMovieNodeChannel | IAutoMoviePointerChannel

    A channel: a typed, addressable animatable value, the universal target that tracks animate, drivers compute, and limits clamp.

    Modelled on glTF animation targets generalized by KHR_animation_pointer. Two forms:

    • IAutoMovieNodeChannel: a node's TRS or morph weights, the glTF-core path that every loader supports and the cheap, common case.
    • IAutoMoviePointerChannel: an arbitrary property addressed by an RFC-6901 JSON pointer (a light's intensity, a material factor, a camera field of view, a rig degree of freedom). This is the form that lets automovie address any value, not just node TRS. Today a shot's lightMotions applies light pointers, and the driver graph reads and writes pointer values inside a frame, but resolveFrame returns none of them.

    A node channel corresponds to the pointer /nodes/{id}/{path} in meaning only: channelKey keys the two forms in disjoint namespaces (node: and ptr:), so a pointer spelled that way neither aliases nor moves the node.
