    Lower semantic shot events and authored cues/dialogue onto one finished-film sound clock.

    All inputs are borrowed for synchronous planning. Profiles and track records are copied into the returned plan, but frameRate retains the timeline's reference. acousticProfile is recorded as provenance; this function does not derive per-event room-response receipts.

    OptionaleventCues

    eventCues?: readonly IEventCue[]

    Optional adopted cues synchronized to picture events. Each authored cue contributes one mix cue per retained occurrence, in film-frame order. Known events removed from the cut contribute no cue. Each resulting span must fit the film, and may extend across shot boundaries. Cues layer over the existing semantic event score and follow fixed-position cues. Callers computing an aggregate input fingerprint include these cues and their adopted asset identities in it.
