    over

    • over(build: (overlay: this) => IAutoMovieMotionHumanChainCore): this

      Perform other actions over the last appended one, at the same time and on other parts of the body: a wave or a phone during a walk.

      The last action carries the body (its root, its legs and whatever it does not yield); the actions build appends to the empty chain it is given start with it, follow one another, and each takes only the channels it claims. The performance refuses an action that cannot ride a carrier, a carrier that does not yield the channels asked, and two overlays that claim one channel at one time, naming both claims.

      a.walk({ to }).over((u) => u.handToFace({ task: "phone" }));

      Parameters

      • build: (overlay: this) => IAutoMovieMotionHumanChainCore

        Appends the overlaid actions to an empty chain of this person.

      Returns this

      The chain.

      Throws

      When the chain ends in no action, or in one already synced (put the overlays on it before syncing it).

    sync

    • sync(sync: ISync): this

      Time the last appended action to an instant of another action or of a cue track, as BML's synchronisation constraints do: one of its own instants (align, its start when absent) falls on the instant named (of and event), offset seconds later.

      The action starts as early as that needs. Where its performer's previous action still runs then, that action is cut there, which its cancel table must allow; an action that would have to start before its performer's previous one, or before the film, is refused with the earliest instant it can meet. What follows in the chain starts when the synced action ends. Cut the action (until) and put overlays on it (over) before syncing it.

      a.stand().gesture({ kind: "beat" }).sync({ of: "dialogue", event: "accent", index: 2, align: "strokeEnd" });
      b.stand().flinch().sync({ of: "strike", event: "contact" });

      Parameters

      • sync: ISync

        The instant to meet and which instant of the action meets it.

      Returns this

      The chain.

      Throws

      When the chain ends in no action, or in one already synced (an action meets one instant).
