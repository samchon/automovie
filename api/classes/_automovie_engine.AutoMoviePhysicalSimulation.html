    Class AutoMoviePhysicalSimulation

    Precompute fixed-step physics, then replay by time. Inputs are sampled bytes, not callbacks hidden behind a cache key. The run frees its assigned WASM World and event queue on exit; restoration allocates before that transfer. A late edit reuses a checkpoint only after every earlier input matches; changed geometry, solver settings or modes require a complete restart.

    • compute(
          input: IAutoMoviePhysicalSimulationInput.IInput,
          previous?: IAutoMoviePhysicalSimulation,
          signal?: AbortSignal,
          progress?: (completed: number, total: number) => void,
      ): Promise<IAutoMoviePhysicalSimulation>

      Compute or resume a complete film from an admitted input snapshot.

      An equal full identity returns previous unchanged. Otherwise a compatible unchanged prefix can resume from a native/controller/balance checkpoint; fully kinematic inputs generate frames without a native dynamics world. Progress reports completed intervals synchronously. Cancellation or an error rejects rather than returning a partial successful performance. Each declared coupled group fits its members against one snapshot. The result keeps every converged report, and a resumed run keeps the reports of its reused prefix. A failed group throws its typed error.
