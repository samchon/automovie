    Class AutoMovieSubjectDescriber

    Describes the subjects of one compiled shot artifact, sharing every index and measurement across one description pass.

    describeAutoMovieSubject and describeAutoMovieSubjects both describe through one of these, so a subject reads the same whether it is addressed alone or listed in the inventory. The describer indexes the artifact when constructed and memoizes model-frame part points per model and staged part boxes per built environment, so a pass over many elements of one model tessellates it once and stages each environment once for its building units. It treats the artifact as an immutable snapshot; a caller that edits the artifact builds a new describer.

    Every member summary is the page of autoMovieSubjectMemberSummary starting at the constructor's memberOffset. Prototype and prototype-part bounds are in model coordinates and every other kind's in world metres.

      Describe the subject at one address, regenerating an element part or a single compact instance only because it was addressed.

      Addresses are those of autoMovieSubjectAddress and autoMovieInstanceAddress. Throws an Error for an address no subject answers, and whatever instanceSlot throws for a member it cannot regenerate.

    inventory

    • inventory(): IAutoMovieSubjectDescription[]

      Every directly stored subject, sorted by address in render-id order.

      Holds each model as a prototype with its prototype parts, each staged scene node as an element, each instance set, and, per built environment, its transform-only groups, logical spaces and building units. Element parts and single instances are left out because they are regenerated only when addressed.
