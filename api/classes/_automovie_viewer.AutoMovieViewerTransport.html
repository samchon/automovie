    Class AutoMovieViewerTransport

    One authoritative review clock for a deterministic film producer: exact seeks, interval playback at a review speed, optional synchronized sound and capture freezes, all through one synchronous place(seconds) producer.

    A placement commits the displayed second only after the producer succeeds, so a failed draw never masquerades as a sought frame. Playback anchors one wall-clock origin (no integrated render deltas), snaps to the frame grid of fps and draws the interval's exact end before pausing. Sound starts before the anchor and a generation token cancels a start that a later pause, seek or speed change superseded. The clock source is injectable, so the logic runs in milliseconds without a browser.
