    Class AutoMoviePhysicsCache

    Owned fixed-step replay data. Readers never advance a solver. Checkpoints contain complete WASM state; frames contain only display/audit quantities. Simulation producers bound storage by admitted step and segment budgets; this mutable container does not enforce those budgets on direct writes.

    • at(seconds: number): IAutoMoviePhysicalFrame

      Interpolate completed world-space cache frames at local film seconds.

      Rejects nonfinite/out-of-film time, an empty cache or missing bracketing frames. Every frame must retain the same body/segment schema; direct cache writes do not validate that invariant. Returns fresh poses and velocities.
