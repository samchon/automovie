    • observe(): IObserver

      Create an optional callback-free observer for physical history costs. Pass it explicitly to history(); read returns independent numeric totals. Replacing public members cannot install code in physical evaluation.

      Returns IObserver

      A privately issued numeric observation handle.

      States explicit operation wiring, numeric counters and independent snapshots. Delegates to the native observation owner; histories borrow only its private counter storage and never invoke a caller method. One factory forwards observation ownership without an ambient context or altered physical input. No monkeypatch, callback notification, trusted caller flag or default instrumentation is introduced. Allocates one fixed-size counter record only on this explicit request; ordinary histories allocate no observation record. The same explicit handle can accumulate actual history epochs; repeated reads copy totals rather than triggering physical work. The caller owns the small handle; private weak registration retains no observer after callers and histories release it. It contains no body, pose, query log or process.
