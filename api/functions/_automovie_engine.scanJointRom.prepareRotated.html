    Function prepareRotated

    • prepareRotated(
          bone: AutoMovieHumanoidBone,
          constraint: IAutoMovieJointConstraint | null,
          rig?: IAutoMovieJointRotationFrame,
      ): ((rotation: IAutoMovieQuaternion) => number) | null

      The same overshoot sum for one bone gated by swing and twist, read from the joint's rotation alone: what prepare's scorer returns for a joint whose angles were read off that rotation on the range's own basis and rest frame (readsSwingTwistFrame), the gate's swing then twist faults in their order, with no angles to read. Such angles, read off a finite rotation, are finite, so the scorer's finite checks on them have nothing to report; a rotation with a non-finite component is the caller's to refuse. Null for an unconstrained or ungated bone, whose scan reads the angles themselves.

      Parameters

      • bone: AutoMovieHumanoidBone

        The bone.

      • constraint: IAutoMovieJointConstraint | null

        Its effective ROM.

      • Optionalrig: IAutoMovieJointRotationFrame

        Its frame as the caller's rig resolves it; the humanoid tables' when absent.

      Returns ((rotation: IAutoMovieQuaternion) => number) | null

      The scorer of a rotation, degrees, or null.
