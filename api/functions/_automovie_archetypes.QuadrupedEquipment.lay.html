      Add admitted yoke/pack geometry and their three possible real hook sites.

      Parameters

      • builder: ArchetypeBuilder<QuadrupedEquipment.Affordance, QuadrupedBody.Dimension>

        The actual animal builder, whose caller supplies total equipment-inclusive mass.

      • rig: QuadrupedBody.IRig

        Canonical +Z-forward rest landmarks of that animal.

      • params: QuadrupedEquipment.IParams

        Complete authored metre dimensions for each requested assembly.

      • archetype: string

        The producer identity reported by a parameter refusal.

      • spheres: readonly QuadrupedEquipment.ISphere[] = []

        Actual additional emitted body spheres, in neutral model metres; defaults to an empty list and is copied during planning.

      Returns void

      For invalid dimensions, nonfinite derived geometry, ordinary rig fit failure or insufficient authored clearance from an additional sphere.

      If an additional sphere has a nonpositive/nonfinite radius or nonfinite centre.

      Throws

      If the producer already used one of this equipment's part identities.
