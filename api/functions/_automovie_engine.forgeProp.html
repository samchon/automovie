    Function forgeProp

    • forgeProp(spec: IAutoMoviePropSpec): IAutoMovieForgedProp

      The FORGE consumer's object side: accept a prop an agent authored as data (crude primitive proxy, rich meaning: body, affordances, self-declared articulation, D011), returning the spec itself on success or every violation of the contracts below at once. forgeCast forges the performers; this forges the things they hold, open, and stack.

      The model contract: node is non-blank and model.id equals it (the staged scene joins on it, as for a forged cast member); origin is "generated" unless the spec names a modelRef, in which case the imported appearance is gated as below; and skeleton is null, because a riggable actor goes through forgeCast and a prop's moving parts are articulation nodes, not bones. validateModel covers parts, materials, extents, body (#595) and affordances (#604), with paths remapped onto $input.model.

      An imported appearance needs a non-blank modelRef, origin "imported", a non-null asset, and a sealed closure: unique non-blank asset paths with sha256: digests of 64 lowercase hex digits, the rigid gltf-static-v1 profile on the closure and every LOD with no humanoid bones, unique LOD levels whose asset and digest match the sealed ledger, and a hero LOD binding the model's own asset. Whether the reference resolves and the digests match bytes on disk is the builder's check, since the engine holds neither the registry nor the files.

      The articulation contract (when present): at least one joint; joint node ids unique and non-blank; parents resolving within the declared nodes (null is the prop's root) without a cycle; each joint's optional mesh naming a part of this prop's own model, and no part claimed by two joints; the binding targeting the declared profile; every boneMap value naming a declared node; and every semantic key the profile references (profileSemanticKeys) mapped. bindProfile would throw on the first missing key, so reporting all of them lets one correction round see the whole list, and a spec that passes binds without a throw.

      Parameters

      • spec: IAutoMoviePropSpec

      Returns IAutoMovieForgedProp
