    Function propSupportFace

    • propSupportFace(
          props: IAutoMoviePropSupportFace.IProps,
      ): IAutoMoviePropSupportFace | null

      The face one on-support relation resolves to, or null when the record states none.

      A surface target resolves to the cited built environment's support patch: its own footprint, holes included, and its own height rule. A prop-affordance target resolves to the host prop's stack-top extent carried through the affordance frame and the host's full staged transform (setPieceMatrix), hulled into one convex ring, with a plane height rule through the transformed top.

      Nothing is guessed. A citation that does not resolve, a host that is not staged, a contact of a kind that carries no face (handle, socket, hook), a stack-top without an extent, a patch whose region encloses no area, and a top staged edge-on to the ground each answer null, because a face nobody can measure is not a face a prop can be proven off. The edge-on top's height over the ground plan is not a function, so there is no rule to read it by, and inventing one would refuse or excuse a prop for a number the author never wrote.

      Lookups take the first record of a given id, exactly as propAnchorFrame does and for the same reason: contradicting ids are validatePropPlacements's own refusal, by name.

      Parameters

      • props: IAutoMoviePropSupportFace.IProps

        The relation target and the records it may cite.

      Returns IAutoMoviePropSupportFace | null

      The face in world metres, or null for the stated unresolved/degenerate cases. Finite authored transforms alone do not ensure finite derived plane coefficients.
