    Function mergeAutoMovieMeshes

    • mergeAutoMovieMeshes(meshes: readonly IAutoMovieMesh[]): IAutoMovieMesh

      Concatenate rigid meshes into one, rebasing each member's indices in declared order.

      This concatenates; it is not a boolean union, and the kernel has no solid union, intersection or difference. Overlapping members come back with both surfaces, including the parts now inside the other, and a contact edge welded by position belongs to four triangles rather than two, which validateMeshTopology reads as non-manifold. The region replaces a boolean here: extrudeAutoMovieRegion takes an outline and its voids together, so a wall less its openings or a plate less its cut-outs is one solid from one description. A subtraction along a direction the section does not run in, such as a niche stopping partway into a wall, is not offered at all, and buildAutoMovieWall refuses the pinched case by name.

      Normals and texture coordinates survive only when every member carries them. A merged buffer is read by vertex index, so a member without coordinates has no honest filler: zeros would pin its surface to one texel, which reads as flat paint nothing traces back to the merge, while dropping the attribute makes the loss visible at the binding. RGB multipliers and relief weights have an honest identity, one: a member that lacks them receives white or a full weight once any member carries them, and entirely bare inputs acquire neither buffer. Explicit physical source pairs survive every merge; equal pairs across members assert one point and must agree on the current grid, and a member without them contributes null entries that keep welding by position. The result owns all of its buffers and metadata.

      Every member is admitted before anything is appended: a skinned member, an index buffer that is ragged or names a missing vertex, and a normal, UV, colour or relief buffer not aligned to the member's vertices each throw, naming the member's position in the list.

      Parameters

      • meshes: readonly IAutoMovieMesh[]

        Rigid members in merge order, only read.

      Returns IAutoMovieMesh

      One mesh with every member's triangles.
