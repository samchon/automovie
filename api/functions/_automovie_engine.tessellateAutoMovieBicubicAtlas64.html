      Tessellate complete bicubic patches with explicit shared control identities. Sixteen controls are row-major: v rows, u columns, all in millimetres. Matching four-ID boundary tuples, including reversals, own one edge; matching endpoint control IDs own one corner. Different IDs at equal positions stay separate. Output positions are metres, indices are append-only global indices from vertexOffset, and a chunk may reference earlier vertices. Inputs remain immutable until completion. Optional triangle-corner parameters retain each accepted triangle's actual chart coordinates independently of shared render vertices and normal fans. They follow emitted triangle order, including after local omissions.

      Exact Bernstein restrictions refine each unit cell using the same-parameter Taylor estimate Muu/8+Muv/4+Mvv/8. Second-partial coefficient norms bound these derivatives in exact arithmetic; binary64 estimates are not outward-rounded certificates. Every incident patch registers boundary requests before emission. Line registries add hanging corners to parameter-boundary triangulations without a global grid. Bottom/top chains are zipped before exterior hanging edges are split, using their existing samples rather than an analytic cell-center vertex. Matching translated boundary polygons retain station-parallel face planes in exact arithmetic. Unequal samples and general fields acquire no normal-error bound. Source fidelity, immersion, orientability and absence of intersections are unproved.
