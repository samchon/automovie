    • gridAutoMovieSolidMesh(
          mesh: IAutoMovieSolidMesh.IMesh,
          input: IAutoMovieSolidMesh.IFace,
      ): string | IAutoMovieGridSolidMeshGrid | null

      Prepare a trimmed face's sampling grid without changing any mesh buffer.

      Surface jets are queried in station-major order and copied before the next query can reuse a returned vector. Metric-margin corner selection is retained, but a cell touching any trim segment's conservative chart bounding box is left for residual triangulation. Original domain authorities prevent unshared subdivision, while an exactly consumed full side or isolated cell-corner contact can retain its cell. They are not cutting loops. This prevents a small hole inside one cell from being filled merely because its four corners are kept.

      Boundary points keep their original IDs and use ILoop.chart on this face, independently of the coordinates their global mesh owner stores. Newly reserved grid IDs remain local until a successful face plan is committed. Source/grid/loop data must stay coherent during this synchronous preparation. An explicit numeric physical2 admission failure is a named refusal; actual source callback and ownership errors retain their original thrown identity.

      • mesh: IAutoMovieSolidMesh.IMesh
      • input: IAutoMovieSolidMesh.IFace
