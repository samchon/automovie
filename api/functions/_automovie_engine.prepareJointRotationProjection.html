      Prepare the nearest effector articulation under one unchanged clinical rig. The admitted normalized basis, rest frame, domain and clamp must describe the same joint and remain unchanged until the owning fit releases this closure. Targets are bone-local articulations after parent and fixed rest frames have been removed. The initial reference is the existing Euler reading clamped through the caller's actual clamp, so numerical ties keep that reading.

      A plain box with at most two positive-width coordinates has a bilinear quaternion objective. Actual Euler factor order and fixed-axis quaternions give four coefficients per actual fixed null/numeric mode; a finite SVD/boundary candidate list then contains its mathematical maximum. Every candidate is converted back to clinical degrees and clamped before its actual composed dot is compared. Within one query, exactly equal admitted clinical records share that composition and score. Their first occurrence also wins every later tie, so duplicate occurrences need no retained score or distance record. Full-turn aliases, neutral/sign maps and a fixed middle coordinate remain in that path. withQuaternion additionally returns the selected joint's already completed raw composition for a caller that will compose it again. The actual composer forwards four completed raw scalars into normalization, whose visitor reads the original normalized components directly into the score. Indexed numeric cells retain the raw values; only a selected paired result creates a quaternion record. Query-owned visitors keep every current input on its synchronous call stack. An exclusive projector-owned workspace reuses empty arrays and the row map; nested queries receive separate storage and finally clears all candidate references on return or throw. Unknown clamp outputs own copied bone/F/A/T values, so a callback reusing one mutable result cannot overwrite a retained reference or selected joint. Explicit swivelCandidates proposes intersections of an algebraic quaternion half-angle circle with a native two-axis product surface. Its deferred native-clamp gate leaves ordinary callable observations unchanged; actual angle ranges, clamping, FK and goals still belong to its curve consumer.

      Coupled swing/swing-twist gates, three mobile axes and unrepresentable alias arithmetic are refined one clinical coordinate at a time, at most four sweeps and none after a sweep that moves nothing. Along one coordinate the composed rotation's signed dot with the target is a sinusoid of half that coordinate's rig angle, so where the clamp returns the line's candidates as asked (a box's own coordinates) the line's least error is read at the sinusoid's stationary value inside the span or at the span's ends, with no search. Where the clamp moves a candidate off the line (a coupled gate or a foreign callback), nothing states what it composes there, and that line keeps its forty-step bracketed search. That fallback is a bounded local search, not a global-optimum guarantee. The analytic comparison identifies dots only within their summation error; it does not declare an unreachable rotation reached or change a ROM limit.
