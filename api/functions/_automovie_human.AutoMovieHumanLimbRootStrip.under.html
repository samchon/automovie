    • under(
          centre: AutoMovieVector3Tuple,
          ring: readonly IAutoMovieHumanLimbRootStrip.IJet[],

      ): IAutoMovieHumanLimbRootStrip.IJet

      An owner ring's jet where the ray from a centre toward a point's level projection meets the ring's outline, the jets interpolated along the outline's edge there. The strip pairs each column by this crossing, so a column runs from the owner's ring to the limb's own point along one ray, whatever order the owner's own phases run in: paired by phase index, the foot's ring and the leg's section ran in opposite orders on one side and twisted the ankle into an hourglass.

      Parameters

      • centre: AutoMovieVector3Tuple

        The ring's centre, mm.

      • ring: readonly IAutoMovieHumanLimbRootStrip.IJet[]

        The ring's jets, closed, in outline order.

      • toward: AutoMovieVector3Tuple

        A point of the limb's own section.

      Returns IAutoMovieHumanLimbRootStrip.IJet

      The jet at the crossing; the first jet where no edge is crossed.
