      Fit a selected private chart batch after one common boundary-network pass. All chart families enter the same network before any coefficient solve, so observed quarter cuts and maximal physical arcs can be reconciled across selected slabs. Chart names retain the caller's private ownership metadata. A failed global network falls back to explicitly unqualified independent networks, preserving finite siblings without claiming shared-bank continuity. Failed maps and fits remain local results and never supply a source mesh.

          Explicit fitting and work-limit policy shared by all chart jobs in this batch.

          • cornerDegrees: number

            Declared turning-angle threshold in degrees for preserving an independent corner tangent.

          • maxIterations: number

            Explicit positive numerical iteration ceiling; exhaustion remains a reported termination, not convergence.

          • OptionalmaxObservationRows?: number

            Optional ceiling on retained area-quadrature observation rows; omission admits at most 250,000 rows per fit.

          • maxPatches: number

            Positive integer ceiling on emitted chart patches; the fitter reports unresolved refinement at the limit.

          • OptionalmaxRefinements?: number

            Optional ceiling on residual-driven refinement rounds; omission permits four rounds after the initial fit.

          • maxSpans: number

            Positive integer ceiling on fitted cubic spans; exhausting it refuses the affected fit.

          • OptionalphysicalGradientLengthMm?: number

            Optional nonnegative millimetre exchange length multiplying physical derivatives; zero or omission disables that objective term.

          • toleranceMm: number

            Positive finite requested positional discrepancy in millimetres; it is not a continuous-surface certificate.
