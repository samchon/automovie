    • observeAutoMoviePlacedCamera(
          props: { sample: IPlacedSample; targets: readonly ICameraRequirement[] },
      ): IResult

      Observe active, source-owned requirements on the host's original delivery camera.

      The interactive Viewer checks each painted frame under fixed triangle budgets and reports a check they stop as deferred. Capture and delivery run every camera check without a budget, and they audit authored pixel coverage with the host renderer, so they leave nothing deferred. A check that cannot run on the subject at all is unsupported in every host.

      Parameters

      • props: { sample: IPlacedSample; targets: readonly ICameraRequirement[] }

        The placed sample and the requirements active at its time.

        • sample: IPlacedSample

          Settled original scene and delivery projection, before inspection effects.

        • targets: readonly ICameraRequirement[]

          Source-owned requirements active at this sample's exact time.

      Returns IResult

      Findings and one coverage row per check and requirement.
