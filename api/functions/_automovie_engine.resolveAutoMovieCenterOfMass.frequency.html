    Function frequency

    • frequency(length: number, gravity?: number): number

      The inverted pendulum's eigenfrequency, ω0 = sqrt(g / l) (Hof, Gazendam and Sinke 2005): its reciprocal is the time a centre of mass takes to cover its own velocity's extrapolation.

      Parameters

      • length: number

        The pendulum's length, metres; positive.

      • gravity: number = AutoMovieGravity.STANDARD

        Gravitational acceleration, m/s²; standard gravity (AutoMovieGravity.STANDARD) when absent.

      Returns number

      Radians per second.

      Throws

      When the length or gravity is not positive.
