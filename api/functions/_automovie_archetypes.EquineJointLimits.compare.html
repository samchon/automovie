      Compare an independently measured angle in one selected study's convention.

      Callers must reproduce the selected row's landmark rays and included-angle side. Model-local Euler offsets cannot be passed as included angles. This reports observed differences; it neither admits nor rejects an anatomical pose.

      Parameters

      • bone: Bone

        Actual distal bone identifying the joint.

      • studyDoi:
            | "10.3389/fvets.2021.752375"
            | "10.3389/fvets.2021.761500"
            | "10.3415/VCOT-15-11-0182"

        The source whose angle convention the caller reproduced.

      • includedAngle: number

        Included landmark angle in degrees within [0, 360].

      Returns IComparison | null

      That source's diagnostic, or null for an unmeasured joint.

      Throws

      For an invalid angle or a source that did not measure this joint.
