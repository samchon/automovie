          archetype: Archetype<Id, string>,

      A body released on its hinge and left to swing.

      Type Parameters

      • Id extends string

      Parameters

      • archetype: Archetype<Id, string>

        The archetype the hinge belongs to, for its range.

      • hinge: Id

        The hinge.

      • props: {
            launch?: number;
            pendulum?: IPendulum;
            release: number;
            seconds: number;
            start: number;
        }

        start, the film second it is released; release, the travel it is released at, at rest, degrees; seconds, how long it swings, after which it holds; pendulum, the swinging body's figures, pendulum(archetype, hinge) when absent; launch, a travel whose first passing is the launch.

      Returns ArchetypeTrack.ITrack<Id>

      The track.

      Throws

      As pendulum does; when the interval or custom pendulum figures are invalid or unrepresentable; when the release is outside the single rest-centred oscillatory well (strictly less than 180 degrees from rest); when that oscillation leaves the hinge's range; or when the launch travel is not passed while it swings.
