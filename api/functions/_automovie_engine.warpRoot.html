    Function warpRoot

    • warpRoot(
          root: IAutoMovieTransform,
          warp: IWarp,
          seconds: number,
      ): IAutoMovieTransform

      Warp a motion's root so it arrives at a different place and heading by a named instant, leaving the motion's own shape intact.

      Motion warping (Witkin and Popović, SIGGRAPH 1995) adds a smooth displacement map to a clip so it meets new keyframe constraints; Unreal's Motion Warping applies the same idea to the root over a warping window ending at a notify. Here the displacement (translation, metres, and yaw, degrees about +Y) is spread over [start, end] seconds by the minimum-jerk profile, so the warp adds no velocity or acceleration discontinuity at either end of the window; before the window the root is the source's, after it the full displacement holds. The yaw turns the root about +Y in the parent frame before the translation is added.

      Parameters

      • root: IAutoMovieTransform

        The source root at the instant.

      • warp: IWarp

        The displacement and its window.

      • seconds: number

        The instant.

      Returns IAutoMovieTransform

      The warped root.
