      Measure external interpenetration from the film owner's evaluated parts.

      Same-layer paths and explicit group ownership govern comparisons. The widest candidate search sorts world group bounds on X and stops at a separating frontier. Optional region bounds are built and compared only for groups that overlap another group. The initialized convex query measures surviving supported pairs without resampling the film. Tangency, native-precision uncertainty and any overlap involving an enclosing or proxy solid are candidates; separation of an enclosing solid proves clearance.
