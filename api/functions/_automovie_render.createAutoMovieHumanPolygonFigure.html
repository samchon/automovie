      A posed polygon figure with its cartoon face: the original polygon drawing (buildHumanPolygon) built once from the evaluator's neutral output, and a face (buildHumanCartoonFace) on its actual head front.

      place applies an evaluated pose to the existing groups and rebuilds the face only when the head pose or expression changes by value, disposing the previous face, so a held expression costs no geometry. The evaluator is a structural function (a Human skeleton evaluator fits); the Viewer imports no figure generator.

      The figure stays deliberately simple: a fix corrects a wrong value within the same primitives, never adds geometry, detail or realism, because its job is a cheap, deterministic silhouette for motion checks and diffusion hints.
