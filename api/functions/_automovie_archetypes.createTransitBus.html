    Function createTransitBus

    • createTransitBus(
          params?: string | { id?: string },
          seed?: string | number,
      ): Archetype<createTransitBus.Affordance, "aisleWidth">

      Builds a rigid, two-door low-floor city bus for boarding, standing and seated passenger scenes. The origin is at road height under the center of the body. +Z points forward and −X faces the curb in right-hand traffic. Open either door by advancing its leader to half the doorway width, in metres. The threshold and aisle are level with one another. Board the front door toward +X, travel along the aisle and exit the rear door toward −X.

      The New Flyer 40-foot Xcelsior supplies the nominal envelope, floor height and wheelbase (https://www.newflyer.com/site-content/uploads/2020/01/NF_Xcelsior_2020-web.pdf). LA Metro's boarding guide and rider guide ground the passenger routes and handhold use. The grasping diameter follows §1192.29(b).

      Parameters

      • params: string | { id?: string } = {}

        The model id, supplied as an option or as a positional string.

      • Optionalseed: string | number

        Draws the aisle width in the Xcelsior seat-model range. Omit it for the nominal 0.59 m aisle.

      Returns Archetype<createTransitBus.Affordance, "aisleWidth">

      A bus at rest with both passenger doors shut.
