    • resolvePhysicalSupportRedundancy(
          input: IAutoMovieResolvePhysicalSupportRedundancy.IInput,
      ): Record<string, IAutoMovieRigidTransform>

      Return a warm support seed's redundant coordinates to the authored posture.

      A warm seed keeps the previous fit's task-space choice, such as which way a near-straight chain bends. The support task constrains only each endpoint and its planted floor witnesses, so a coordinate change in that task's null space (a limb swivel or patch yaw) has no restoring term in the least-squares fit, whose steps never leave the row space. Carried forward from step to step, such a change accumulates under root sway. This applies Liégeois's redundancy resolution once to the seed: the coordinate difference to the admitted authored posture is split along the right singular directions of the support-task Jacobian. Directions are returned to authored from the smallest linearized task effect upward while the root-sum-square of those effects stays within the fit's own residual tolerance; the remaining directions keep the warm task-space choice. The null space therefore always returns, and a near-singular row (whose singular value is small but whose task effect is second order) does not hold a first-order posture offset. The subsequent bounded fit corrects the task within the same tolerance.

      Coordinates are the native independent twist coordinates θ = 2 atan(q_axis / w) owned by projectPhysicalJointRotation. The Jacobian uses central differences with the error-optimal step ε^(1/3); its truncation and rounding noise is of relative order ε^(2/3), far below the tolerance budget, so numerically null directions always return. ROM projection follows the update.
