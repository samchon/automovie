    • prepareSkeletonPoseResolution(
          skeleton: IAutoMovieSkeleton,
          jointAxes?: Partial<Record<AutoMovieHumanoidBone, IAutoMovieJointAxes>>,
          restFrames?: Partial<Record<AutoMovieHumanoidBone, IAutoMovieRestFrame>>,
          topology?: IAutoMovieSkeletonTopology,
      ): IAutoMovieSkeletonPoseResolution.IRig

      Snapshot a rig's static FK prerequisites once, then resolve changing poses through operation-owned dependency rows. Rest translations and rotations, axis precedence, clinical bases, affine frames and the reachable parent order are copied here; later edits to the source rig/tables do not change this snapshot. Reprepare explicitly to adopt such edits.

      Every authored joint is admitted in its original order, even an overwritten, unreachable or undemanded record. Joint records are values: a record is not edited after the rig admitted it, and a changed articulation is a new record (a pose's list of records may change; the rig keeps no list). The rig reads a record it already admitted as the value it admitted, without reading its coordinates again, so a pose made of another's records (a limb's reduced pose, a fit merged back) costs a lookup a shared record. A requested set limits returned bones and the computed ancestor closure, preserving the full walk's relative order. Omission returns all reachable bones. Root and rest scale remain ignored. Root placement keeps the ordinary parent-first arithmetic; root-null reads reuse the independent root-relative frames. Every output is fresh plain data. prepareBones snapshots fixed output membership/order once. preparePose actually admits a fixed source/root once, then accepts complete appended edit lists; absent edits restore that source. Neither companion stores a pose identity, target answer or query-result history.
