    Function overshoot

    • overshoot(
          body: IAutoMovieMotionHumanBody,
          shapes: readonly IAutoMovieMotionHumanColliders.IPlaced[],
          elbow: IAutoMovieVector3,
          wrist: IAutoMovieVector3,
          side: "left" | "right",
          others?: readonly IAutoMovieMotionHumanColliders.IPlaced[],
          goal?: boolean,
          rival?: IAutoMovieVector3,
          hint?: IAutoMovieVector3,
          rests?: readonly IAutoMovieMotionHumanColliders.IPlaced[],
      ): number

      How far a forearm lies inside the room it needs, as degrees of upper arm turn (HumanArmOvershoot.of, which states the rule).

      Parameters

      • body: IAutoMovieMotionHumanBody

        The body, for the forearm's radius and the upper arm's length.

      • shapes: readonly IAutoMovieMotionHumanColliders.IPlaced[]

        The trunk's placed colliders (trunk).

      • elbow: IAutoMovieVector3

        The elbow, world metres.

      • wrist: IAutoMovieVector3

        The wrist, world metres.

      • side: "left" | "right"

        The arm.

      • others: readonly IAutoMovieMotionHumanColliders.IPlaced[] = []

        Placed colliders the wrist has no goal on (another body's); none when absent.

      • goal: boolean = true

        Whether the wrist is where a goal put it, which excuses its own depth in shapes; a carried arm between its ends has none.

      • Optionalrival: IAutoMovieVector3

        The world point the other arm's goal will put its wrist at, while that arm is still to be fitted; absent, the room is kept unless the other arm's colliders are among shapes.

      • Optionalhint: IAutoMovieVector3

        The world point the goal hints the elbow toward; none when absent.

      • rests: readonly IAutoMovieMotionHumanColliders.IPlaced[] = []

        Placed colliders of another body the goal lays the hand on; none when absent.

      Returns number

      Degrees; 0 when the forearm clears every shape and the elbow keeps its side.
