    Function autoMovieDrawingOpeningMark

    • autoMovieDrawingOpeningMark(
          design: IAutoMovieDrawingDesignIndex,
          frame: IAutoMovieDrawingFrame,
          opening: IAutoMovieBuiltOpening,
      ): IAutoMovieDrawingOpeningMark

      One opening as a drawing can state it, and what that statement rests on.

      The size and basis come from autoMovieOpeningNominalExtent, the rule the schedule also reads: an opening with its own void is marked with basis: "profile", its hull size, and its drafted outline placed on the host boundary's face and projected onto the page on the grid; one sized by its filling element is basis: "fill" with an empty outline, because the leaf's extent is not the hole's shape; one with neither is basis: "none" with null sizes. Validation guarantees a profiled opening's host boundary has a face, which the outline placement relies on.

      Parameters

      • design: IAutoMovieDrawingDesignIndex

        Index of the validated design.

      • frame: IAutoMovieDrawingFrame

        The view's page basis.

      • opening: IAutoMovieBuiltOpening

        Opening to mark.

      Returns IAutoMovieDrawingOpeningMark

      The opening's mark, carrying its identity, basis, outline and size.
