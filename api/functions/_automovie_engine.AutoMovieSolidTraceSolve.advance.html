      Continue from a point to a target parameter by predicted and corrected steps, halving a rejected proposal and recovering a low-defect step.

      Parameters

      • part: IAutoMovieSolidSurface

        The part's surface.

      • host: IAutoMovieSolidAtlas

        The host's faces.

      • law: IAutoMovieSolidTraceLaw.ILaw

        The parameter's law.

      • from: IAutoMovieSolidIntersection.IPoint

        The point to continue from.

      • target: number

        The parameter to reach.

      • tolerance: number

        Largest gap accepted, mm.

      Returns IAutoMovieSolidIntersection.IPoint | null

      The point at the target, or null after more than HALVINGS consecutive failed halvings, 1024 meeting candidates, or a proposed parameter that cannot make finite representable progress.

      The next proposal may double when the corrected world defect uses at most one eighth of the existing acceptance allowance. That is a bounded proposal heuristic, not a third-order error guarantee for a C2 surface; every candidate still passes the same predictor/corrector acceptance test. The original interval caps growth and each accepted point restarts the consecutive-failure counter. The 1024-candidate protection is a product work budget, not a geometric sufficiency condition or a wall-time bound. Different accepted substeps can change rounding or expose a budget failure without changing the source surfaces, Newton residual or tolerance.
