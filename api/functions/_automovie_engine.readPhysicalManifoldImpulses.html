    Function readPhysicalManifoldImpulses

    • readPhysicalManifoldImpulses(
          world: World,
          manifold: TempContactManifold,
          first: number,
          second: number,
      ): number[]

      Normal impulse, N s, that the native solver applied at each tracked point of one contact manifold during the completed step; zero for points it did not solve.

      The pinned narrow phase reduces a manifold with more than four tracked points to four solver contacts and writes impulses back only to those, while contactImpulse reads every tracked point. A point dropped from the selection keeps its last impulse for as long as it stays tracked, so summing every point reports a load nothing receives (dimforge/rapier#1077; a resting six-point prism reads 1.46 times its weight). Each solver contact copies its tracked point's distance exactly and lies at the midpoint of that point's two surface witnesses, so the point with an equal distance and the nearest midpoint is the one the solver used.

      Parameters

      • world: World

        Native world, between steps.

      • manifold: TempContactManifold

        One manifold of the pair.

      • first: number

        Handle of the manifold's first collider.

      • second: number

        Handle of the manifold's second collider.

      Returns number[]

      One impulse per tracked point, in tracked order.
