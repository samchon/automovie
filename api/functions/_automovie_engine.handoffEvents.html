    Function handoffEvents

    • handoffEvents(
          child: string,
          parent: string,
          start: number,
          end: number,
          actionIndex: number,
      ): IAutoMovieInteractionEvent[]

      The four scripted-cue events one attachTo handoff emits: the child is grabbed and attached at start, then detached and released at end.

      Every event names the child as both actor and object and the parent as target, carries no contact point or reaction, and records actionIndex, the authored action's index, so a reader can trace it back. Its id is <kind>:<child>:<parent>:<time> with the time written by eventTimeKey. Repeated participant pairs in one formatted time bin collide, and participant ids containing colons can make the delimiter join ambiguous; this constructor does not enforce uniqueness. Times are shot-local seconds. coupleObjects calls this once per handoff it bakes; a staged mount emits no events at all.

      Parameters

      • child: string

        Coupled child node id.

      • parent: string

        Parent node id whose bone carries the child.

      • start: number

        Shot-local second the child is grabbed and attached.

      • end: number

        Shot-local second the child is detached and released.

      • actionIndex: number

        Index of the authored attachTo action.

      Returns IAutoMovieInteractionEvent[]

      Four new events in grab, attach, detach, release order.
