      Admit a complete source/root without computing unused output frames, only through this factory's original own-data map callable. Unknown, copied, proxied, inherited or replaced readers decline without invoking a method/getter. A supported call performs the real ordered admission; its failures propagate and no source-validity flag/result is retained.

Every supported call reads its current source; matching fixed-source consumers own completion reuse and raw fallback. The weak registration retains only the original callable; descriptor/empty-set temporaries end with this call, without a source verdict, result history, strong registry, handle or task. Speedup is unmeasured.
