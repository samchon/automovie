      Give a distally twisting mid bone its bounded twist share before orienting the effector. The existing solveDistalTwist candidate law starts from the current articulation, clamps the mid joint and ranks the effector rotation its shared projector will actually show. It is not a global solve over both joints. Bones without distal twist return unchanged.

      The fixed effector frame includes intermediate rests and articulations. Twisting leaves the effector point unchanged when the lower-to-effector offset is parallel to the lower twist axis, as on the canonical limb rig; an arbitrary offset does not satisfy that point-preservation premise.

      The pose with the mid bone's twist set within the actual rig's limits.
