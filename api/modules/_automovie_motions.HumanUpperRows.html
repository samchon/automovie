    Namespace HumanUpperRows

    The upper-body acts re-expressed as rows over the arm's phrases (#3361): each row is armPhrase with its phrase, its hand and the shape of its target fixed, so a gesture, a touch, a hand at rest, a hand to the face and a wipe share one plan, one timing and one set of refusals, and each accepts any base, carrier, side and manner the phrase law does. The rows of the older laws (gesture, touch, rest, handToFace, wipe) stay until these rows pass their verdicts; the target a touch or a wipe needs, and the prop a tool row holds (held), are left open.

    A row is written for the right hand: the region of a side it fixes (hipRight) is read on the acting hand's own side (mirror), so the same row puts the left hand on the left hip.

    Every offset is a share of the arm's length (upper arm, forearm and hand) in the performer's frame, so a row fits any body; the shares are provisional, set from each act's description with no measured source read.
