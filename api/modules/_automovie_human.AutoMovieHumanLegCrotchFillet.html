    Namespace AutoMovieHumanLegCrotchFillet

    The crotch ring the leg starts on, rounded.

    The ring the leg takes is the trunk's arc closed by the slit between the thighs, so it has a corner at each pinch. Each corner is a cubic Hermite fillet whose sides run the root's corner size along the arc and the slit, so the leg's own sections never keep the root's corner. The trunk's first and second station derivatives are carried round the loop: the arc's own, a linear run along each fillet, and the pinches' on the slit, on the midline. The loop is read at the leg's phases about the ring's centre.
