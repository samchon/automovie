    Namespace AutoMovieMotionHumanTiming

    How long an effector takes to travel a distance.

    Two rules, and which one a movement takes:

    • AutoMovieMotionHumanTiming.transport: a movement in free space (a gesture's preparation, a hand to a rest place, a retraction) lasts 0.25 + 0.5 D seconds for D metres. Provisional: a gesture's preparation lasts a few tenths of a second and reaching time grows with distance (Fitts 1954).
    • AutoMovieMotionHumanTiming.aimed: a movement that must stop on a target of a given width lasts a + b lg A + c W for an amplitude A in millimetres and a width W, the two-factor model McIntosh, Mon-Williams and Tresilian (2018, J. Exp. Psychol. Hum. Percept. Perform. 44:1022, table 1) fitted to reach-to-grasp times, with a = -306.07 ms, b = 297.27 ms per decade and c = 0.65 ms per millimetre (r^2 = 0.97). Amplitudes below the study's shortest (170 mm) take its value, since the fit is not valid there.

    AutoMovieMotionHumanTiming.of chooses: a place that is solid and has a width is aimed at, any other is travelled to.
