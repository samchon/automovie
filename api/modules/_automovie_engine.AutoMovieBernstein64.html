    Namespace AutoMovieBernstein64

    Preserves the existing binary64 Bernstein namespace while responsibility owners implement its operations. All five structural types and twenty-five function names remain available, including the thirteen subdivision, grid and quotient functions previously implemented directly in this namespace. Function values are direct aliases; their coefficients, domains, errors and arithmetic are unchanged. Internal owners depend on the algebra implementation rather than this facade, preventing import cycles.
