    Namespace AutoMovieMeshExtract

    Reverse extraction of sparse 2D lines from a dense triangle mesh: exact plane sections at stations along a frame axis, with their chained loops, extreme points in eight in-plane directions and artifact flags, and the fewest cubic Hermite knots (value and slope on a run, point and tangent on a closed loop) that hold a dense sampled line within a tolerance. It is an analysis of an existing mesh, kept apart from construction, whose sources are authored and never fitted to samples: a modeler reads a reference here, corrects the result by eye, and authors the corrected knots as source. profileCurve is the output adaptor for that hand-over: it turns per-station knot loops (extracted or corrected) into the curve owner the construction profile consumes, which is why this module imports the profile source type and the natural spline; it evaluates the given knots and fits nothing.
