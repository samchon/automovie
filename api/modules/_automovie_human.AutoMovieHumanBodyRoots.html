    Namespace AutoMovieHumanBodyRoots

    Root loops on a chain's chart and the transition strips that join an appendage to them.

    A root loop is a closed curve (s(u), t(u)) in a base chain's chart. The base is lofted with every cell touching the loop's inside left out; the hole's edge of grid vertices and the loop itself are joined by a zipper, so the base surface runs up to the loop. Between the loop and the appendage's end ring runs the strip of AutoMovieHumanBodyStrip, which meets both with their positions, tangent planes and curvatures (G2); this module samples it in rings and zips its base edge to the hole.
