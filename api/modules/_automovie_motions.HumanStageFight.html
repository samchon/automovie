    Namespace HumanStageFight

    Stage fighting short of a strike: slaps, grabs and holds, each a row of a shipped action on a partner the composition names (the row leaves the target or the partner open). The receiver's response is its own row (slapped, shoved, grabbed, pushed), whose start the composition syncs to the attacker's contact: b.registered("slapped", { from }).sync({ of: "slap" }). Register the ones a film uses.
