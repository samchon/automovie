    Variable triangleIndicesOfConst

    triangleIndicesOf: (mesh: IAutoMovieMesh, label: string) => number[] = ...

    The triangle index run a mesh carries, refused rather than read past its end.

    An index array that is not a whole number of triangles, or that names a vertex the mesh does not carry, would otherwise read undefined and emit NaN positions and a NaN volume that no downstream check attributes back to the malformed input. A mesh without indices is read as consecutive triangles 0, 1, 2, ... over its vertices.

    Positions are not checked for finiteness; callers that need finite coordinates check them separately.

    Type Declaration

      • (mesh: IAutoMovieMesh, label: string): number[]

      • Parameters

        • mesh: IAutoMovieMesh

          Mesh to read.

        • label: string

          Name the error messages give the mesh.

        Returns number[]

        The mesh's own indices array, not a copy, or a new consecutive run when it has none; callers must not mutate it.

    Throws

    Error when positions are not whole xyz triples, indices are not whole triangles, or an index is not a safe integer inside the vertex range.
