    Locate a point against a direction-correspondence sweep's sampled section planes.

    Signed plane distance is sampled over 128 equal intervals; sign changes are bisected 48 times and exact sample roots retained. The candidate with smallest absolute radial offset wins. If no root is detected, the nearer end plane is used. Tangential roots or multiple roots between probes can be missed, so that fallback does not prove a point is beyond an end. Polar turns match the surface parameter only for direction correspondence; parameter correspondence is rejected. Offset is signed in-plane radial distance, not Euclidean distance to the surface or a global closest-point certificate.

          A model-space point and a compiled direction-correspondence sweep for section-plane inversion.

          The locator samples signed plane distance over 128 intervals and bisects sign changes 48 times. It selects the candidate with the smallest absolute radial offset. If no candidate is detected, it uses the end plane with smaller absolute signed distance. Tangential roots and multiple crossings between samples can be missed, so fallback does not prove the point lies beyond an end.

          • point: IAutoMovieVector3

            Finite position in the surface's model frame, in metres. The locator rejects nonfinite coordinates; distance outside an end is projected into that end plane for the reported radial offset.

          • surface: IAutoMovieSweepSurface

            Compiled surface queried by section frame and polar radius. Parameter correspondence throws; explicit direction and omitted/default correspondence are accepted.

        Returns IAutoMovieLocateSweepPoint.IResult

        u, the spine parameter of the section plane holding the point, 0 to 1; v, the point's polar direction in that plane, a turn from 0 to 1; and offset, its distance outside the surface along that direction in metres, negative inside.

    Throws

    Error when the point is not finite or correspondence is parameter.
