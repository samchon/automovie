    Forward kinematics: resolve a pose against its skeleton into one transform per bone.

    Each bone's local rotation is its rest rotation composed with the pose's articulation (jointToQuaternion); its world rotation is the parent's world rotation times that, and its world position is the parent's position plus the rest translation turned by the parent's world rotation. Rest scale is not applied. The walk starts at the pose's root transform, or the origin with identity rotation when it is null, and visits parents before children, so the result lists bones in that order. The renderer uses localRotation; validators and solvers use the world fields.

    Only bones reachable from a null-parent root are resolved. A bone with an undeclared parent, in a detached subtree or in a parent cycle is omitted, and a skeleton without a root resolves to an empty array; callers that need a bone gate on reachableBoneNames, which reports the same set. A joint for an undeclared or unreachable bone contributes no transform, but every authored record is still admitted in order; a repeated bone takes the later joint. An optional requested set returns only its reachable bones and computes their ancestors, pruning unrelated subtrees after admission.
