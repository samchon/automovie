    Check every field of one analysis run except its seal.

    The rules all defend the same line: an absent measurement must stay visibly absent. A metric without a value must carry a reason and a remedy and may not carry a target; a metric with a value may not carry a gap and must agree with its own verdict; a spatial sample may only be a field of a metric that actually produced a value, so no overlay can be drawn for a computation nobody ran.

    Violations are appended to out with paths rooted at $input, in field order: header, solver, settings digest, then the outcome. The digest field and its agreement with the contents are left to the caller: validateAutoMovieAnalysisRun checks them for a run that arrived from elsewhere, while sealAutoMovieAnalysisRun calls this before it computes the digest, so a seal never hashes a record it will refuse.

    Resident metric, sample and warning slots are visited by index and an absent record is refused at its slot; judged comparisons must be at-least or at-most. Other nested fields must already have the declared shape: reading a missing solver.id container or sample position can throw a TypeError, so this is not a total unknown-JSON schema validator.
