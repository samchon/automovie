    Interface IAutoMovieEditPlan

    Coding-agent-owned edit over shot artifacts that were already built.

    cutSequence folds it into an IAutoMovieSequence and reports its accumulated runtime in seconds; pacing and continuity rationale are review prose. The cut refuses invalid edit spans and a non-finite runtime. A placement may use two exact built event ids as its source bounds. Optional requirements check that a chosen play retains an interaction event or that a prop channel matches across a hard cut.

    OptionalrequiredPropContinuity

    requiredPropContinuity?: readonly {
        component: "translation" | "rotation" | "scale" | "weights";
        entry: number;
        node: string;
        tolerance: number;
    }[]

    Compare one sampled prop channel on the two sides of a declared hard cut. Omitted or empty means no prop checks. Both shots must use the same staged scene and write the channel through objectMotions. Reads the outgoing trim end from the left and the incoming trim start inclusively. For a symbolic trim the selected event supplies the exact end. Without a trim, those times are the outgoing shot duration and incoming time zero. If the outgoing winning track starts, steps or loops exactly at the cut, the check refuses that boundary because the inclusive sampler would read the discarded side. There is no fallback to an unstored staged value.
