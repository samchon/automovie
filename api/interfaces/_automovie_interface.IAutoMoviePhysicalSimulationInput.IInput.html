    Interface IInput

    Complete sampled scene and explicit work budgets for deterministic fixed-step simulation.

    rate is cached intervals/s; substeps multiplies it into native ticks/s. Positive duration times rate is an exact safe integer bounded by maximumSteps. AutoMoviePhysicalSimulation owns a clone with defaults applied; settings, profiles, targets and impulses participate in content identity and checkpoint compatibility. admitPhysicalSimulation checks finite native-range scalars, floor dimensions, population and clock budgets before world allocation. Empty arrays are valid where no body or impulse is needed; invalid references or budgets throw.
