    Interface IAutoMovieMotionHumanLexiconBladeParams

    Open parameters of the blade lexicon family, keyed by each runtime export name. Omitted keys are fixed by the row before its underlying law plans; the remaining members retain that law's defaults, units and required status. HumanPerformanceParams checks these open inputs using the generated row schema before HumanActionRow resolves fixed values.
