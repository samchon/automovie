    Interface IAutoMovieSurfaceRegistry

    The vertices of a surface rig by identity, each with the writer that evaluates it per pose, from registerAutoMovieSurfaceVertices. Registration, binding and finalization are allowed only before finalization; afterward only count, identity lookup and the resolved writers remain usable. A binding failure leaves the registry terminal and releases its compile-only records.

    bindSweep

    • bindSweep(key: string, bind: (sample: ISweep | null) => void): void

      Bind a dependent evaluator after every sweep cell has been resolved, before the sweep rigs are sealed.

      The callback receives the geometric writer and cell, independent of pinned cage controls. An identity not registered as a sweep sample receives null; an observational node then keeps its raw zero-cell meaning. The callback runs once during finalize and may register sweep samples or probes, but cannot add registry entries.

      Parameters

      • key: string

        Exact shared sample identity

      • bind: (sample: ISweep | null) => void

        One-time compile callback; its reference is released after finalization, including failure

      Returns void

      Throws

      Error if the registry has been finalized
