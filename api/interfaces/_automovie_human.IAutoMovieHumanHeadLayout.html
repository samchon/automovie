    Interface IAutoMovieHumanHeadLayout

    Stations and sizes of one person, calibration millimetres.

    Keeps public chords, shared datums, original neck sources and explicitly separate shape priors available to actual source authors. One layout feeds head mass and regional builders before any tree realization. Data does not certify reference fit, actual tape closure, internal overlap or final join success. Fields state calibration units and distinguish border direction, bulk relief, measurements and retained conventions. A data interface performs no calculation. Producers own each original preparation. The caller owns numeric records and call-owned source closures; no global figure is retained.
