    Interface IAutoMovieRecoverySupportFit

    Fit evidence kept outside compact support-coefficient generation authority. Pixel residuals include the implied intersection's support, not only each independently fitted offset. Numerical event and mesh counts qualify the selected representation; they do not observe hidden physical topology.
