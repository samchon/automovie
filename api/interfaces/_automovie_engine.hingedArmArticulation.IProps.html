    score

    score: (
        upper: IAutoMovieQuaternion,
        lower: IAutoMovieQuaternion,
        swivel: number,
        posed: (
            swivel: number,
        ) => { lower: IAutoMovieQuaternion; upper: IAutoMovieQuaternion },
    ) => {
        deviation: number;
        exact?: () => number;
        overshoot: number;
        tiebreak?: () => number;
    }

    Score one candidate's bone-local root and mid rotations: overshoot is the total ROM overshoot in degrees, compared first, and deviation the effort tie-break, compared second. The caller owns the decomposition convention and the rig's constraints. With exact, deviation is a lower bound of the tie-break and exact gives it exactly: a caller whose tie-break ends in a costly non-negative term passes the rest as the bound, and the term is computed only for a comparison the bound cannot decide. With tie, tiebreak is a second key: two deviations in one bucket of width tie are one, and the lesser tiebreak decides (task priority, Siciliano and Slotine 1991: the second objective only among the first's optima), so exact need then be right only to its bucket. The score and its lazy readers describe the same unchanged objective throughout this synchronous solve. The candidate's swivel, degrees, and its branch's poser are passed for a caller that reads them.
