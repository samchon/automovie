    Interface IPrepared

    One original family, with independent guides/lower material and a lazy upper closure.

    Both consumers retain this invocation's one generating family and original axis. Retains only the original base, one requested lower adapter and one requested closed source.

    ReadonlytapeInvariant

    tapeInvariant: { part: IAutoMovieViewPart; plan: IAutoMovieHumanHeadLayout }

    The family's pre-closure member and its layout, exact on and below nasion.

    The upper tape closure varies only cranialTapePower. In AutoMovieHumanHeadMassSource.prepare that power enters two scalar outlines and nothing else: the fullness shoulder, through its knots at nasion (vault), frontotemporale (cranial) and the last station, and the face departure, through its frontotemporale knot (frontal - cranial). The front, back and side support outlines, the axis, the stations and the pole are built once before the power is read. Every shoulder and departure knot carries explicit zero first and second jets, so AutoMovieViewOutline interpolates each knot span by its own quintic Hermite: a span's values and station derivatives depend only on its two end knots. On and below nasion both members share the spans gonion -> nasion (shoulder constant vault; the pre-closure member's single span gonion -> last is the same constant) and zygion -> nasion (departure constant face - vault), with every lower knot identical. Their native sections, frames and first/second station derivatives are therefore bit-identical at every station at or below nasion, and differ only above it. The layout differs only by that power, which no regional consumer reads. A consumer whose every mass read lies at or below nasion may use this member without the closure; a consumer reading above nasion (the ears, whose top lies above it, and the orbital domes, whose footprint reaches it) must still request the closed member.

    Methods

    closed

    • closed(): IAutoMovieHumanHeadCanonical.IOutput

      Resolve the actual complete original once when its upper field is needed.

      Solves the original family's actual tape and returns its selected part/witness unchanged. Full-source demand is explicit and independent of guide/lower consumers. Every source failure propagates; no cached coefficient or incomplete source is returned as closed. The full closure is attempted once per immutable preparation, including a failed attempt, without a raw loft; retained reads return its result or rethrow its original failure. Production, original sections and raw readers borrow that identical selected part or observe the same original failure; a new input context owns a fresh attempt. The result or original error and immutable source dependencies live with this one invocation, without a global failure cache.

      Returns IAutoMovieHumanHeadCanonical.IOutput

    lower

    • lower(
          placement: IAutoMovieHumanNeckSource.IOutput,
      ): IAutoMovieHumanNeckConstruction.IOutput

      Borrow the exact lower original interval once, without the upper solve.

      Existing restriction reads the unchanged family's original values, parameter jets and axis below nasion. The output is an explicit regular adapter interval, never a second full head. An upper request or a different placement context is rejected; no old source or missing derivative is substituted. One requested interval scalar restriction and engine loft, then constant-time reuse. Returns the same adapter for the same immutable placement and generating family. Only one placement identity and its actual adapter survive with this preparation.
