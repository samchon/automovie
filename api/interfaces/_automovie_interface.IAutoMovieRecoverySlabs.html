    Interface IAutoMovieRecoverySlabs

    Acquisition-only source topology with newly verified cut addresses and caller-attested saved curve references. No coefficients, source positions, source triangles or normal fields are returned. PL event qualification has the existing source-topology meaning and does not qualify the saved curves.
