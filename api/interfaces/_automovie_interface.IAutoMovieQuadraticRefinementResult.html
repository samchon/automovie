    Interface IAutoMovieQuadraticRefinementResult

    The solution refineAutoMovieQuadraticProgram returns for a diagonal quadratic program, with its residuals measured on every original row.

    primal and dual are the native solution unless polishing produced a finite candidate that passed the caller's threshold on every original row; then they are that candidate. status is always the native status, so an unsuccessful solve is never promoted. The caller admits the solution only when status is 1 and the three residuals are within its tolerance. All arrays are new and owned by the caller.
