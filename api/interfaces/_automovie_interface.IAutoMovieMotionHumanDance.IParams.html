    Optionallock

    lock?: { event?: string; of: string }

    A cue track to lock the beats to (#3340, #3378): beat k falls on the track's k-th instant named event (beat when absent) at or after the action's start, and the tempo is the mean interval of those instants, so bpm is not read. The track is the performance's input, never audio. Unlocked, the beats follow bpm from one period after the start.

    Type Declaration

    • Optionalevent?: string

      Cue event name whose instants are used; defaults to beat.

    • of: string

      Performance cue-track id whose instants entrain the dance beats.
