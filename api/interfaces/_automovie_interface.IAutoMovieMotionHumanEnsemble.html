    Interface IAutoMovieMotionHumanEnsemble

    A group of people written once: its members are performers of the grammar, ${id}.${index} with the index from 0, each given a body from the group's pool, a proficiency and attribute values drawn from the group's distributions, an optional role, and a place.

    The draws are keyed by the chain seed, the id, the member's index and the quantity (HumanAttribute.stream), so adding a member or an attribute leaves every other member's values bit-identical. A preset names a set of distributions (HUMAN_ENSEMBLE_PRESETS); attributes and proficiency override its rows. A member's place is its formation slot at second 0, or the place given.
