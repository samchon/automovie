    OptionalallocationStateKnown

    allocationStateKnown?: boolean

    Whether reported current fields can certify native allocation state. False leaves storage and sharing/cardinality unknown. Omission preserves legacy fresh-context facts; this never replaces missing sampler or identity authority. Metadata-only manual layouts cannot certify cached native keys after the SDK mutates their generation flag during upload.

    OptionalenvironmentBackgroundFormat

    environmentBackgroundFormat?: "rgba8" | "rgba16f" | "rgba32f"

    Owned sharp-background cube color storage, observed from the source's component type and the renderer's RGBA cube factory. The factory inherits component type but does not inherit raw channel count or internal format. Existing cached conversions require an unchanged owned creation tuple; current mutable source properties alone cannot certify those allocations. Changed or unsuccessfully retired conversions set allocationStateKnown false even when this prospective factory format remains reportable. Missing or unsupported output facts leave required cube bytes unknown. This is a host runtime fact, never an author-entered byte estimate.

    environmentSampler?: {

        wrapS: "clamp"
        | "repeat"
        | "mirror";
        wrapT: "clamp" | "repeat" | "mirror";
    }

    Sampling intent of the host's sharp-background conversion. The native factory may first upload a configured mip-linear image with a linear filter, then restore the property without changing its cached upload key. Closure retains configured and factory choices as a conservative union; this does not claim either choice is the currently allocated native key.
