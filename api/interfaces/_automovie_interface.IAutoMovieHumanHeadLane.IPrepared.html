    Interface IPrepared

    Canonical original material and records, before regional composition.

    Body and head consumers borrow the same actual mass/neck and records derived from its closed layout. The complete lane adds only its regional tree, source collection and lip colour curve. This source stage is not a fallback or a successful partial head tree. Requires the same immutable invocation inputs; all records retain calibration-mm meanings. Data performs no work. Full creation reuses the identical canonical source and records without rebuilding them. The caller owns the base, records and transitive source dependencies.

    originals

    • originals(names?: readonly string[]): IAutoMovieHumanHeadComposer.IDefinition

      Call-owned lazy original definitions, independent of complete realization.

      The actual regional builders borrow the identical canonical mass and selected placement context. One definition supplies selected-original observation and complete creation. Failed original attempts stay explicit and no substitute part or successful partial tree is manufactured. Empty requests and unknown-name admission construct no source. Exact top-level requests author only selected factories; their result lists/maps take O(selected sources) to publish. A first complete or known nested/ear request retains the existing whole-catalogue costs; the completed definition itself is subsequently reused. Selected and complete requests reuse identical authored top-level objects and the paired lip contact. Selected definition containers are rebuilt; complete creation borrows the retained complete definition and source map. Only this immutable invocation retains its original definitions and callbacks; no global registry is added.
