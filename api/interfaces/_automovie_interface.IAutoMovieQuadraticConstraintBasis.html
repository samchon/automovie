    Interface IAutoMovieQuadraticConstraintBasis

    An orthogonal factorization of one working set of affine equations aᵢ · x = boundᵢ, as createAutoMovieQuadraticConstraintBasis returns it.

    Each working row is normalized and the normals are factored by column-pivoted Householder QR, [a₁/d₁ … aₖ/dₖ] P = Q R. Rows are identified by their position in the working list the caller passed, not by their row number in the whole program. Only exact structure removes a row: a free equation fixing one variable to zero repeats an earlier one on the same variable, or an all-zero row with a zero endpoint. Any other numerical dependence sets refusal instead of dropping a row. All arrays are new and owned by the caller; on a refusal they may be partial and must not be used.
