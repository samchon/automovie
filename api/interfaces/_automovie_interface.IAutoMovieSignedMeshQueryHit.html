    Interface IAutoMovieSignedMeshQueryHit

    Owned nearest-feature reading from one compiled oriented surface, returned by the query createAutoMovieSignedMeshQuery compiles.

    Vectors use the mesh-local metre frame. The query owns its compiled snapshot; changing these returned vectors cannot alter later readings. A boundary feature on an open sheet has no qualified interior-side classification.
