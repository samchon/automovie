    malleoli

    malleoli: {
        lateral: { height: number; prominence: number; radius: number };
        medial: { height: number; prominence: number; radius: number };
    }

    The malleoli as relief windows on the ankle's column: centre height in lateral malleolus heights (the lateral one is the input's site, 1 by definition; the medial one stands higher, Gray), prominence and radius in mm. Convention, awaiting a relief fit on the references: the cuts read no isolated prominence on the borders' extremes beyond 1 to 4 mm.

    Type Declaration

    • lateral: { height: number; prominence: number; radius: number }

      Lateral-malleolus relief window; its height defines the reference malleolus datum.

      • height: number

        Malleolus centre height divided by the lateral-malleolus height; the lateral centre is 1 by definition.

      • prominence: number

        Malleolus outward relief prominence, millimetres; the retained prior treats this as a construction convention.

      • radius: number

        Malleolus relief-window radius, millimetres.

    • medial: { height: number; prominence: number; radius: number }

      Medial-malleolus relief window, positioned above the lateral datum.

      • height: number

        Malleolus centre height divided by the lateral-malleolus height; the lateral centre is 1 by definition.

      • prominence: number

        Malleolus outward relief prominence, millimetres; the retained prior treats this as a construction convention.

      • radius: number

        Malleolus relief-window radius, millimetres.

    ring

    ring: number

    Height of the ankle ring, the leg's start, per lateral malleolus height.

    Fitted, with no published or measured basis: the ratio that keeps the leg's start at the height the earlier construction gave it, so the leg (AutoMovieHumanLegConstruction, which reads this ring as its lowest section) did not move with the foot's rewrite. It is to be replaced by the ankle girth solved at its own site (the minimum girth above the malleoli, ISO 8559-1), and every column knot at this height with it.
