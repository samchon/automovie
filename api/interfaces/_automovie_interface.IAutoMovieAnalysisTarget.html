    Interface IAutoMovieAnalysisTarget

    One numeric target the production declares for one metric.

    The unit is declared beside the value because a target of 300 against a metric in lux and a target of 300 against a metric in candela are different requirements, and a number alone would let one clear the other.

    A target only narrows a verdict. One that cannot be applied, because its unit disagrees with the metric (target-unit-mismatch) or its key names no metric the study reports (target-key-unknown), is dropped and reported as a run warning rather than treated as satisfied. A target whose metric produced no value reaches the report as that metric's gap instead.

    Keys and units are compared as exact strings with no conversion or alias, so a target in lux does not apply to a metric in lx. A target list is refused before any solver reads it when a key or unit is blank, a value is not finite, a comparison is unknown, or a key repeats.
