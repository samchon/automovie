    Interface IAutoMovieRecoveryCameraMapEstimate

    Conditional three-camera map and sparse fitting evidence in one seed gauge. Only seed-supported landmarks are triangulated in this version; other linked tracks remain explicitly untriangulated. A completed operation is partial with respect to an editable surface, metric scale and unobserved scene geometry.
