    Direct coefficient derivatives in a common closing root/angle coordinate, with finite virtual zero-pole data. The existing coefficients remain the values; absent/different maps select the ordinary station-Hermite boundary. This is a new principal-coefficient interpolant, not a guarantee of original scalar/fullness fidelity between layers.

    OptionalframeSlopes

    frameSlopes?: IAutoMovieLoftSectionFrame

    First physical-station derivatives of the layer's plane component by component: origin in mm/mm, axes in 1/mm. These derivative triples are not positions or unit axes. Matching actual frameSource records own the intermediate frame instead. Otherwise, when both interval layers carry them, the plane is the Hermite of the two planes' components, its axes not renormalised. Shared values and slopes give C1 continuity with the cubic rule; consistent shared frameCurvatures select the quintic rule and give C2 continuity. Without frameSlopes, the rotation Hermite of AutoMovieLoftFrame.interpolate.

    • Defined in packages/interface/src/construction/IAutoMovieLoftChain.ts:208

    OptionalframeSource

    frameSource?: IAutoMovieLoftFrameSource.ISource

    Actual immutable axis and independent value/station-jet snapshot. Equal-value copies preserve it; a changed datum must explicitly remove or re-express it. Callable source records cannot be restored by JSON; rebuild them from the authored tree. Null station jets preserve finite source values but do not qualify that boundary for a regular solid 2-jet.

    • Defined in packages/interface/src/construction/IAutoMovieLoftChain.ts:151

    Optionallift

    lift?: number[]

    Out-of-plane displacement of a spline section along the frame normal v x u (up for a horizontal layer), one value per control point in mm, interpolated over phase by the same B-spline and over station by the same Hermite rule as the coefficients.

    A fitted specimen's sections lie in their planes, so its layers omit it; a shape law that moves an anatomical point across its station (see AutoMovieHumanBodyLaw) writes it. Absent means zero.

    Optionalview

    view?: IAutoMovieLoftChain.IView

    The view box and shoulders the view-to-section operator (AutoMovieViewLoft) drew this layer from; present exactly on layers it emitted from a four-quarter section (a touch/split conic chain's layer has none). The section touches the box at the guide phases 0, pi / 2, pi and 3 pi / 2: the point there is the outline's value on its chart axis (a knot of the section's B-spline), so an audit reads the guide-touch rule on the layers that carry it.
