    Interface IAutoMovieSurfaceCage

    A surface network sampled at one tier: a quad control cage ready for subdivideAutoMovieSurface, with the surface coordinate of every face corner, the per-patch grids and the named rings.

    Within a tier the cage's connectivity, UV layout and coordinates depend only on the network's patch and count declarations, never on the shapes of its sweeps and curves, so every input of one network yields the same topology and only positions change. Every tier addresses the same coordinates, (patch, s, t), so a point bound on one tier is found on another by mapAutoMovieSurfaceTier.
