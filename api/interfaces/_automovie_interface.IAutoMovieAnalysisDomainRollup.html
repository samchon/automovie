    Interface IAutoMovieAnalysisDomainRollup

    One domain's tally inside an analysis report.

    Every submitted run is counted once in runs and then exactly once more, as stale when it read another revision or else as solved, unsupported or notRun, so runs equals the sum of those four. Metric counts come only from current solved runs, and measured metrics that are neither meets nor misses are untargeted and have no field of their own.
