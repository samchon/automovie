    Interface IAutoMovieHumanTrunkSection

    One horizontal section of the trunk's column, canonical left half: the measures the guides and sectors read, at one height, in calibration millimetres in the body frame (forward +X, up +Y, left +Z).

    The front and the back quadrant each lie on zeta^n + xi^n = 1 in normalised coordinates zeta = z / width and xi = (x - middle) / depth, with the section's squareness n per quadrant.
