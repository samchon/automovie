    Interface IAutoMovieDrawingView

    How one drawing is taken from one design.

    A view supplies cut/projection placement, scale, filters, dimensions, authored notes and a pen to a drawing derivation. Geometry comes from the built-environment snapshot, but tessellation, clipping, rounding and unimplemented derivations limit agreement with rendered geometry. The drawing is output; IAutoMovieDesignReference is separately authored evidence, and neither is automatically read back into building source.

    deriveAutoMovieDrawing validates the design first and throws for an invalid one. Its frame gate then requires finite origin/direction/up components, direction and up lengths above 1e-9, an up-cross-normal length above 1e-9, positive finite scale and finite nonnegative depth/overhead when non-null. Duplicate dimension or annotation ids also throw; canonical output encoding can refuse non-finite derived values or invalid Unicode text.

    origin

    origin: IAutoMovieVector3

    World point the cut plane passes through, and the page origin, in metres.

    The normal component places the cut and in-plane components move the page origin. For the usual vertical plan direction only world height changes the plane; an admitted oblique plan direction also makes horizontal origin components affect its cut. Projection labels do not override the supplied direction.

    overhead: number | null

    How far toward the viewer geometry the cut removed is still drawn, in metres, or null to draw none of it; finite and not negative.

    An element wholly on the viewer's side whose closest corner to the plane lies within this band is drawn overhead, the dashed convention floor plans use for beams and wall cabinets above the cut. An elevation cuts nothing and ignores the band.

    spaces

    spaces: string[]

    Logical spaces this view is restricted to, descendants included; empty includes every space.

    Lines, regions and opening marks outside every included space are left out, and an element bound to no space is left out of a filtered view. A boundary that draws its own face is kept when any space it separates is included, and an opening is kept when its host boundary touches one, so a party wall and its door appear on both rooms' sheets.

    An id the design does not declare selects nothing and is reported once as the view-space-filter gap.

    up

    up: IAutoMovieVector3

    Page-up hint; finite, non-zero and not parallel to direction.

    The hint is re-orthogonalized against the view direction, so an author may write the nearest cardinal axis rather than an exact in-plane vector. A plan that writes -Z puts world -Z up the page and world +X to the right; an elevation writes +Y.
