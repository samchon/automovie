    Interface IAutoMovieObjectMotionGate

    Everything gateAuthoredObjectMotions checks one shot's authored object clips against.

    performShot fills it after the performance and coupling compiled, so baked holds every clip the engine produced for the shot and performed every node a synthesized motion drives. The gate reads every field and keeps none of them after it returns.
