    OptionalscoreDucking

    scoreDucking?: { attackFrames: number; gain: number; releaseFrames: number }

    Optional attenuation of music cues around dialogue placements with adopted PCM. Attack precedes each line and release follows it. Their absolute frame anchors are rounded to sample ticks before interpolation. Overlaps use the lowest gain. Only the part inside the film is applied. Omission preserves the existing mix.

    Type Declaration

    • attackFrames: number

      Nonnegative safe-integer film frames for the pre-dialogue ramp.

    • gain: number

      Finite linear music gain during dialogue, in [0, 1].

    • releaseFrames: number

      Nonnegative safe-integer film frames for the post-dialogue ramp.
