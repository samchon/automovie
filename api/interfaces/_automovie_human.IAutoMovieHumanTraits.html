    Interface IAutoMovieHumanTraits

    A beginner's description of a person: sex, age, stature, reference population and build.

    This is an authored parameter description. No converter or statistical expansion is supplied.

    Build traits are normalized authoring offsets: zero denotes the requested reference population's mean for the given sex and age, and the sign states the direction. These offsets do not define a conversion to physical measurements.

    OptionalskinTone

    skinTone?: number

    Skin pigmentation independent of population: 0 is pale (melanin fraction 0.013), 1 is dark (0.43), interpolated logarithmically. Omitted, no pigmentation override is requested; detailed identities can additionally set eumelanin share and haemoglobin. This is a conventional authoring scale, not a clinical phototype. Schema constraints: Minimum: 0; Maximum: 1; retained by Human's schema refinement.
