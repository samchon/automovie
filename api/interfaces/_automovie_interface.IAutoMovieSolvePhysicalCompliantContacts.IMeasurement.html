    Interface IMeasurement

    One positive compliant-contact solve and the actual rounded transfer to each body.

    point is world metres, normal a world unit vector from handle to other, impulse N s and signed separation metres at the supplied native instant. solvePhysicalCompliantContacts emits a new record after applying rounded impulses; recordPhysicalContact maps collider handles to scene endpoints and merges the observation. impulse is the pre-gain solve while appliedImpulse records transferred normal components, zero for a nondynamic side. Handles identify the current world only and are not portable checkpoint identities.
