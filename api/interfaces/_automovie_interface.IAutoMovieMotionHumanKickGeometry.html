    Interface IAutoMovieMotionHumanKickGeometry

    A built kick: the body's carriage, the kicking leg's goal (the ankle, the knee's bend hint and the foot's rotation) and the feet's contact windows, each a pure function of the seconds since the kick's own start, plus what the kick decided. A redirect reads its source's geometry to continue it.
