    Interface IWorkspace

    A fit operation's borrowed source dependencies and exact chain-frame reader. Keep the rig, topology, source/reference poses, mappings and callback dependencies unchanged for this workspace's lifetime. Results borrow the source root and unrelated joints, which must also remain unchanged while the workspace is in use. Release the workspace when that operation ends.

    States input stability, borrowed result members, caller-owned lifetime and the two operations' frames. Fixed source dependencies admit several independent model-metre targets without making the previous answer a new source or continuation seed. The contact re-aim consumer needs only another fit and its actual reached rotation; internal preparation and lazy caches stay private. fit keeps its source's fixed cold/near policy. Explicit continued accepts a deterministic curve owner's candidate seed; it does not certify the cold global winner, curve continuity or current final orientation/contact.

    continued

    • continued(
          target: IAutoMovieVector3,
          near: IAutoMovieSwivelNear,
          observe?: IAutoMovieChainContinuationObserver,
      ): IAutoMovieSeededChainFit

      Evaluate an explicit continuous-curve candidate at the current target. The curve owner supplies a deterministic branch/swivel with positive degree-valued bracket tolerance and verifies current final effector orientation, pole side, ROM, contacts/clearance and branch events. Eligible native two-axis orientation roots first receive actual post-clamp point, rotation, ROM and pole checks. Unsupported or failed roots retain near fitting, whose actual post-clamp shell must pass the ordinary bend residual gate; otherwise the complete cold fit runs on this same source. The original source/root still receives actual ordered admission. An explicit rig uses an empty FK demand; a raw source keeps full authored FK. Only the unchanged fixed source may share successful admission. Invalid seed numbers also decline the candidate and run cold. No last query is retained and no global cold-score equivalence is promised. An optional observer reports actual orientation-root trials/acceptance and near/cold attempts; its events never control physical admission.

    fit

    • fit(
          target: IAutoMovieVector3,
          near?: IAutoMovieSwivelNear,
          incumbent?: IAutoMovieSwivelSeed,
          capture?: orientChainEffector.IReading,
      ): IAutoMovieSeededChainFit

      Fit one target using the original source pose and unchanged search policy. Keep that target's coordinate record unchanged until the fit returns. An optional near replaces the source's cold/near mode for this target only: the fit continues that seed (a later contact re-aim pass continuing the previous pass's answer for a target millimetres away). An optional incumbent (ignored with near) is a seed the caller holds for this swept fit: it only starts the bounded sweep's stop (IAutoMovieFitChainToTargetProps.incumbent), so the answer is the swept fit's either way.

      States model-metre input, fixed source/search meaning and the per-target continuation. Signature only; prepare owns the fit composition. No body is declared here. The signature performs no solve. The producer documents shared preparation and unchanged candidate work. The producer owns invariant sharing. The signature acquires nothing.
