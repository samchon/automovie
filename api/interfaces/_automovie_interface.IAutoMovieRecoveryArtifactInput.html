    Interface IAutoMovieRecoveryArtifactInput

    Generated geometry, its exact coefficient binding and current run observations borrowed by createAutoMovieRecoveryArtifact for one publication snapshot. Counts and memory probes run synchronously; memory updates peaks before the peak record is read. The assembler retains geometry/report references in its result, so publication must observe the same run state and spool identities. Pair counts describe processing and retained coverage separately; none proves source fidelity. started uses the host's monotonic millisecond clock.
