    Interface IBase

    Canonical mass preparation, independent of regional face source success.

    The same record is passed to composition; mass source and neck are not rebuilt. The caller owns the layout, original closures and any requested raw mass loft for its definition lifetime.

    closed

    • closed(): IAutoMovieHumanHeadCanonical.IOutput

      Explicitly request the actual full public-input closure.

      Delegates to the same canonical constraint owner used by production and preserves its selected actual source. A method owns full-source demand while layout, guides and attempt observations remain independent. No property read invokes closure, and a failed attempt rethrows its original value without another source. Performs the actual constraint once on explicit first demand. Subsequent production and inspection calls receive the identical canonical result or original failure. Only this invocation retains the actual selected source and attempt.

      Returns IAutoMovieHumanHeadCanonical.IOutput

    loft

    • loft(): IAutoMovieViewLoft.IResult

      Call-owned lazy raw loft of that identical source, prepared at most once.

      Lofts the exact retained massPart only when a raw or complete geometry consumer requests it. Explicit lazy consumption is separate from original-source admission. It never replaces the source or reports unperformed loft admission as success. The first request performs one engine loft; subsequent requests return the retained result in constant time. Explicit raw consumers borrow the same result; ordinary source-leaf realization receives the actual part independently. Only this call-owned source closure retains a requested loft; there is no global cache.

      Returns IAutoMovieViewLoft.IResult
