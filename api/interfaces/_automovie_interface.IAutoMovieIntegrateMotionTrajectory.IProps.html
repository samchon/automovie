    OptionalrotationDefect

    rotationDefect?: (
        seconds: number,
        q: IAutoMovieQuaternion,
        w: IAutoMovieVector3,
    ) => number

    Optional continuous rotation-defect admission. Receives film seconds, the dense orientation and its actual body angular velocity in rad/s. The pure callback returns a nonnegative error normalized in its own physical units: at most one admits, Infinity rejects. Adaptive dense control checks paired extensions independently of the existing RMS. Requires both q0 and an adaptive tolerance; otherwise admission throws. Smoothness underlies the sampled estimator; arbitrary unsampled history features and a downstream finite-difference observer are not certified. Borrowed numeric records must not be mutated or retained for mutation.
