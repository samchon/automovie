    Optionalsearch

    search?: { from: number; phase: number; to: number }

    Where the engine searches the part's station line for its meeting with the parent (IAutoMovieConstructionSearchSeed): the phase and the shares of the station range walked; absent, phase 0 from the base (share 0) to the apex (share 1), which a dome crosses its parent on.

    Type Declaration

    • from: number

      Start of the seed-search interval as a dimensionless share of the part's station span.

    • phase: number

      Section phase in radians, increasing according to the source curve's orientation.

    • to: number

      End of the seed-search interval as a dimensionless share of the part's station span.
