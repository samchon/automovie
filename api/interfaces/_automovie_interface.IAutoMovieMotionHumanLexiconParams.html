    Interface IAutoMovieMotionHumanLexiconParams

    Open parameters of every installed Human lexicon family and its exported row. A row's export key may differ from its registered action name; HUMAN_LEXICON_FAMILIES pairs them when generating the schema. This map guides the runtime rows. HumanPerformanceParams admits their supplied parameters against the generated schemas before planning.
