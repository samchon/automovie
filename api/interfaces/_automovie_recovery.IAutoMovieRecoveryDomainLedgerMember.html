    Interface IAutoMovieRecoveryDomainLedgerMember

    One declared reconstruction occurrence and its observed processing state. Null stage values mean unpublished observations, not a failed or skipped stage. Delegation preserves this occurrence's identity without borrowing its owner's ranges.

    interface IAutoMovieRecoveryDomainLedgerMember {
