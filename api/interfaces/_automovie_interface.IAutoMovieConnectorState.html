    drive

    drive: "forward" | "reverse" | "still"

    Which way the run is driven while it stands in this state.

    forward runs from IAutoMovieBuiltConnector.from towards IAutoMovieBuiltConnector.to and reverse the other way, so a one-way run may not declare a reverse state. still is a run that is not being driven, such as a stopped car or a switched-off escalator. Validation checks it, but no placement, drawing, or render reads it.
