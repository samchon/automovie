    Interface IAutoMovieMotionHumanRefusal

    A composition the vocabulary refuses to perform, as a value its author can act on: who was to act, which action, which axis of it is at fault, the value given, what would have been accepted, and what to change.

    The author of a composition is a coding agent that never sees the film it asks for until it is built, so a refusal is its only feedback. Each refusal therefore names one axis and one repair, and the same facts are fields, so a program reads them without parsing the message:

    try { new HumanPerformance(input); }
    catch (error) {
      if (error instanceof HumanRefusal) console.log(error.axis, error.feasible, error.fix);
    }

    A refusal is deterministic: it depends on the composition, the bodies and the places, never on the seed. Repair it at the axis it names (move the target, change the value, release the hand, declare the cut); catching it and carrying on performs nothing.

    A law that refuses knows the axis but not always its place in the film, so it may raise a refusal with no performer; the performance locates it (HumanRefusal.locate) before it reaches the author.
