    Interface IAutoMovieDrawingOpeningMark

    One opening as the drawing can see it.

    Every opening whose host boundary touches a space the view includes gets a mark, whether or not the design gave it a shape and whatever the view's element-kind filter says, so a sheet's openings can be compared with the design's by id. Marks are sorted by opening id.

    basis says where the geometry came from, and the answers are not interchangeable. profile is the opening's own void placed on its host boundary's face. fill is the filling element's extent standing in for a void nobody authored, which is the leaf's size and not the hole's. none means the design sizes the opening by neither, and the mark then carries no outline and null sizes.

    polygon

    polygon: IAutoMovieDrawingPoint[]

    The void's own outline on the page for a profile mark, and empty for every other basis.

    A fill mark has no outline because the leaf's extent drawn as the void's shape would put a rectangle on the sheet where the building has no hole. Arc edges are drafted as chords at a fixed angular step; width and height are not computed from these chords.

    • Defined in packages/interface/src/drawing/IAutoMovieDrawingOpeningMark.ts:49

    width

    width: number | null

    Width in metres of whatever basis says was measured, rounded to six decimals, or null when it says none.

    A profile mark measures the void's bounding hull along the host face's local X axis, which is tight for an arc whose chord is parallel to a face axis and larger than the arc for a tilted chord. A fill mark measures the wider of the leaf's world X and Z extents.
