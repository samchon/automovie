    Interface IAutoMovieRigLocalTransform

    An absolute rig transform in the parent frame, without scale. Deterministic rig evaluators supply this borrowed tuple view to applyAutoMovieRigLocals. The transform replaces the previous local pose; it is not a rest-pose delta. The adapter requires exact tuple lengths, finite components and squared quaternion norm within 1e-6 of one before mutating any bone, and writes unit scale.

    IAutoMovieRigidTransform instead uses mutable object components named position/rotation and a frame selected by each physical-profile field. IAutoMovieTransform adds authored scale to object-valued translation/rotation. This read-only evaluator view preserves its tuple representation and fixed parent-frame, unit-scale premise; conversion between these records is explicit. Read-only access does not freeze the producer's arrays, so the producer must keep them stable for the duration of an adapter call.
