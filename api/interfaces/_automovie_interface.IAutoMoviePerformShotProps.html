    Interface IAutoMoviePerformShotProps

    The inputs of performShot: the script, the staged world and the beat's performance, the synthesizer and rig lookups that realize it, and the optional context that sharpens framing, gating and coupling.

    Every optional field states what omitting it does; none changes the shot of a caller that omits it beyond what that field documents.

    OptionalframeFormat

    frameFormat?: { height: number; width: number }

    Delivery raster for the horizontal half of the framing fit. Omitted, or with a non-positive side, a wide subject is fitted to a square frame, which stands back far enough for any raster of that height.

    Type Declaration

    • height: number

      Delivery height in pixels used as the aspect-ratio denominator; the same non-positive-side fallback applies.

    • width: number

      Delivery width in pixels used only through width/height. A side that is not greater than zero selects the square-frame fallback; finite positive dimensions are the caller's premise.
