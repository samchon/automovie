    Interface IAutoMovieRecoverySavedSection

    Caller-bound publication identities for one previously observed physical cut. Coefficients are deliberately absent. The caller verifies the source bytes, registration, selected original ordinal space and saved artifact commitment; matching opaque identities here is not a cryptographic verification. Slab observation independently recuts the source and verifies contour ordinals, address sets and admitted closure. It does not verify a named curve's shape, parameterization, direction, error, degree, rational weights or material phase.
