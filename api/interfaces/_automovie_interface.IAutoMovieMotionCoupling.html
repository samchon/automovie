    The borne body's root frame in the bearer's anchor frame at the coupling's key pose, its legs there and the bearer's stance it was placed on.

    Type Declaration

    • legs: readonly [number, number, number]

      Both legs' hip flexion, knee flexion and hip abduction, degrees: the carry's own, changed least so the bearer's arms reach the holds.

    • position: IAutoMovieVector3

      Metres.

    • rotation: IAutoMovieQuaternion

      Unit quaternion.

    • stance: { depth: number; incline: number }

      The first bearer's stance: its trunk's forward inclination, degrees, shared by the lumbopelvic rhythm, and how far it lowers by bending its knees, a share of a squat's drop in [0, 1]. Upright, both none, changed least so its arms reach the holds.

      • depth: number

        Lowering as a share of the body's squat drop in [0, 1]; zero is the standing alignment.

      • incline: number

        Forward trunk inclination in degrees.
