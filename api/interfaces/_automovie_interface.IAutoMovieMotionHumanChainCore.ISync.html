    Optionallatency

    latency?: Latency

    A delay drawn per performer and added after offset: reaction for a person answering the cue (a command, a shot), shortened by the preparatory word when the track names one (HumanCue.orders), or a stated normal for a deliberate pause (HumanResponse.latency). Keyed by the performer, the synced action's id and latency, so it is the performer's own and no other draw moves. None when absent.
