    Interface IAutoMovieMotionHumanLexiconPursuitParams

    Open parameters of the pursuit lexicon family, keyed by each runtime export name. Omitted keys are fixed by the row before its underlying law plans; the remaining members retain that law's defaults, units and required status. HumanPerformanceParams checks these open inputs using the generated row schema before HumanActionRow resolves fixed values.

    intercept

    intercept: IIntercept

    Head a moving person off: a run to where they will be when the runner gets there, stopping at arm's length of that place (the handing gap of HumanProxemics), not to where they are when it begins.

    The meeting instant is the one at which the run to the person's place at that instant ends at that instant, found by planning the run to where they are at each estimate and taking its end as the next, up to eight times, to within one 24th of a second. Their place is read from their placed actions, so they are composed before the runner. A person the pace does not close on is refused with the last estimate. First pass: one straight run, so the bearing to the person is held only as far as both go straight (Fajen and Warren 2007 describe the curved approach of real interceptions).
