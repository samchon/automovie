    Interface IAutoMovieEnginePerformShotGateContext

    The staged world and lookups performShot builds once and every one of its input gates reads.

    performShot creates one per call after reading its inputs, and passes it to the action, target, camera, blocking and overlap gates, so each gate judges an action against the same tables and reports into the same collector. The lookups are read-only for the gates; only out is written.
