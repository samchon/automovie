    Interface IAutoMovieFormationLodInput

    Inputs to the deterministic automatic formation LOD selector.

    selectFormationLod scales distance by 24 / max(1, projectedPixels) and takes the first tier whose maxDistance is null or covers that value, the last tier when none does. Production design validation guarantees tiers in strictly ascending maxDistance with only the final tier unbounded; the selector relies on that order without rechecking it and throws on an empty list.
