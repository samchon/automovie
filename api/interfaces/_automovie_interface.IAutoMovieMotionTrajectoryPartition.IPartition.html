    Interface IPartition

    Numeric interval ownership, with all times in seconds.

    Describes exact-end lookup, strict rejected-leaf bisection and explicit release. Contains only numerical time boundaries of one finite forward integration interval, never physical state or admission verdicts. Shooting owns the object and the adaptive stepper alone consumes end/split; clear releases the mesh on every exit. No trusted success flag, estimated shape or unconstrained output storage is exposed.
