    Interface IAutoMovieRecoverySupportLoft

    Source-independent finite-view support approximation with editable dimensions. Cubic support offsets and oriented planes generate a convex section hull; they do not establish that the observed physical sections were convex. Fitting and pixel uncertainty mean this is not a certified outer enclosure. Width/depth scale X/Z about the frame origin; height scales about the first Y.
