    Interface IAutoMovieSurfacePoint

    A point of a surface rig that is written per pose: a node, a sweep sample or a curve's control point. rigAutoMovieSurfaceNetwork creates these records and rigAutoMovieSurfaceCurve reads their current writers and probes. Sweep-node records are resolved during registry finalization; reading their placeholder writer before that throws.

    probe

    probe: { rig: IAutoMovieSweepRig; slot: number } | null

    For a point on a sweep, the sweep's rig and the probe slot of its normal there; otherwise null.

    Type Declaration

    • { rig: IAutoMovieSweepRig; slot: number }
      • rig: IAutoMovieSweepRig

        Shared sweep rig, refreshed before curve update. Its probe uses the finalized geometric sampling cell, or a zero cell for observation-only nodes.

      • slot: number

        Probe ordinal, addressing six scalars at 6*slot: unit normal XYZ then spine derivative XYZ in metres per normalized u. Null probe means the point has no sweep tangent-plane constraint.
