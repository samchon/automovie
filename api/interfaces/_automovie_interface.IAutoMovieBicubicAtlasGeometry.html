    Interface IAutoMovieBicubicAtlasGeometry

    A deterministic atlas of complete bicubic Bernstein patches.

    Shared coefficient indices, rather than coordinate equality, declare shared corners and complete cubic edges. Reversing an edge reverses its four indices. Optional canonical bindings explicitly construct a side from one saved cubic interval before derivative bounds and tessellation; they define the recipe's field rather than repairing a generated mesh. Producers report any difference from an earlier fitted coefficient field. Hanging endpoints share position identity through these intervals, while analytic normal fans may stay separate. This recipe supplies a field, not its original observations or source mesh. Parameter continuity, injectivity and source fidelity remain independent qualifications. Resource exhaustion retains an explicit partial realization.
