    Interface IAutoMoviePatternQuantities

    The take-off one pattern run produces.

    Totals are sums over the zone records. consumedArea charges each occurrence its full module area, so wasteArea includes area an exclusion punched out. jointArea counts every uncovered square metre of the net region, joints and any area the generator left empty alike, so jointLength is the joint length only when the program tiles the region.
