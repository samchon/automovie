    Interface IAutoMovieMotionHumanWalkGait

    A gait the stepping plan runs: its speed, its step and swing, its pelvis and its arms, and how it keeps time.

    Speed and step are given for any body: the speed as a Froude number, v² / (g l) with l the hip height (Alexander 1984), and every length in hip heights. A walk, a run and a named style of either are each one of these, read by walk.locomote.
