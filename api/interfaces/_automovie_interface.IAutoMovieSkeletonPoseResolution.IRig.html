    • joint(
          joint: IAutoMovieJointPose,
          operation?: IAutoMoviePoseResolution,
      ): IAutoMovieQuaternion

      Admit one current clinical joint against the rig's fixed axes and frame and return a fresh quaternion. Every coordinate of a record the rig has not admitted before is checked; a record it already admitted is a value, read again as the value it was admitted as, since a joint record is not edited after admission.
