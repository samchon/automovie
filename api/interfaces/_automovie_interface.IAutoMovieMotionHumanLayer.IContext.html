    Optionalresolution

    resolution?: () => IAutoMoviePoseResolution

    Exact FK metadata borrowed only during this synchronous layer apply. Call lazily for the same unchanged body; neither the reader nor this getter may be stored in a plan, output posture or callback. The host revokes its borrowed source on return or throw; a retained getter then creates an independent fresh reader rather than retaining the source.
