    Interface IAutoMovieConnectorLanding

    One further space a run serves at a point along its own route.

    Where the stop is on the route is stated; whether that point falls inside the space it serves is not checked, because a run may serve a space it only reaches the edge of, as a facade ladder leaves a storey from outside the storey's own volume. Where a carriage stands is checked instead, through IAutoMovieCarriageValue.serves, because a carriage is a body with a place rather than a station on a centreline.
