    Interface IAutoMovieMeshCrossingQuery

    Strict crossing queries over one immutable resident surface, prepared by createAutoMovieMeshCrossingQuery. Both meshes share the snapshot's metre frame. The callable reports original first/second triangle ordinals in the established candidate order; crosses answers only whether a witness exists. withPositions creates a separate current-coordinate snapshot with the same copied source addressing and hierarchy partition. None of these operations supplies penetration depth, containment or swept proof.

    withPositions

    • withPositions(positions: readonly number[]): IAutoMovieMeshCrossingQuery

      Snapshot all current XYZ coordinates in the queries' shared metre frame using the original copied index run and exactly its original scalar count. Every source triangle remains present, including zero-area triangles that become valid or degenerate at another pose. Coordinates may come from rigid, affine or independently articulated placement; the same world-space strict predicates and numeric cutoffs apply to their actual supplied values.

      Copies all used corners and validates every scalar, including unused vertices. Wrong cardinality, holes and nonfinite values throw without changing this query. Source indices are immutable; changing index layout or vertex count requires createAutoMovieMeshCrossingQuery. Later input/output edits cannot change this or another snapshot. A refit may retain a less efficient partition than a fresh build, but never uses old geometric bounds.
