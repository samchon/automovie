    Interface IAutoMovieDesignReference

    One observed design reference: the bytes, how they are read, what was seen, what was proposed, and what remains undecided.

    This record is evidence and only evidence. The design source of truth stays the TypeScript building source; a reference is cited by it through IAutoMovieDesignEvidence and never merged into it. A plan image therefore cannot quietly become a wall, because nothing here is a wall.

    Current asset bytes, their digest, container family and provenance use require explicit host verification; the production byte/ledger gate is retired.
