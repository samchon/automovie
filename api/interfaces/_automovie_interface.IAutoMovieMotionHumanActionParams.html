    Interface IAutoMovieMotionHumanActionParams

    The parameters of every action by its name: the one table that types a chain's act(name, params) and each vocabulary method, so a call names an action and the type checker supplies and checks its parameters.

    Each member is the law's own IParams; nothing is restated here. Its keys are exactly HumanActionName: HumanChain.act indexes it by the name, so a name without a member, or a member without a name, fails to compile.
