    interactionObservations?: {
        afterMm: number;

        group: number;
        pass: number;
        qualified: boolean;
        refinements: number;
        side: "before" | "after";
    }[]

    Pass-local source-leaf interaction work before shared-boundary emission. Refinements count contact-driven leaf splits; chordPairs and exactOrientationTests count actual visited pairs and exact determinant calls. Timing is null without observeWork. Pass qualification is separate from retained historical diagnostics.

    Type Declaration

    • afterMm: number

      Upper saved cut coordinate for this interaction pass, millimetres.

    • beforeMm: number

      Lower saved cut coordinate for this interaction pass, millimetres.

    • chordPairs: number

      Number of chord pairs actually visited by this pass, not the Cartesian-product population.

    • diagnostics: string[]

      Ordered local interaction qualifications and failure explanations; empty means no diagnostics were published for the pass.

    • elapsedMs: number | null

      Observed wall-clock duration in milliseconds, or null when observeWork was omitted or false.

    • exactOrientationTests: number

      Number of exact determinant calls made while qualifying this pass.

    • group: number

      Zero-based incidence group whose source-leaf interactions were inspected.

    • pass: number

      Producer's pass ordinal for this group's contact-driven refinement work.

    • qualified: boolean

      Whether this pass's interaction checks succeeded; older diagnostics may remain even after a qualified pass.

    • refinements: number

      Number of actual contact-driven source-leaf splits in this pass.

    • side: "before" | "after"

      Which saved section supplied the boundary leaves inspected in this pass.

    Actual retained generated triangles, addressed by zero-based mesh triangle ordinal and source-free incidence group. Omission means this kernel did not publish ownership; it never authorizes inferred attribution.

    Type Declaration

    • afterMm: number

      Upper saved cut coordinate of the owning interval, millimetres.

    • beforeMm: number

      Lower saved cut coordinate of the owning interval, millimetres.

    • eventNames: string[]

      Declared critical-event identities attributed to these retained triangles; empty means no named event attribution.

    • firstTriangle: number

      Zero-based first retained triangle in mesh.indices, measured in triangles rather than scalar index entries.

    • group: number

      Zero-based independently emitted incidence-group ordinal within this interval.

    • kind: "strip" | "cap"

      Strip joins two incident boundaries; cap belongs to an explicitly declared regular extremum terminal.

    • triangleCount: number

      Number of consecutively retained triangles belonging to this source-free incidence group.

    stripObservations?: {

        beforeMm: number;

        qualified: boolean;
    }[]

    Source-free strip qualification and work observations. A finite emitted candidate remains displayable when topology/link/orientation qualification fails; qualified does not certify injectivity, C1 or visual quality. Timing is null unless observeWork was requested.

    Type Declaration

    • afterMm: number

      Upper saved cut coordinate of the strip interval, millimetres.

    • beforeMm: number

      Lower saved cut coordinate of the strip interval, millimetres.

    • diagnostics: string[]

      Local strip-search and qualification explanations; finite emitted candidates can coexist with failed qualification.

    • dpCalls: number

      Four-state DP solves for distinct forbidden-transition conditions, including infeasible solves.

    • elapsedMs: number | null

      Actual strip admission, construction, search and emission time, milliseconds; null without explicit observeWork.

    • expandedConflicts: number

      Popped candidates that failed qualification and generated alternative branches.

    • group: number

      Ordinal of the independently emitted group in this interval.

    • m: number

      Second oriented input-walk node count under the same convention.

    • n: number

      First oriented input-walk node count after slit expansion, including repeated sheet occurrences.

    • peakQueue: number

      Maximum queued feasible candidates, excluding the currently popped candidate.

    • qualified: boolean

      Whether the emitted candidate passed the strip topology, link and orientation checks; not an injectivity or C1 certificate.
