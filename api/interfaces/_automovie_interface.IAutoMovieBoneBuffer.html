    Interface IAutoMovieBoneBuffer

    Each bone's rigid motion from rest to the current pose in arrays, from bufferAutoMovieBones, refreshed per pose without allocation.

    Bone b carries a point p to P_b + Q_b R_b^-1 (p - O_b) and a direction by Q_b R_b^-1 alone, the transform createAutoMovieBoneMotion gives. Before the first update, and after reset, every motion is the identity, applied as an exact copy.
