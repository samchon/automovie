    Interface IAutoMovieProductionVideoProfile

    The exact H.264-in-MP4 picture profile one video deliverable must carry, resolved from its authored raster and frame rate.

    resolveProductionVideoProfile builds it, and assertProductionVideoProfile refuses a probed file that differs from it. Raster and rate vary per deliverable; brands, matrix, pixel aspect and color are fixed literals of the one profile the normalizer writes.

    color

    color: { fullRange: true; matrix: 1; primaries: 1; transfer: 13 }

    ITU-T H.273 color code points the track's nclx color box must declare: BT.709 primaries (1), sRGB transfer (13), BT.709 matrix (1), and full range.

    Type Declaration

    • fullRange: true

      Encoded sample values use the complete integer code range.

    • matrix: 1

      BT.709 matrix-coefficient code point.

    • primaries: 1

      BT.709 primaries code point in the nclx declaration.

    • transfer: 13

      sRGB transfer-characteristic code point.
