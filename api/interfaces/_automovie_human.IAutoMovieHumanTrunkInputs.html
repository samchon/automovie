    Interface IAutoMovieHumanTrunkInputs

    What the trunk and shoulders read: the person's tapes, courses and controls in calibration millimetres (the public input times the stature scale), the one fixed input every trunk piece is built from.

    Each tape is an ISO 8559-1:2017 girth taken at its site on the skin; each course a taut surface length between its landmarks, defined in docs/sources/iso-8559-1-2017-landmarks.md.
