    Interface IAutoMovieServiceSchematic

    One system reduced to the drawing an operator can actually read.

    The schematic derives plan geometry and totals from the supplied graph; it neither proves design intent nor asserts that validation accepted it. serviceNetworkSchematic currently has no production consumer; validation is not a precondition enforced by this record or that producer.
