    Interface IAutoMovieBuiltSupportSweepReport

    What one whole-building support sweep measured, not only what it found.

    The census is part of the answer. An empty finding list from a sweep that resolved nothing reads exactly like a clean building, so the counts travel beside the findings and a caller compares them.

    Every measured body lands in exactly one of grounded, borne and floating, judged by the underside of its world box. The ground height is the sweep's own groundY argument, 0 by default, not anything read from the environment.
