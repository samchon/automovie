    span

    span: readonly [number, number] | null

    The run of the tool's edge along its axis, metres behind the working point: its end by the point, then its end by the hand, read from the edge affordance's centre and length (a sword's true edge, the length of its blade). Null when the tool declares no such edge: its working point is then all that strikes (a racket's sweetSpot, a club's strike, the bare hand's grip).
