    Interface IAutoMovieMotionHumanLexiconArcheryParams

    Open parameters of the archery lexicon family, keyed by each runtime export name. Omitted keys are fixed by the row before its underlying law plans. Release rows can also transfer one staged prop onto an authored continuation. HumanPerformanceParams checks these open inputs using the generated row schema before HumanActionRow resolves fixed values.
