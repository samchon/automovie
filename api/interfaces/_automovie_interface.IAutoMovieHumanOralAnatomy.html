    Interface IAutoMovieHumanOralAnatomy

    One person's oral anatomy in the registered figure frame: +X forward, +Y up and +Z left. Lengths and coordinates are millimetres; cant is the dimensionless rise per backward millimetre. Contact samples use normalized half-width shares, not angular phase.
