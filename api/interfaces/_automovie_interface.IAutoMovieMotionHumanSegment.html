    Interface IAutoMovieMotionHumanSegment

    One scheduled and planned human action with its law, context, film placement and optional transition from another segment. Performance evaluation and motion audits share this identity.

    interface IAutoMovieMotionHumanSegment {
        context: IAutoMovieMotionHumanActionContext<never>;
        end: number;
        entry: number;
        entryTime: number;
        id: string;
        incumbents?: Readonly<
            Partial<
                Record<
                    "leftArm"
                    | "rightArm"
                    | "leftLeg"
                    | "rightLeg",
                    IAutoMovieSwivelSeed | null,
                >,
            >,
        >;
        index: number;
        law: IAutoMovieMotionHumanActionLaw<never>;
        legs?: {
            at: number;
            joints: readonly IAutoMovieJointPose[];
            seeds: Readonly<
                Partial<Record<AutoMovieHumanLimb, IAutoMovieSwivelSeed | null>>,
            >;
        };
        name: AutoMovieMotionHumanActionKey;
        params: object;
        plan: IAutoMovieMotionHumanActionPlan;
        start: number;
        transition?: {
            blend: number;
            cut: number;
            kind: "phase"
            | "inertialize"
            | "redirect";
            offset?: (elapsed: number, pose: IAutoMoviePose) => IAutoMoviePose;
            source: IAutoMovieMotionHumanSegment;
        };
    }

    The legs' fit of a leaf resolve inside the plan's legs-still window (IAutoMovieMotionHumanActionPlan.legsStill): the plan second it was read at, the legs' joint records it gave and their seeds, which every later leaf resolve in that window keeps in place of fitting the legs again; absent until then, and released when the person's memos are forgotten.
