    Interface ICurve

    An immutable generating owner, not boundary Taylor coefficients or a fit.

    Prepared surfaces retain this curve and its dependencies by reference. Point, phase and jet query the same local function at station millimetres and its original clock. Keep all three and their domains unchanged while readers exist. Foreign callback/getter exceptions propagate.
