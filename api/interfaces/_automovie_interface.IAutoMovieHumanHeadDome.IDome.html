    Interface IDome

    A dome's generating frame and positive dimensions in calibration mm.

    Separates the caller's frame, footprint, rise, profile and shoulder from the optional host-curvature estimate. A single record supplies the cap source. Contains no person selector, reference target or join-driven shape override. Documents each field's units, orientation and optional default. A data contract chooses no algorithm. A data contract coordinates no work. A data contract owns no runtime resource lifecycle.

    host?: number | IHost

    Explicit parent-plane datum or numeric host radius, calibration mm. A datum queries native curvature in its actual frame and radial direction. The base sinks by the sagitta estimate e^2 / (2 R) of the longest half extent e; absent, R is e. A supplied local radius or size proxy is not a certified least principal radius over the complete footprint.
