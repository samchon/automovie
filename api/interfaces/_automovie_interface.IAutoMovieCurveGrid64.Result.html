    Complexity and degeneracy observations, not acceptance criteria.

    Type Declaration

    • commonSpans: number

      Number of intervals in the union of all normalized course span boundaries.

    • courses: number

      Number of supplied generating cubic courses.

    • evaluatedSpans: number

      Number of common course spans whose tensor station family was actually constructed during ordered sampling.

    • inputSpans: number

      Sum of original cubic span counts across all input courses.

    • isolatedVertices: number

      Subset of unresolved normals with no incident emitted triangle.

    • minimumTriangleAreaMm2: number

      Smallest retained triangle area in square millimetres; remains Number.MAX_VALUE if no triangle was retained.

    • nonfiniteNormalSums: number

      Subset of unresolved normals whose accumulated length is nonfinite.

    • omittedZeroAreaTriangles: number

      Proposed faces omitted when their generated cross-product magnitude was zero or nonfinite.

    • triangles: number

      Actual retained triangle count in the output index buffer.

    • unresolvedVertexNormals: number

      Generated vertices with zero or nonfinite accumulated normals, retained with zero normal.

    • vertices: number

      Actual generated mesh vertex count, including boundary vertices without a retained incident triangle.
