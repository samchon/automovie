    Interface IAutoMovieRealizeShotContractProps

    What realizeShotContract grades: one shot contract against the compiled artifacts that claim to realize it.

    Two callers build it at two moments. compileDefinedShot passes the direct source-stage output with production: null, a raster in frameFormat, and a skeleton lookup because no builder-owned models exist yet. AutoMovieProductionBuilder passes the materialized source with the full production, whose models carry every rig. Every field is read only; the grade never mutates the contract or the artifacts.
