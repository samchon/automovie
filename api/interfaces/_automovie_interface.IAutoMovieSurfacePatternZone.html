    Interface IAutoMovieSurfacePatternZone

    One area of the host face filled by one module program.

    Every module the generator returns is clipped to region, so a zone owns exactly the pieces inside it, and a neighbouring zone meets it along a shared border that the neighbour scan measures across. An occurrence of this zone is identified as <zone id>/<module id>.

    reach

    reach: { u: number; v: number }

    How far in metres a generated module may reach from its cell origin.

    The lattice is enumerated wide enough that every cell whose modules could touch the region is visited, which is only knowable if the author states the reach. A module with a corner beyond it is refused with a throw rather than silently dropped at the region's edge.

    Type Declaration
