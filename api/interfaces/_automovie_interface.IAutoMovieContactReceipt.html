    Interface IAutoMovieContactReceipt

    One contact episode, shared by geometric measurements and solved performance.

    Times are film seconds and points are world metres. A geometry-only result carries null impulse; the solver supplies completed-step measurements, so a reader must select samples no later than its inspection time. The receipt records what its producer measured rather than certifying continuous contact between samples. Episode aggregation and physical contact sampling own these values; this data type performs no admission.
