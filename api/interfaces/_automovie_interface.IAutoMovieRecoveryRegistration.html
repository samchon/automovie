    Interface IAutoMovieRecoveryRegistration

    Caller-declared registration of already evaluated indexed source triangles. Container inspection cannot establish these facts. A host loader applies node transforms, evaluated deformation and unit conversion before this handoff. The recovery package checks structure and finite values, not the truth of an unknown pose or visibility mask. Unknown facts belong in uncertainty rather than guesses.
