    Interface IAutoMovieCameraIntent

    One frame span's directorial intent for framing, camera movement and lens settings.

    A downstream host can read the lens marks independently of the camera path. The scene camera's fovY remains the geometric field of view.

    interface IAutoMovieCameraIntent {
        focalLength: number | null;
        focus: IAutoMovieVector3 | null;
        focusPull?: { end: number; start: number; to: IAutoMovieVector3 };
        framing: "wide" | "full" | "medium" | "close";
        move: "static" | "follow" | "orbit" | "push-in" | "truck" | "whip";
        start: number;
    }
