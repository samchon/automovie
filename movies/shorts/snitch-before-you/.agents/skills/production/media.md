# Media and generation records

Use this resource when saving a generated or acquired file, a pipeline output, or the request that produced a generated file. Research originals stay under [research](../story/planning/research.md).

Commit every image and generation request. Never commit audio or video; they are too large for Git, so they gather in the ignored `media/` folders below, and the committed `media/manifest.json` and request records identify and restore each file (source URL or request, license, content hash, tool, model and seed).

| Location, when used | Owns |
| --- | --- |
| `docs/prompts/<purpose>/<descriptive-name>.md` | Generation requests and the receipts that identify their results |
| `media/diffusion/images/<domain>/` | Images generated by external models, at the settings record's domain path, including the canon character, place and object images the records embed |
| Ignored `media/diffusion/audios/`, `media/diffusion/videos/` | Audio and video generated by external models (diffusion, speech, music), identified by their request records |
| `media/acquired/images/`; ignored `media/acquired/audios/`, `media/acquired/videos/` | Third-party production material such as sound libraries, and research footage |
| Ignored `media/automovie/<film>/` | What this production's pipeline makes for one film: `frames/` debugging stills and frame sheets, `videos/` renders, segment clips and capture reports, `audios/` converted cues and mixed soundtracks |
| `media/manifest.json` | Source, license, digest and restoration of every ignored media file |
