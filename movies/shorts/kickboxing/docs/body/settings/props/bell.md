# Bell

## Form {#form}

### Heard only {#heard-only}

The timekeeper's bell sits outside the ring and is never seen; only its clear ring is heard.

## Use {#use}

### Start and end {#start-end}

It rings once to open the round and once as the match-ending bell after the knockout is declared.

## State changes {#state}

### None {#none}

N/A: the bell does not change.
