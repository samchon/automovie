# Project ownership and customization

Use this resource when syncing instructions, changing the layout or adapting the production's organization.

## Sync and ownership

Package upgrades never rewrite this production. Authorized AutoMovie CLI sync updates generated routers and bundled task resources while preserving contracts, configuration, project decisions, content and proof. Inspect its check result before applying; the installed CLI's README or `automovie --help` owns the invocation and baseline handling. Stored instruction digests detect local conflicts, and differing legacy instructions need their declared prior baseline. In a workspace the shared instructions, their `.automovie/scaffold-state.json` and their sync belong to the workspace root, never to one production. Keep custom criteria and decisions with their production owners. Reusable checking belongs to installed `@automovie/evidence`; adapting paths, language or tools preserves the route's duties and actual relationships.

## Changing the layout

When changing a layout, keep selectors, imports, commands, links, identities, and actual consumers aligned. Update source and media answers through [their evidence method](../evidence/answering.md); changes touching narrative answers or closed reviews follow [upstream repair](../story/correction/repair.md).
