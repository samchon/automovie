# 에른스트 폰 파엘

## 에른스트 폰 파엘 {#ernst-von-pfuel}

**정의·범위**

풀과 혼동하기 쉬운 프로이센 장군의 신원과 별개 관력을 식별한다. 작품의 채택 범위는 아래 이차 요약의 값까지다.

**확정 내용**

에른스트 폰 파엘(Ernst von Pfuel,1779~1866)은 프로이센 장군이고1848년6주간 총리였으며 군사 수영 학교를 세웠다고 기존 이차 요약은 쓴다. 러시아에서 복무한 카를 루트비히 폰 풀과는 다른 사람이다.

**참조·미결**

Sources: [Ernst von Pfuel](https://en.wikipedia.org/wiki/Ernst_von_Pfuel) 기존 정전이 사용한 위키백과 단서다. 생몰·총리 재임·수영 학교를 이번 이행에서 별도의 일차 자료로 확인한 것은 아니며 풀의 관력으로 옮겨 쓰지 않는다.
