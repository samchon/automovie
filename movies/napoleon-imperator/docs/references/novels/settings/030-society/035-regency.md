# 섭정법

## 섭정법 {#regency}

**정의·범위**

섭정법은 조지 3세의 병으로 1811년 초에 왕세자에게 제한된 권한을 주었다.

**확정 내용**

조지 3세의 병이 1810년 말 재발하자 의회가 섭정을 세웠다. 섭정법은 1811년 2월 4일 또는 5일에 의회를 통과했다는 서술이 갈리고, 2월 5일 위임장으로 재가되었으며, 왕세자는 2월 6일 선서했다. 세 일이 사흘 안에 있어 하류는 통과, 재가, 선서의 순서를 지켜 쓰고 통과와 재가를 같은 날의 장면으로 써도 된다.

퍼시벌의 법안은 섭정의 귀족 서임과 관직·연금 수여를 제한했다. 제한은 12개월, 곧 1812년 2월까지로 왕의 회복을 기다리는 기간이었다. 1788~89년의 앞선 섭정 위기가 모형이었다는 서술은 이 정전이 직접 받치지 못해 쓰지 않는다.

막내딸 아멜리아가 1810년에 죽자 왕의 병이 도졌다고 하며, 하류는 "막내딸의 죽음 뒤 병이 도졌다고 전해진다"로 쓰고 날짜는 1810년 말까지만 쓴다. 섭정 결의안의 표결 수는 쓰지 않고 "의회가 제한을 붙여 가결했다"로만 쓴다. 왕세자가 제한에 불만이었고 내각 교체를 꾀했으나 퍼시벌이 총리로 남았으므로, 하류는 "퍼시벌 내각이 그대로 이어졌다"로 쓴다.
