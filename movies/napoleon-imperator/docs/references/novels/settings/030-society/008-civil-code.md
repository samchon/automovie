# 통령·제정기의 법전

## 민법전 {#civil-code}

**정의·범위**

민법전은 평등과 가장의 권위를 함께 세웠다.

**확정 내용**

『프랑스인의 민법전』은 1804년 3월 21일(공화력 12년 방토즈 30일)에 공포되었고, 이 작품에서 통치자 나폴레옹의 가장 큰 장면의 재료다. 1800년 8월 12일 보나파르트가 초안을 맡길 위원회를 지명했고 트롱셰와 포르탈리스와 비고 드 프레아므뇌와 말르빌이 기초했다. 국무원은 이 법을 본회의에서 107번 의논했고 55번은 보나파르트가 의장을 맡았다(나폴레옹 재단). 그는 법전을 직접 기초하지 않았지만 그 절반 넘게를 주재했다. 국무원의 준비 회의는1801년7월17일부터1804년3월17일까지로 쓰며,1800년 위원회 임명과는 다른 절차의 시점이다.

법은 모든 시민이 법 앞에 평등하다고 정했고 이혼을 인정했으며, 아들과 딸, 장남과 차남의 구별 없이 같은 몫으로 상속하게 하고 소유권을 가장 절대적인 방식으로 보호했다. 동시에 남편은 아내에게 보호를, 아내는 남편에게 복종을 빚지고, 아내는 남편의 허가 없이 소송을 하지 못하며, 부권은 결혼 중 아버지만 행사한다. 이 두 얼굴이 이 작품이 같은 인물의 일로 쓰는 법과 제도의 모순이다. [상법](#commercial-code-1807)과 [형법](#penal-code-1810)은 별개 법전이다.

나폴레옹이 이 법을 자기 업적보다 오래 갈 것으로 여겼다는 말을 나폴레옹 재단이 전한다. 세인트헬레나에서 "나의 참된 영광은 마흔 번의 전투를 이긴 것이 아니다. 워털루가 그 승리의 기억을 지울 것이다. 아무것도 지우지 못하고 영원히 살 것은 나의 민법전이다"라고 했다는 것이다. 재단은 이 말에 기록자를 달지 않고 이 한 형태만 싣는다. 하류는 이 형태를 따옴표로 인용할 수 있으나, 회고로 전해지는 말이므로 "전해진다"로 쓴다.

**참조·미결**

Sources: [21 mars 1804](https://www.herodote.net/21_mars_1804-evenement-18040322.php) 법안의 국무원 논의와 보나파르트의 의장을 쓴다. [Le Code civil, 21 mars 1804: naissance, principes et postérité](https://www.napoleon.org/enseignants/documents/le-code-civil-21-mars-1804-naissance-principes-et-posterite/) 1800년 8월 12일 위원회의 지명, 107번의 의논과 55번의 보나파르트 의장, 1804년 3월 21일 공포, 법 앞의 평등과 이혼의 인정을 쓴다. [La promulgation du Code civil des Français](https://www.napoleon.org/histoire-des-2-empires/dossiers-thematiques/la-promulgation-du-code-civil-des-francais-21-mars-1804/) 세인트헬레나에서 나폴레옹이 했다고 하는 "나의 참된 영광" 말을 쓴다. [Code civil des Français 1804](https://fr.wikisource.org/wiki/Code_civil_des_Fran%C3%A7ais_1804/Texte_entier) 1804년판의 전사로 제213조의 남편의 보호와 아내의 복종, 제215조의 아내의 소송, 제373조의 부권, 제544조의 소유권, 제745조의 균등 상속을 쓴다. [Le Code de commerce](https://www.napoleon.org/histoire-des-2-empires/dossiers-thematiques/le-code-de-commerce-un-remaniement-necessaire-des-regles-de-commerce/) 상법이 1807년 9월 15일 공포되어 1808년 1월 1일 시행되었다고 쓴다. [Le Code pénal de 1810](https://www.napoleon.org/histoire-des-2-empires/dossiers-thematiques/le-code-penal-de-1810/) 형법이 1810년 2월 22일 공포되었다고 쓴다.

## 1807년 상법 {#commercial-code-1807}

**정의·범위**

상법의 공포와 시행 시점을 식별한다. 민법전의 공포일과 구별한다.

**확정 내용**

상법은1807년9월15일 공포되어1808년1월1일 시행되었다.

**참조·미결**

Sources: [Le Code de commerce](https://www.napoleon.org/histoire-des-2-empires/dossiers-thematiques/le-code-de-commerce-un-remaniement-necessaire-des-regles-de-commerce/) 기존 정전이 채택한 공포·시행의 해설이다. 상법 전체 조문의 적용을 이 날짜 기록만으로 확장하지 않는다.

## 1810년 형법 {#penal-code-1810}

**정의·범위**

형법의 공포 시점을 식별한다. 민법전·상법의 효력이나 처벌 조문을 대신 정하지 않는다.

**확정 내용**

형법은1810년2월22일 공포되었다.

**참조·미결**

Sources: [Le Code pénal de 1810](https://www.napoleon.org/histoire-des-2-empires/dossiers-thematiques/le-code-penal-de-1810/) 기존 정전이 채택한 공포 해설이다. 새로 형벌이나 시행일을 추정해 채우지 않는다.
