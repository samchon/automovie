# 방돔 기둥

## 방돔 기둥 {#vendome-column}

**정의·범위**

방돔 기둥은 1806년 1월 1일 칙령으로 서 1810년 8월에 낙성되었고 입상은 1814년에 내려졌다.

**확정 내용**

1806년 1월 1일 칙령이 아우스터리츠 뒤 대육군을 기리는 기둥을 정했고 건축가는 공도앵과 르페르다. 공사는 1806년 8월 25일 시작해 1810년 8월 15일 끝났고, 재단은 높이를 42미터, 나선 부조의 길이를 280미터라 쓴다.

돌에는 청동판 425개를 덮었다. 청동은 러시아와 오스트리아에서 빼앗은 대포 약 1200문에서 얻었다고 재단이 쓰나, 영어 위키백과는 아우스터리츠에서 실제로 빼앗은 대포가 180문뿐이라며 부풀린 수로 본다. 대포의 수가 갈리므로 하류는 수를 쓰지 않고 "빼앗은 대포의 청동"으로만 쓴다.

꼭대기의 로마 복장 입상은 쇼데가 만들었다. 이 입상은 1814년에 연합군이 내렸다. 기둥은 이 작품의 시대 뒤인 1871년 파리 코뮌 때 쓰러져 1875년에 다시 세워졌다.

**참조·미결**

Sources: [Colonne Vendôme](https://www.napoleon.org/magazine/lieux/colonne-vendome-paris) 재단의 글로 1806년 1월 1일 칙령, 공도앵과 르페르, 42미터와 부조 280미터, 청동판 425개, 대포 약 1200문, 1806년 8월 25일 착공과 1810년 8월 15일 완성, 1814년 연합군의 입상 철거, 코뮌 때의 쓰러짐과 1875년의 재건립을 쓴다. [Vendôme Column](https://en.wikipedia.org/wiki/Vend%C3%B4me_Column) 위키백과를 단서로만 쓰며 아우스터리츠에서 실제로 빼앗은 대포가 180문이라는 서술을 싣는다.
