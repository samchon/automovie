# Episode 1 runtime

The current result is a running direct 3D prototype, not an accepted finished episode. [Independent review round 1](episode-one-review-1.md) records the complete failed judgment and protected behavior. Only Napoleon episode 1 is in this runtime; it does not render another episode or production.

From this production directory, `pnpm dev` starts the interactive viewer at `http://127.0.0.1:5187/`. Play follows the retained PCM media clock; pause, the timeline, scene selection and the inspection-camera slider use the same absolute-time evaluator. “Authored camera” restores the delivered view. A missing fixed film/audio input is an error rather than a generated playback substitute.

`pnpm capture --probe` rebuilds the capture runner and collects three samples per shot, reverse-seek pixel comparisons and real interactive-control observations. `pnpm capture` rebuilds the same runner and captures all 9,097 scheduled frames through the public `createViewerCaptureSession`, then encodes the retained mix with H.264 and AAC. The profile is 1,280 × 720, 24 fps and 379.0416667 seconds. The source-linked ESM packages are bundled with Vite's SSR build before Node executes `.capture/capture.mjs`; direct Node type stripping does not resolve their authored `.js` import specifiers. `.capture` and `dist` are derived build output.

Each run gets a distinct directory under `public/outputs/episode-one/runs`. `baseline.json` records implementation files, the actual capture bundle, package sources, lockfile, frozen edit, mix and every retained speech take by SHA-256. Per-frame observations carry that runtime identity, actual time, camera and renderer. `completed.json` requires unchanged input bytes at the end; `failed.json` preserves a failed run. `latest.json` identifies the latest completed observation or capture and does not grant acceptance.

`scripts/prepare-film.py`, run with the recorded local speech environment's Python, validates the canonical screenplay and saved takes before building `public/film.json` and the PCM mix. Speech generation remains in `scripts/generate-speech.py`, outside playback. It resolves only the adopted local VoxCPM2 snapshot. Existing take hashes and `candidate-unheard` status remain authoritative; ASR and waveform measurements do not replace listening.

The frozen first inspection used AMD Radeon 8060S hardware through ANGLE/D3D11. All 129 samples executed without a page error, all 43 reverse seeks reproduced matching PNG bytes, and play, pause holding, final-frame seeking and inspection-camera reset operated. Source/cut/take checks passed, lint passed and Evidence reported zero errors and warnings. These checks establish that observed prototype and do not approve the unperformed continuous viewing or soundtrack audition.
