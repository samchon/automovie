# 돌사성 공격의 품일

## 돌사성 공격의 품일 {#pumil}

**정의·범위**

품일은 664년 음력7월 문무왕이 돌사성을 공격하게 한 신라 지휘자 가운데 한 사람이다.

**확정 내용**

현재 예정 서사에서는 고구려에 도착한 함락 보고에 이름이 등장하며, 독립 전투 장면이나 고구려 수뇌부와의 대면은 없다. 김인문·군관·문영과 함께 일선주·한산주와 웅진 부성 병마를 움직이는 기록의 범위를 유지한다. 확인되지 않은 병력 수와 개별 전공을 붙이지 않는다.
