# 돌사성 공격의 문영

## 돌사성 공격의 문영 {#munyeong}

**정의·범위**

문영은 돌사성 공격을 명령받은 신라 장군이다.

**확정 내용**

다른 세 장군과 공동으로 이름이 기록되지만 한 사람으로 합치지 않는다. 현재 예정 서사에는 고구려가 국지적 성의 손실을 보고받는 대목만 있으며 개별 전술과 가족, 사적 발언은 배정하지 않는다. 정확한 돌사성 위치가 불명이라는 한계도 이 인물의 독립 활약으로 메우지 않는다.
