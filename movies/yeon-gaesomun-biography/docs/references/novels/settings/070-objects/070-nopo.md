# 큰 살대를 쏘는 노포

## 큰 살대를 쏘는 노포 {#nopo}

**정의·범위**

노포는 활 모양의 힘을 걸어 긴 살대를 발사하는 큰 장치다.661년 기록만으로 모든 구조와 크기가 밝혀진 것처럼 세밀한 기계 도면을 주장하지 않는다.

**확정 내용**

작품에서는 길이2미터의 받침과 폭1.5미터의 활 부분, 받침에 놓는 긴 살대로 조형하며 옮길 때 분해하거나 여러 사람이 들어야 한다. 이 값들은661년 기사에 없는 창작 규격이다.
