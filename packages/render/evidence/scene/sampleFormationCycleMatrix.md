# src/index.ts#sampleFormationCycleMatrix

## @evidence contracts/development/implementation.md#principled-implementation

Checks the requested part index, wraps a finite cycle position modulo1 and linearly mixes adjacent canonical Float32 table entries with last-to-first closure into a Matrix4.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One readable CPU projection of the baked cycle law stays distinct from shader patching, take loading and actor/instance ownership.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Valid positive sample count, complete take table and finite position remain actual producer premises; JavaScript arithmetic is not bit-identical device GLSL or appearance proof and no fallback repairs malformed table data.

## @evidence contracts/development/common.md#meaningful-documentation

Documents normalized cycle wrap, selected take, rest-to-posed matrix and CPU-versus-native precision/validity boundaries.

## @evidence contracts/development/implementation.md#efficient-algorithms

Twelve affine components each read two samples and one fixed Matrix4 is created, constant work independent of full table length or formation population.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Every request uses the current take/position with its canonical table; this helper does not reuse a stale matrix after take selection or cycle advancement.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Only one returned matrix owns copied numbers, while cycle/take tables stay borrowed and no take texture, geometry or native resource is acquired.
