## @evidence contracts/development/implementation.md#principled-implementation

Requires enough top-level children, indexes canonical mask node names and binds designed nodes positionally before named traversal overrides with actual matching objects.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One root-index owner serves both painter and nonmutating audit; nearest ancestor lookup and unresolved classification remain separate.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Only child-count is checked here: correct initial declaration order, admitted nonambiguous mask index and object names remain producer premises. Names/root presence cannot certify actual drawable pixels.

## @evidence contracts/development/common.md#meaningful-documentation

Documents anonymous staged groups, named descendants, positional order and too-short scene refusal without claiming full build validity.

## @evidence contracts/development/implementation.md#efficient-algorithms

Engine indexing plus designed-node loop and full scene traversal cost O(E+S+N), with one object-keyed Map and no repeated palette scan per object.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

One call-local root map is reused by its owning paint/audit operation; changed graph/order/palette needs a fresh map rather than a name-only cached result.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The returned Map borrows scene object/document references for that operation scope and acquires no geometry/material/native handle; caller releases the map when the audit/pass ends.
