## @evidence contracts/development/implementation.md#principled-implementation

Captures per-material RGB radius uniforms and registers the table lookup/curvature source patch through public Three compile hooks; the supported physical chunk and Engine-admitted material are required premises.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Uniform setup, shared table production and shader rewriting retain separate existing owners; the material keeps the subsurface texture role visible in userData.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No anatomical fitted output, foreign-method replacement or runtime shader-registry patch is used; screen-space curvature and tabulated Gaussian response remain a rendering approximation requiring actual beauty observation.

## @evidence contracts/development/common.md#meaningful-documentation

States radius units/admission owner, shared texture borrowing, direct-diffuse scope and visual/scientific limits.

## @evidence contracts/development/implementation.md#efficient-algorithms

Fixed uniform setup delegates first-use table quadrature and O(shader length) compile rewriting; normal material construction registers only its current small feature set.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

All materials borrow the same immutable lookup wrapper while each radius uniform stays independent; Three program reuse depends on the structural patch key, not equality of captured radius values.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Material hooks/userData retain radius and the borrowed texture until material references disappear; lookup storage has module lifetime with no explicit retirement API, and this helper acquires no program itself.
