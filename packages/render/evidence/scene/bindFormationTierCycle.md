## @evidence contracts/development/implementation.md#clear-and-simple-structure

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Uses original palette identity rather than temporary guide material identity; the callback cast describes the pinned native runtime boundary, not a fixture group fallback, and no Three prototype method is replaced.

## @evidence contracts/development/implementation.md#efficient-algorithms

Installs fixed-count references/callback once per mesh; each shadow draw resolves one palette slot and performs the shadow owner's constant identity lookup, without per-member traversal.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Meshes of one tier borrow the same cycle/shadow pair and palette identity table; temporary guide overrides do not create duplicate shadow program identities.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Mesh callback/metadata retain borrowed tier resources through mesh lifetime; tier construction/runtime disposal owns physical materials/textures, and this binder allocates no separate GPU handle or task.
