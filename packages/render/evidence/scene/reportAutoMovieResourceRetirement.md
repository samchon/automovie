# src/index.ts#reportAutoMovieResourceRetirement

## @evidence contracts/development/implementation.md#principled-implementation

Runs the shared synchronous retirement collector and, when diagnostic string conversion succeeds, gives its nonopaque aggregate a message retaining ordered original causes. Sole/primary error identity follows the collector; string conversion is not part of resource retirement.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Diagnostic presentation stays separate from owner fan-out and settlement; the private description helper catches inspection failure, while final message joining remains outside that helper's boundary.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Empty, cyclic or uninspectable aggregates remain opaque causes under the collector policy, and a refused message getter yields fallback text. A nonstring Error.message whose coercion throws during join remains an unresolved original-cause preservation gap; no successful retirement is inferred from diagnostic presentation.

## @evidence contracts/development/common.md#meaningful-documentation

Documents synchronous reporting, original cause/order, message-only transports, opaque/single primary identity and the unresolved runtime message-coercion boundary.

## @evidence contracts/development/implementation.md#efficient-algorithms

Collector work scales with operations and aggregate entries; description joins scale with actual message bytes and no new asynchronous settlement window is opened.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Reporting uses the completed owner failures rather than retrying their resource operations, while original cause objects are reused in the reported aggregate.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Only temporary cause/message arrays and the thrown diagnostic survive the call; owners retain uncertain resources and this reporter acquires no handle or cleanup task.
