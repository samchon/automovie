# src/scene/createFormationRepresentations.ts#createFormationRepresentations

## @evidence contracts/development/implementation.md#principled-implementation

Resolves each declared LOD model, flattens/bakes it, registers its tier before custom shadow setup and validates requested gait names against the union repertoire; admitted unique tier identities are a premise, and a gait present in one tier may still fall back in another according to that cycle's selector.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Owns the tier construction/admission transaction before anonymous chunks, delegating rigid flatten/bake, shadow material setup and independent resource retirement to their existing owners.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Missing referenced models and absent declared repertoire refuse with real unit/tier/cue ids, not substitute fixtures; early tier registration prevents a shadow-setup refusal from hiding an already-acquired visible representation.

## @evidence contracts/development/common.md#meaningful-documentation

States tier/cue admission, rollback of already-constructed tiers and chunk-after-success ordering; actual repertoire union versus per-tier fallback is disclosed in the implementation answer.

## @evidence contracts/development/implementation.md#efficient-algorithms

Constructs T declared tiers once with canonical per-model flatten/bake costs, collects K take names and scans Q relevant cues with Set membership; rollback visits unique resources across admitted tiers without scanning anonymous members.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Builds one representation per declared tier for all later chunk borrowers and uses one repertoire Set during cue admission; independently mutable model/tier input has no immutable revision key for cross-build cache reuse.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Owns each completed flattened tier before acquiring shadows and attempts all registered tier resources on any later refusal, preserving primary and cleanup causes; success transfers T tiers/textures/materials to the formation runtime, while nested constructors retire their own pre-return allocations.
