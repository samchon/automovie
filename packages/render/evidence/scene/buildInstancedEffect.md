# src/scene/buildInstancedEffect.ts#buildInstancedEffect

## @evidence contracts/development/implementation.md#principled-implementation

Samples admitted compiled effects by absolute time and distance, then copies bounded live particle position/size/opacity into camera-world-oriented instance matrices; maxParticles bounds live buffers, recipe ranges/finite coordinates are upstream premises and a smooth radial feather defines billboard appearance rather than physical volumetric scattering.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One native instanced plane stream projects the canonical sampler and reports its current scalar summary; there is no production scene/film consumer in the current tree, and no new runtime service is added to conceal that exported-only reach.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Uses actual seed/time/particle values and declared cap without fixture particles or GPU random state; radial feather thresholds0.28/0.5 and renderOrder10 are explicit current display conventions. Color uses native hex decoding/global color policy, and this custom shader has no final color-space chunk, so full captured-color parity is not guaranteed.

## @evidence contracts/development/common.md#meaningful-documentation

Gives fixed-step numerical ownership, camera-facing projection, live capacity, caller native-resource retirement and missing production/rollback boundaries rather than certifying a drawn effect.

## @evidence contracts/development/implementation.md#efficient-algorithms

Allocates B matrix/opacity capacity once for budget B and fills N live sampled particles per update, plus the sampler's candidate/lifetime/LOD cost; per-particle Vector3 temporaries are still allocated and transparent raster overdraw follows screen coverage, not just live count.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Reuses one plane/material/instance buffer and working matrix/scale/camera quaternion across frames; absolute-time sampling recomputes live particles, since matching object identity is not an immutable recipe/time/distance equivalence key.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Returned mesh owns one geometry/material/native instance stream and retains the compiled effect through update, with bytes proportional to cap; no disposer/constructor rollback is returned, so callers must retire all three actual native roles and discard the handle. No worker or decoder is acquired.
