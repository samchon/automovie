# @automovie/human

A human figure generated by code from typed parameters: body measurements, head dimensions, and optionally appearance, pose and expression. The result is an `IAutoMovieModel` in metres, so the engine and viewer treat it like any other model.

A production normally draws this body as a polygon man, plain primitives over the same joints, and generates the full skin only when a shot needs a particular person's build and face.

The package is being rebuilt, so expect its API to change.

## Use

The package needs Node.js 22.23.2 or later.

```bash
npm install @automovie/human
```

```ts
import { AutoMovieHuman, type IAutoMovieHumanParameters } from "@automovie/human";

declare const parameters: IAutoMovieHumanParameters;

const { model } = AutoMovieHuman.generate(parameters);
```

`body` and `head` are required and everything else is optional. Each field's JSDoc gives its unit and what an unknown value means.

## Entry points

- `AutoMovieHuman.generate` returns the model in its neutral pose for one parameter set.
- `AutoMovieHuman.prepare` generates once and also returns the skeleton and a pose evaluator. An `AutoMovieHumanInstance` then holds one pose, expression and root transform over that body, so posing never regenerates it.
- `AutoMovieHuman.diagnose` lists the optional parts that failed their checks and fell back to a base shape. It is empty for a sound figure.
- `AutoMovieHumanCanonicalBody.prepare(parameters, { mass, id })` builds the canonical body without any skin: the canonical skeleton, which is this person on the engine's humanoid joint set (the VRM 1.0 humanoid), and its contact profile, the mass and contact shapes of each segment. This is the body `@automovie/motions` performs with.

## Polygon man

The polygon man is drawn by `@automovie/viewer` from the canonical body, and posed with canonical poses such as the ones `@automovie/motions` samples.

```bash
npm install @automovie/viewer @automovie/interface three
```

```ts
import { AutoMovieHumanCanonicalBody, type IAutoMovieHumanParameters } from "@automovie/human";
import type { IAutoMoviePose } from "@automovie/interface";
import { buildHumanPolygon } from "@automovie/viewer";
import * as THREE from "three";

declare const parameters: IAutoMovieHumanParameters;
declare const pose: IAutoMoviePose;

const body = AutoMovieHumanCanonicalBody.prepare(parameters, { mass: 72, id: "a" });
const drawing = buildHumanPolygon(AutoMovieHumanCanonicalBody.display(body));

// The human package's frame mirrors the canonical world, so the drawing sits under this matrix.
const figure = new THREE.Group();
figure.matrixAutoUpdate = false;
figure.matrix.fromArray([...AutoMovieHumanCanonicalBody.REFLECTION]);
figure.add(drawing.object);

drawing.setPose({ posed: AutoMovieHumanCanonicalBody.display(body, pose).posed });
```

The polygon man is plain because it only has to show motion cheaply. Nothing about it stands for skin or clothing.

## Background and debugging

The anatomy, sources and lofting technique behind the generator are written up in [`docs`](./docs/README.md). The [debug viewer](./debug/README.md) is a development tool in this repository, not part of the published package; `pnpm debug` in `packages/human` serves it on port 5197.
