# @automovie/human

A human figure generated by code from typed parameters: body measurements, head dimensions, and optionally appearance, pose and expression. The result is an ordinary `IAutoMovieModel` in metres, so the engine and viewer treat it like any other model.

A production normally draws this body as a polygon man, plain primitives over the same joints, and generates the full skin only when a shot needs a particular person's build and face. The package is being rebuilt, so expect its surface to change.

## Use

It needs Node.js 22.23.2 or later.

```bash
npm install @automovie/human
```

```ts
import { AutoMovieHuman, type IAutoMovieHumanParameters } from "@automovie/human";

declare const parameters: IAutoMovieHumanParameters;

const { model } = AutoMovieHuman.generate(parameters);
```

`body` and `head` are required and everything else is optional. Each field's JSDoc gives its unit and what an unknown value means. Four complete parameter sets are in the playground's [`human-parameters`](../playground/src/human-parameters).

## Entry points

- `AutoMovieHuman.generate` returns the neutral body for one parameter set.
- `AutoMovieHuman.prepare` generates once and also returns the skeleton and an evaluator. An `AutoMovieHumanInstance` then holds one pose, expression and root over that shape, so posing never regenerates the body.
- `AutoMovieHuman.diagnose` lists the optional pieces that broke their contract and fell back to a base shape. It is empty for a sound figure.
- `AutoMovieHumanCanonicalBody.prepare(parameters, { mass, id })` builds the skeleton and contact profile on the canonical humanoid rig without any skin. This is the body `@automovie/motions` performs with.

## Polygon man

The polygon man is drawn by `@automovie/viewer` from the canonical body, and posed with canonical poses such as the ones `@automovie/motions` samples.

```ts
import { AutoMovieHumanCanonicalBody, type IAutoMovieHumanParameters } from "@automovie/human";
import type { IAutoMoviePose } from "@automovie/interface";
import { buildHumanPolygon } from "@automovie/viewer";
import * as THREE from "three";

declare const parameters: IAutoMovieHumanParameters;
declare const pose: IAutoMoviePose;

const body = AutoMovieHumanCanonicalBody.prepare(parameters, { mass: 72, id: "a" });
const drawing = buildHumanPolygon(AutoMovieHumanCanonicalBody.display(body));

// Human's own frame mirrors the canonical world, so the drawing sits under this matrix.
const figure = new THREE.Group();
figure.matrixAutoUpdate = false;
figure.matrix.fromArray([...AutoMovieHumanCanonicalBody.REFLECTION]);
figure.add(drawing.object);

drawing.setPose({ posed: AutoMovieHumanCanonicalBody.display(body, pose).posed });
```

The figure stays plain on purpose. It exists to show motion cheaply, so nothing about it stands for skin or clothing.
