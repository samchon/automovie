# @automovie/human

The body of a person for AutoMovie, generated by code from typed parameters of body measurements and head dimensions. From them `AutoMovieHumanCanonicalBody` builds the canonical body: the skeleton of that person on the engine's humanoid joint set (the VRM 1.0 humanoid), and its contact profile, the mass and contact shapes of each segment. This is the body `@automovie/motions` performs with and `@automovie/viewer` draws as the polygon man.

The package is being rebuilt. The realistic skin surface was removed and is being reconstructed from the same parameters, so expect the API to change.

## Use

The package needs Node.js 22.23.2 or later.

```bash
npm install @automovie/human
```

```ts
import { AutoMovieHumanCanonicalBody, type IAutoMovieHumanParameters } from "@automovie/human";

declare const parameters: IAutoMovieHumanParameters;

const body = AutoMovieHumanCanonicalBody.prepare(parameters, { mass: 72, id: "a" });
// body.skeleton, body.profile and body.joints
```

`body` and `head` are required and everything else is optional. Each field's JSDoc gives its unit.

## Entry points

- `AutoMovieHumanCanonicalBody.prepare(parameters, { mass, id })` builds the canonical body at its T-pose rest: the rig as an `IAutoMovieSkeleton`, the contact profile as an `IAutoMoviePhysicalProfile`, and every joint with the bone that carries it.
- `AutoMovieHumanCanonicalBody.place(body, pose)` runs the rig's forward kinematics for a canonical pose and returns each joint's placement in the order of `body.joints`.
- `AutoMovieHumanCanonicalBody.display(body, pose?)` returns the rest bones and placements in this package's own frame for drawing, the T-pose when `pose` is omitted. `REFLECTION` is the column-major matrix that puts that drawing in the canonical world.

## Polygon man

The polygon man is drawn by `@automovie/render` from the canonical body, and posed with canonical poses such as the ones `@automovie/motions` samples.

```bash
npm install @automovie/render @automovie/interface three
```

```ts
import { AutoMovieHumanCanonicalBody, type IAutoMovieHumanParameters } from "@automovie/human";
import type { IAutoMoviePose } from "@automovie/interface";
import { buildHumanPolygon } from "@automovie/render";
import * as THREE from "three";

declare const parameters: IAutoMovieHumanParameters;
declare const pose: IAutoMoviePose;

const body = AutoMovieHumanCanonicalBody.prepare(parameters, { mass: 72, id: "a" });
const drawing = buildHumanPolygon(AutoMovieHumanCanonicalBody.display(body));

// The human package's frame mirrors the canonical world, so the drawing sits under this matrix.
const figure = new THREE.Group();
figure.matrixAutoUpdate = false;
figure.matrix.fromArray([...AutoMovieHumanCanonicalBody.REFLECTION]);
figure.add(drawing.object);

drawing.setPose({ posed: AutoMovieHumanCanonicalBody.display(body, pose).posed });
```

The polygon man is plain because it only has to show motion cheaply. Nothing about it stands for skin or clothing.

## Inspection

The figure is inspected with AutoMovie's shared instrument. `src/executable/subjects.ts` is a draw-only subject module that offers every person the package defines, by name (`f1`), in its canonical pose; `<person>@<pose>` names another pose once the package defines one. From this folder, `pnpm capture` runs `automovie capture` on it for stills and contact sheets, and `pnpm inspect` opens the inspector page over it; both take the request keys the [`render` README](../render/README.md#inspection) lists.

| Path | What it names |
| --- | --- |
| `f1` | The whole person |
| `f1/body` | The sewn skin: the trunk with the limbs, digits, ears and nose joined to it |
| `f1/<family>`, `f1/<family>.mirror` | One family's construction curves, such as `f1/arm` and its reflected twin's `f1/arm.mirror`; a loose family, when one is defined, is also a piece of its own here |
| `f1/<family>/section/<k>` | The section ring at the family's `k`-th authored knot |
| `f1/<family>/guide/<q>` | The guide rail at quarter phase `q`, 0 to 3 |
| `f1/<family>/axis` | The line through the rings' centres |

The construction curves are marks of the kinds `curve/section`, `curve/guide` and `curve/axis`, so `--marks curve/*` draws them over the surface and `--marks curve/* --surface 0` draws them alone, through the same views. The skin is one piece, so a family's surface cannot be drawn apart from the body; select its curves and frame them with `@focus`.
