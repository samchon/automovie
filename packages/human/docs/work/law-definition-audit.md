The current source starts at `G=A+[0,-0.17*B,0]` but uses `H=(1-0.1044-0.0432)*AR` and elbow-to-radiale offset `e=0.0432*AR`. In the collinear vertical measuring case, generated AR is `AR+0.17*B-0.1044*AR`. The error vanishes only when the two independently chosen GH offsets agree. No f1 value or measured output is required to establish this symbolic incompatibility.

A breast amplitude derived from independent inputs must first fix a common chest-wall and posterior datum at the breast's actual height. Only then can a front-outline difference be interpreted as a local projection. A whole-depth difference between two heights is not that quantity. The same distinction applies to a gluteal projection above the bare posterior wall. The presence of reference support holes or white bands does not justify changing these datums or fitting new constants. Published subcutaneous-fat studies found during this round do not establish that a fold rolling radius equals local fat thickness.
