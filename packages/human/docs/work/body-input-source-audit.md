It follows the 55 fields of `structures/body/IAutoMovieHumanBodyAnatomy.ts`, both sides of the four public hand dimensions and three public foot dimensions, and the declared foot-assembly switch. No derived survey value is described as a private f1 measurement.

This audit does not widen the current f1 shape work into implementing every unused field or a new bony-landmark system. This replaces the all-toe FOOT dorsum envelope as an individual distal-depth owner without changing that transverse family. The final D/B ratio is not claimed to equal the retained ratio after anisotropic scaling.
