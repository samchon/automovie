# Body input to original-source audit

This is one inspection round of the existing f1 construction scope, before another shoulder shape batch. It follows the 55 fields of `structures/body/IAutoMovieHumanBodyAnatomy.ts`, both sides of the four public hand dimensions and three public foot dimensions, and the declared foot-assembly switch. HEAD owns the separate head-input matrix. It adds no input, person, measurement, coefficient or generation run.

Every anatomy field first passes through `AutoMovieHumanBodyAnatomy.resolve`: a supplied value survives, while an omitted value takes its named survey/default rule. In the authored f1 anatomy 24 fields are supplied and 31 omitted; all 14 paired hand/foot values are supplied. E below means explicitly supplied in f1; D means omitted/defaulted. The public field declaration owns the cited measurement protocol; LAWS's `law-definition-audit.md` distinguishes primary sources actually read from citations not independently reopened. No derived survey value is described as a private f1 measurement.

The active path is `BodyLaw.limbInputs/headInputs/define` to `BodyLaneInterim`, then TrunkViews/Build, LegLaws/Walk, ArmInterim/Walk, HandBones/DigitInterim/Walk and FootInterim/Part/ToePart. Old TrunkConstruction/Solver still runs and some of its landmarks feed new sources. A record stored there, a retired builder, a source name, and an accepted final skin are four different things.

The verification column describes the currently observed construction checks, principally completed 53347 (4/5; only the two existing isolated leg median failures), and coupled 1328 (2/3; actual body definition and head records pass, one existing maximum-caliper counterexample remains). HEAD's C7/height expectations still pass in that current round. This does not assert that every older test is absent or that final anatomy tests passed. No new reference-overlay PNG exists for this source.
