# Prior sourcing list (f1 original 2D phase)

Opened 2026-11-07 21:25 +09:00. Constants that original 2D curves currently read from the private reference set ("Observed", "fitted", "estimated from the private reference set", four-reference means) are listed here with the measured effect on f1 where known and the published sources or input-derived constructions that can replace them. f1 belongs to every one of those fitted sets, so agreement with the f1 reference on a constant listed here is partly circular and accepts nothing. A replacement states its source (title, table or section), cohort, mean and SD where it is a population value, or its derivation from public inputs; a value with no published source becomes a declared convention with its reason, never a fitted number. Work proceeds in batches ordered by measured departure size, each one change plus one render/profile round.

## Citation audit, opened 2026-11-07 22:30 +09:00

Every published value an original 2D curve reads is listed with its citation as the code states it, the place in the source, the value, the cohort, the code's use and the reading behind it. Reading states, strictest first:

- Primary read (URL): f1_modeler opened the primary text or primary data in this campaign and the quoted value is copied from it.
- Secondary read (URL): f1_modeler read a published secondary source that reproduces the value; the primary was not read.
- Note only: an earlier worker's `docs/sources` note records a reading; f1_modeler has not read that source. Unverified citation.
- Unverified citation: no reading by anyone is recorded.

A row whose source does not say what the code uses moves to FIX or DEBT in its last column; that judgement holds only for the reading state it names.
