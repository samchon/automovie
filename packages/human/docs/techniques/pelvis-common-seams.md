# Pelvic seam constraints

A shared hip port and two thigh ports require qualified source incidence, phase and anatomical domain. A world lateral sign cannot select the own-leg shell when inner skin crosses that sign.

For a qualified thigh direction b through A and projected forward eX, a candidate common guide plane is

```
n = normalize(eX-dot(eX,b)*b)
c = dot(n,A)
dot(n,P) = c.
```

Refuse a degenerate projection or chord frame. The actual assembly owns each port curve, intersection parameter, oriented tangent and transverse ribbon.

For generated physical phase t in [0,L] and u=t/L, normalized endpoint derivatives are L times the physical endpoint derivatives. A chosen unit endpoint speed is a generated gauge, not proof that phase width equals arc length.

A seam can use its exact endpoint Hermite field plus

```
Hip*u²*(1-u)²*sum(theta_k*P_k(2u-1)).
```

Hip is a declared length scale; the polynomial residual and its first derivatives vanish at both ends. Retain the actual residual degree and 1/L, 1/L² derivative factors. Original source widths and speeds remain unchanged.

Endpoint position/tangent compatibility supplies no transverse jet or completed pelvic surface. Three-port topology, excluded regions, embedding and material phase need independent qualification.
