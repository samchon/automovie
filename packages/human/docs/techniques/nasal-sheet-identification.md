# Nasal rims and sheet domains

A nostril rim can be nonplanar and contain intentional corners. Preserve its full Hermite spans, physical h and one-sided jets rather than replacing it by a smooth ellipse. Incidence two at the rim does not by itself establish or reject an internal cavity sheet.

Use source adjacency after cutting the complete semantic rim cycle to identify its incident disks and exterior domain. Canonical position identity does not imply canonical/native triangle identity. Validate transferred native face membership against the same boundary edges and retain every unresolved sheet.

## Phase and shape

Selecting the largest corner angle as a cycle seam can pick a different anatomical corner in another source. Qualify the actual semantic corner and direction before normalizing the complete phase. A closed polynomial profile

```
P(u) = a0 + u*(1-u)*sum(a_k*(2u-1)^k)
```

can share endpoint position while retaining independent one-sided derivatives. Its degree and fit error remain distinct from those of the original source curves, and an additional corner needs explicit representation.

Clinical subnasale-to-pronasale protrusion, a forward gizmo displacement and a rim-centroid offset have different meanings; a geometric proxy is not a clinical input because both are called protrusion. Rim span, height and forward placement need a qualified common frame and observed definitions.

## Surface constraints

Identify root, tip, alar and columellar feature curves before selecting charts. Separate exterior skin from internal rim-bounded sheets using actual incidence. A named nasolabial curve without a shared junction is not automatically a nasal side-wall boundary.

Each incident chart consumes the same rim object and compatible transverse derivatives through the actual parameter Jacobian. A profile fit, a chosen disk topology or a small source residual does not establish an assembled nose, lip contact or independent clinical response.
