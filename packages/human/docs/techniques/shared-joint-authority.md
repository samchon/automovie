# Shared joint authority

This is an implementation and inspection record, not a claim of completed Human coverage. Human and Human-viewer tests are prohibited for this task. The existing reference-experiment processor owns acquisition and actual render comparisons.

## Failure and representation change

Round 2 shared shaft/joint ring positions and analytic normals exactly at their sampled vertices, but the clamped world-coordinate cubic had interior rank loss in every elbow. Increasing tessellation would not remove a singular generating surface. The replacement changes the generating chart instead of moving boundary handles or substituting normals.

The source-derived shaft remains its original analytic function `F(s, psi)`, including its actual longitudinal degree six or seven and angular degree seven. `HumanPlaneCut` solves `n dot (F-O)=lambda` inside the original supported station domain. The solution station depends on phase; it is neither an averaged station nor a projection of the old ring. The same cut is then parameterized by its polar angle about the declared common bone origin. The existing middle joint curve is inverted in the same chart without another Fourier fit.

For `c=n dot F_s`, `d=n dot F_psi`, and `a=-d/c`, the plane-cut tangent is `T=F_psi+a F_s`. Polar speed must be positive. The mixed coordinate derivative uses the regional owner's analytic `F_ss`, `F_spsi` and `F_psipsi`; finite differences are not advertised as exact jets. Missing second derivatives or nonpositive chart speed refuse the operation.

## Positive joining surface

Each joining half has two actual curve and transverse-derivative owners. A physical cubic Hermite field interpolates **log radius**, including its phase and mixed derivatives. The world surface is

`P(lambda, phi) = J + lambda n + exp(f(lambda, phi)) (u cos(phi)+v sin(phi))`.

The world surface is exponential, not a world-coordinate cubic. When its admitted radius remains finite and positive, `n dot P_lambda=1` and `n dot P_phi=0`, and its polar tangent is nonzero. These premises structurally avoid the previous interior rank loss within this chart. They do not establish anatomical correspondence or reproduce all measured joint features.

The original shaft is restricted by its actual parameter functions on the cut. `HumanRetainedShaft` maps its normalized chart into the original station/phase domain and differentiates that map analytically. A positive coordinate Jacobian is required. Source positions, point welding and source normals are absent.

## One evaluation and sampling authority

An audit found an implementation error before a successful round-3 publication: `HumanPositiveJoint` supplied the exponential evaluator to `HumanCurveFamily.interval`, but the interval previously evaluated an endpoint cubic surrogate. Explicit analytic authorities now create `restrictedInterval` directly. Both interval evaluation and every child retain the original function. The remaining constrained-family interval caller is genuinely cubic.

The common assembly owns periodic angular sample addresses. Joining families and retained shaft charts consume those same numbers and the same boundary functions. Patch sampling can also receive explicit physical parameter arrays. This addresses the former cranial/posterior mismatch, where agreeing curve functions still generated different polygonal boundary chords; it does not repair an invalid posterior anatomical chart.

## Coverage and validation limits

Round-2 source and generated observations distinguish original curve-fit error, pooled-rule residual, skeleton placement, interior embedding failure and tessellation. The plane-cut feasibility analysis covered 32 boundaries and 768 angular samples each within the original supported domains; it found unique intersections and positive chart speeds. This is finite numerical evidence, not an interval certificate for every unobserved input.

The new method must complete the affected four-person render and neighbor inspection before any visual-success claim. Independent input changes, interactions and return to the original state remain separate required evidence. Knee feature loss and source-pose correspondence are not solved merely by positive joining surfaces. Shoulder, pelvic, wrist, ankle and neck transitions remain separate domains.

Failed perioral diamond, unqualified equal-parameter lid strips, the radial posterior ear-overhang candidate, intersecting foot skin and unsupported thumb-root skin are excluded from the current generated output.
