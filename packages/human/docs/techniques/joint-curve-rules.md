# Joint neighborhoods and physical jets

Incoming, outgoing and bisector observations are different charts. A bisector built from adjacent support directions requires a nondegenerate direction sum and qualified roll; their skin contours are not averaged into one curve. Use the actual support chain for section selection and retain cavities, ambiguity and source lineage.

## Regional derivatives

Let J be the support, b the unit bisector, U,V the rolled plane axes, G a physical course scale and lambda the signed physical offset. For eta=lambda/G and a dimensionless conditioning scale a, xi=eta/a. A fitted channel c=G*f(xi) has dc/dlambda=f'(xi)/a. Conditioning does not change physical units or identify a clinical perimeter.

For O=J+lambda*b+U*c0+V*c1 and e=U*cos(phi)+V*sin(phi),

```
P = O + e*R
P_lambda = b + U*c0_lambda + V*c1_lambda + e*R_lambda
P_phi = e_phi*R + e*R_phi
P_lambda_phi = e_phi*R_lambda + e*R_lambda_phi.
```

A circumferential Hermite tangent is not an observed transverse surface derivative. The latter follows from a qualified regional law or measured guide constraints.

## Implicit cuts

For a shaft F(s,phi) cut by lambda=b dot (F-J),

```
ds/dlambda = 1/(b dot F_s)
ds/dphi = -(b dot F_phi)/(b dot F_s).
```

Dividing by the angle between support chords does not reparameterize the skin. Zero or ambiguous intersections remain unsupported.

For an observed guide gamma(u) with regular lambda(u),

```
gamma_lambda = gamma_u/lambda_u
gamma_lambdalambda = (gamma_uu*lambda_u-gamma_u*lambda_uu)/lambda_u³.
```

If f=log(radius/G) and the observed guide has polar path phi(lambda), it constrains

```
f_lambda + f_phi*phi_lambda = d(log radius)/d lambda
f_lambdalambda + 2*f_lambdaphi*phi_lambda
  + f_phiphi*phi_lambda² + f_phi*phi_lambdalambda
  = d²(log radius)/d lambda².
```

These equations are linear in common coefficients for fixed correspondence. One path does not independently observe every mixed derivative. Preserve source-fit uncertainty, actual physical widths and endpoint jets when solving the full constrained problem.
