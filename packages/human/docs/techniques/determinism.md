# Floating-point determinism

[ECMAScript](../sources/ecma-262-math.md) specifies binary64 arithmetic and square root, but transcendental functions and exponentiation may use implementation approximations. Addition is not associative, so accumulation order also affects the result. [V8's fdlibm imports](../sources/v8-fdlibm-commits.md) improve cross-platform consistency for particular functions without promising bit identity across engine versions.

Reproducibility needs a fixed complete input, algorithm and runtime version. Typed inputs and seeded integer hashes stabilize a generated variant; they do not establish universal transcendental bit identity. Direct evaluation from parameters avoids compounding last-bit differences through accumulated state. Connectivity comes from semantic topology, not equality comparisons between generated positions.

Persisting generated bytes and provenance avoids relying on regeneration across runtime versions. A viewer that regenerates from inputs remains sensitive to those versions.
