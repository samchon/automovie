# Hand curve correspondence and source reconstruction

This is a development record, not a form acceptance. The reference meshes stay outside the package; no reference vertex, connectivity, landmark index or morph data is copied into Human.

## Correspondence

The four lean adult gates were registered to the current generated skeleton. All55 public joint origins reconstructed from the immutable b341 consumer match the target skeleton within2.28e-13mm. Native reference skin weights rotate and stretch bone axes onto those joints, preserving transverse reference dimensions. The native rig markers are not clinical joint centres. Digit roll and palmar offsets remain different between reference people, so their absolute transverse depths are not individual fitting targets.

The first-web ratio is Greiner1991's pooled crotch1 height over hand length, already declared by `AUTOMOVIE_HUMAN_HAND_FORM`. Its photographic wrist-crease baseline is approximated by the radial stylion datum, not asserted to be an individual clinical identity. The adult ratio is still held across converter ages; range generation is a separate check. No independent length, breadth or skeleton measurement is replaced by a reference fit.

The defining sections, bone-relative belly and web plane are independent of sampling rows. The bridge's eight ports and two rows are its existing topological budget; subdivision changes approximation density. The physical and logical networks share block correspondence while keeping their different coordinate meanings.

## Diagnosis and limits

Exact triangle–plane cuts, with every connected component retained, replaced the earlier ±1.5mm slab plots for quantitative comparison. The slab plots remain flow illustrations only. With the reference's native transverse sizes and rig orientation retained, first palm/thumb separation appears at x/L=.315–.335 across the four references; the old assembled source was already split at the scan's first plane,.250. The new curve-family private preview separates at.315–.320. These are engineering diagnostics of the branch, not clinical measurements or a visual pass.

The shared belly guides recover it to196.13mm; a residual difference remains. The reference's214.22mm is not adopted as a direct target because the registration retains its own transverse dimensions and joint-marker offset.
