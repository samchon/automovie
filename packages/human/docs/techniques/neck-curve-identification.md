# Neck course identification

Separate lower collar convergence, regular neck tube and upper jaw/occiput transition. A named head boundary is not a measured neck endpoint by name alone. A single radial continuation cannot represent collar or jaw branching.

For an oblique plane n dot P=d intersecting a unit support direction t from A, the physical station is

```
s = (d-n dot A)/(n dot t).
```

Retain n, d and the actual nonzero Jacobian n dot t. Circumferential h, native girth and anterior neck-length course are different quantities and do not replace this station.

Admit a radial chart only where the selected support-containing loop has unique positive intersections in the required domain. An incidence-qualified annulus establishes continuation, not material phase or a source transverse derivative. Shared fixed support fractions can misalign collar features between shapes; additional polynomial degree does not identify missing correspondence.

Physical quadrature must use actual adjacent station widths rather than observation counts. Detect perimeter or area turns on the retained analytic family; a finite sign scan can miss even-multiplicity or shallow stationary points. New principal descriptors evaluate the unchanged function and add no shape information.

Achieved native girths, captured course lengths and recovered section lengths are separate observables. Independent neck length must be reconciled with both head and trunk boundaries. Current-cohort coefficients, response laws and visual acceptance remain to be established from bound observations.
