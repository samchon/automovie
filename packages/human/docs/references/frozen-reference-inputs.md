# Earlier reference input provenance

The [original input ledger](https://github.com/samchon/automovie/blob/197196b7b/packages/human/docs/references/frozen-reference-inputs.md) preserves requested controls, achieved readbacks, immutable hashes, registration and measurement limits for an earlier four-model dataset. It is not the current f1/f2/m1/m2 cohort.

A requested control, native readback, geometric extent and clinical measurement have different protocols. Inactive readbacks cannot recover missing authoring inputs. A triangle-plane section becomes an anatomical measure only after its landmark, posture, component selection and measurement protocol are established. Skin arclength and convex-tape perimeter also differ.

The earlier ledger used a different axis conversion and source topology. Do not apply its numeric transform, vertex counts, indexed landmarks or fitted ratios to the current reference files. Native joint supports, clinical landmarks and surface extrema remain distinct observations. Equal source indices do not establish clinical correspondence.

Use the current [reference contract](../../../../.agents/skills/human/references.md) and selected manifest receipts for live paths, source-frame conversion and original/Recovery image lookup. Repeated sections of one model do not add independent people; previously fitted references are not untouched holdouts.
