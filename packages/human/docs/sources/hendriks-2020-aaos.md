# Hendriks et al. 2020 supplement, AAOS normal range of motion table

Hendriks T. et al., Supplementary Digital Content 1, "Normal ROM values according to AAOS," *Plastic and Reconstructive Surgery Global Open* 8(6), 2020, https://cdn-links.lww.com/permalink/prsgo/b/prsgo_8_6_2020_04_17_hendriks_gox-d-20-00155r2_sdc1.pdf. Read in full (one page). The AAOS handbooks themselves (1965; Greene and Heckman 1994) were not read, so this is a secondary transcription.

## Licence

Journal supplement, Wolters Kluwer; values cited.

## Values (deg)

| Joint | Motion and normal |
| --- | --- |
| Neck | extension 45, flexion 45, rotation 60, lateral flexion 45 |
| Shoulder | extension 60, flexion 180, abduction 180, adduction 40 (added by the authors, not AAOS) |
| Elbow | extension 0, flexion 150 |
| Wrist | extension 70, flexion 80 |
| Hip | extension 20, flexion 120, abduction 40, adduction 20 |
| Knee | extension 0, flexion 135 |
| Ankle | plantar flexion 50, dorsiflexion 20 |
| Toe MTP | extension 70, flexion 45 |
| Thumb | CMC palmar and radial abduction 60 (added, not AAOS); MCP flexion 50, extension 0; IP flexion 80, extension 0 |
| Fingers II to V | MCP flexion 80, PIP 90, DIP 65, extensions 0 (from Richard and Parry, median right index finger) |

Grade: conventional (a handbook norm whose population and protocol the handbook does not give, as Roaas and Andersson 1982 point out).
