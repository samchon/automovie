# Literature sources

Read the source note before using a measurement to design a body. Each note describes what the source supports, including the study population and limits where applicable.

The construction notes link to their source records.

- [Skeleton](../anatomy/skeleton.md) and [joint range](../anatomy/joint-range.md) cover body landmarks and mobility.
- [Lofting](../techniques/section-chain-lofting.md) and [surface composition](../techniques/surface-composition.md) cover numerical construction.
- [Skin](../anatomy/skin.md) and [hair](../anatomy/hair.md) cover appearance and its variation.

The [source directory](https://github.com/samchon/automovie/tree/master/packages/human/docs/sources) lists the individual notes.
