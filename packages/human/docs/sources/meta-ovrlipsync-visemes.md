# Meta (Oculus) Lipsync viseme reference

Meta. "Viseme Reference" for Oculus Lipsync (Unity). Read at https://developers.meta.com/horizon/documentation/unity/audio-ovrlipsync-viseme-reference/. The page states it is no longer updated and refers to the MPEG-4 viseme standard.

## Licence

Vendor documentation; the viseme set is a de facto convention. No licence statement for the reference images, which are not used.

## What Human takes

The viseme vocabulary for speech, each viseme to be defined as an AU combination plus jaw opening and tongue position in `../anatomy/expression.md`, and the mapping from the interface's five VRM vowel presets (aa, ih, ou, ee, oh).
