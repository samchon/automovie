# Jacques 1998, skin optics summary

Jacques SL. "Skin Optics." Oregon Medical Laser Center News, January 1998. Read at https://omlc.org/news/jan98/skinoptics.html.

## Formulas and values

λ in nm, coefficients in cm⁻¹. The page calls them approximations and starting points. Grade: population-fitted to published spectra.

| Quantity | Formula or value |
| --- | --- |
| Melanosome absorption | μa,mel = 6.6 × 10¹¹ λ^-3.33 |
| Baseline (bloodless, melaninless) | μa,base = 0.244 + 85.3 e^-(λ-154)/66.2 |
| Epidermis | μa,epi = f_mel μa,mel + (1 - f_mel) μa,base |
| Dermis | μa,derm = f_blood μa,blood + (1 - f_blood) μa,base |
| Melanosome volume fraction, light adults | 1.3 to 6.3 percent |
| Moderately pigmented adults | 11 to 16 percent |
| Darkly pigmented adults | 18 to 43 percent |
| Average dermal blood volume fraction | about 0.2 percent; 2 to 5 percent locally in the venous plexus 100 to 200 μm deep |
| Epidermis thickness used | 60 μm |
| Dermal reduced scattering | μ's = 2 × 10¹² λ^-4 + 2 × 10⁵ λ^-1.5 (Rayleigh plus Mie from collagen fibres) |
| Anisotropy g | 0.7 to 0.95 |

Rayleigh scattering dominates below about 650 nm, Mie above.
