# Human schema types

Use `IAutoMovieHumanParameters` from `@automovie/interface` for ordinary Human inputs. For typia validation or schema generation, import `IAutoMovieHumanParametersSchema` and related `*Schema` types from `@automovie/human`. They add unit and range metadata to the same input shapes.

Read the [Human README](../../README.md) to build a body from those parameters.
