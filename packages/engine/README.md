# @automovie/engine

The deterministic core of AutoMovie. It validates what an authoring agent declares and computes everything a frame needs from it: kinematics and range of motion, motion sampling and performance, staging and film grammar, physics, soft bodies and fluids, buildings and drawings, light and sound, and the analyses productions run over them. The same inputs always produce the same frames.

The engine owns computation and admission, not appearance: it imports no renderer, and `interface` owns the types it reads and writes.

## Use

```bash
npm install @automovie/engine
```

```ts
import { stageScene, performShot, cutSequence } from "@automovie/engine";
```

Public APIs consume typed declarations. Validation entry points return field-specific violations; compute and playback paths throw when input is malformed or incompatible. The core reads no authored files; offline asset I/O belongs to the Node tools.

`createAutoMovieEllipticLoftAtlas` in `geometry` converts ordered cubic centre/radius profiles into an open shared bicubic atlas in metres. Four tangent-matching cubic quarter arcs approximate each ellipse, with a separate radial deviation bound of `0.000273 * maximumRadius`; atlas tessellation has its own tolerance and budgets. Adjacent spans share exact endpoint coefficients and retain independent normal limits at C0 creases. The producer performs no image fitting and adds no end caps.

`realizeAutoMovieConvexSupportLoft` generates an open lateral mesh and its construction from fixed oriented XZ support planes with cubic metre offsets. Feasible triple-plane events preserve changes of boundary incidence; normals derive from each face equation and shared physical vertices retain separate normal fans. Supply plane, event, strip and vertex budgets. `faceChordBoundMeters` covers interpolation inside the numerical partition; `eventQualification` and `maximumBoundaryDefectMeters` separately disclose uncertified event isolation and boundary roundoff. `evaluateAutoMovieSupportSection` queries an admitted bounded section without tessellating it. Neither operation observes images or identifies hidden concavity.

For repeated sections with the same directions, `createAutoMovieSupportSectionQuery` copies and prepares the fixed normal pairs once. Its returned CPU query accepts fresh offsets without sharing results; a weak pair refuses only when feasible for that offset field. Release the caller-owned closure when its fixed directions are no longer needed.

## Physical performance

`AutoMoviePhysicalSimulation.compute(input, previous?, signal?, progress?)` precomputes admitted numerical targets through pinned Rapier 0.21.0 WASM. The optional synchronous callback reports completed intervals; `yieldEvery` services the host event loop in authored and native paths, and cancellation rejects without exposing a partial successful result. `identity(input)` independently admits and hashes current sampled input without allocating a solver. Raw and derived values transferred to native f32 must remain finite. Profiles declare SI masses, centres, inertias, collision surfaces, joint frames, ROM and finite actuator budgets. The adapter has no species branch. `derivePhysicalProfile` supplies engine models; the Human package supplies its own anatomical provider and clinical target producer. Root forces, joint torques, optional planted-support forces and actual-root support IK remain explicitly bounded. Tracking withdrawal retains declared passive damping and allows a physical fall.

In simulated modes, each target's `dynamicSegments` selects complete descendant subtrees: omission selects every segment, `[]` selects authored motion, and an array selects its named bones. Kinematic body mode keeps every segment authored. Pose samples are at `k/rate`; discrete ownership, relationship and strength fields in target `k` apply to the preceding interval `[(k-1)/rate, k/rate)`. Target zero initializes the world. For example, at 120 Hz a selection in target 90 starts at 89/120 s, rather than 0.75 s. `ownershipAt` reports the actual native boundary. Activation retains the actual native pose and COM/angular velocities. Returning segments use position-based kinematic authority for `handoffSeconds` (default 0.2 s), with C1 relative-rotation and root-position corrections from the actual entry state. Child origins and transport velocities follow their fixed joint anchors; cache frames record those native placements. Arbitrary-time playback approximates the intervening motion with the cache's linear-position and shortest-arc rotation interpolation. This return has animation authority rather than bounded dynamic force. `handoffLimits` declares inherited linear and angular residuals; their envelope decreases during return. Each native candidate is checked against floor, receiver and joint constraints; an obstructed candidate refuses. These discrete checks do not certify continuous collision freedom or dynamic feasibility. Tracking strength controls motor effort independently of segment ownership. Authored ownership does not withdraw tracking or activate released-body quality. A declared positive-contact release selects the complete dynamic body irreversibly.

Authored coordinate systems can differ from a fixed-pivot physical profile. `projectPhysicalTargets` projects parent-relative rotations into the native angular-coordinate box and reconstructs coincident anchors, reporting the maximum pose adjustment. `planPhysicalFloorSupportTargets` then fits declared support chains against their actual convex patches, retaining floor and endpoint residuals under bounded work. Both functions prepare motor goals; they never correct solved bodies. Per-target `unavailableSupports` reserves endpoints for authored motion independently of their actuator strength. An explicitly declared `releasedQuality.duringReflex` policy follows effective root withdrawal, including balance failure, while protective joint motors remain active.

Per-target `bindings` name a source collider, its actuator chain and a receiver collider on an actual scene body. `contact` fits toward that current surface, with compression bounded by the declared materials; `separate` only removes penetrating intent. `planPhysicalContactTargets` exposes the same bounded fitting and its remaining residuals. Simulation evaluates these relationships from actual scene states and sends the results through the existing capped joint motors. Kinematic evaluation uses the same relationships and geometric receipts with null impulse. A relationship is intent: a physical hit still requires an actual solver receipt, and an unreachable scripted outcome still fails.

`pointBounds` constrains a source bone-local point relative to a reference along an explicit world unit axis: `minimum <= dot(source - reference, axis) <= maximum`. Select exactly one reference `localPoint` or collider `shape`. A shape supplies its directional support point, including its offset, rotation and changing capsule/box features. At least one finite side is required. A reference on the same body follows the candidate articulation, including shared ancestors; an external reference uses the simultaneous actual snapshot. These intervals share `maximumBindings`, unique ids and the combined row/coordinate budgets with collider bindings. Each finite side consumes one residual row. Strictly violated inequalities supply signed local derivatives; exact one-sided boundaries remain free to move into clearance. Nonlinear acceptance retains the full clamped errors. The fitter reports named remaining metre errors, including unreachable or conflicting intent, and never moves solved bodies directly.

`AutoMovieStepPlanner` owns its precomputed schedule and swing policy. `peakPitch` is an explicit additional swing angle in radians, defaulting to zero. Physical balance recovery declares endpoint clearance, without an unimplemented pitch policy. Clearance and interpolation do not introduce an undeclared rotation.

Balance posture fitting uses the measured root frame and complete declared support patches. A reach-derived lowering request changes the separate root motor intent; it does not replace that measured frame. Stationary actual stance owns its joint posture, while reserved or moving endpoints retain their authored Cartesian task. This balance IK uses its declared iteration budget independently of `supportTracking.iterations`, whose zero value keeps the optional endpoint actuator force-only. Interval pose and twist goals are derived together and retained in controller checkpoints. Quiet drift and confirmed landing audits still compare against the original promised world anchors and accepted placements.

`actuation: "world"` declares external root and endpoint actuators. `actuation: "internal"` allocates a requested root wrench at actual floor witnesses under unilateral normal forces and a conservative Coulomb friction pyramid, then maps those forces through the support Jacobians by virtual work, τ = Jᵀw, into the existing torque-limited joint motors. Actual stationary floor constraints take priority over an independent endpoint world-point motor. Free endpoints retain their declared tracking. This adds no external wrench to an unsupported assembly; gravity compensation cannot suspend its centre of mass. It remains bounded virtual model control, whose actual response depends on native constraints and motor caps ([Pratt et al., ICRA 1997](https://www.ias.informatik.tu-darmstadt.de/uploads/Research/LocomotionSeminar/pratt_ICRA97.pdf)). `cache.supportWrenches` records requested versus allocated force and moment, their SI residuals and the root COM origin before integration. These predictions are distinct from achieved floor force measured by native contact impulses. Collider bindings can select a bone-local outward `target.normal`. Their surface goals, enabled self contacts, floor clearance and declared support endpoints are fitted together under the body's `maximumBindings` (default 16, at most 256), combined 1024-residual and 64-coordinate budgets. Fitted interval endpoints retain motion at every native substep. `samplePhysicalRecoverySupport` exposes measured swing ownership, confirmed landing offsets and authored handoffs for replay and audit.

Cache reads interpolate stored states without stepping a solver. Identity covers sampled inputs, profiles, policy, native settings and the cache protocol; unchanged prefix data permits exact checkpoint continuation. All-kinematic scenes skip dynamics worlds and native integration; collider fitting can still initialize query-only WASM. Mixed scenes give kinematic colliders their declared infinite-mass boundary; exaggerated bodies apply their stated incoming-impulse, gravity and compliance factors. Contact episodes retain causal per-step measurements, so early frames do not read later impact totals. Geometric receipts cannot contain solved impulse samples. Effects and local appearance require an explicit formula estimate for them, and the force overlay draws only positive solver samples. Compression-aware audits account only for each explicitly opted-in owner's compliant material allowance, including inter-body overlap.

`AutoMovieMotionAudit` accepts exactly one body description: a fully admitted physical `profile`, or `geometry: IAutoMovieMotionGeometry` for independent collision carriers, actual joint frames and optional observation-only `witnesses`. Geometry-only auditing makes no claim about mass, inertia, native connectivity or dynamic feasibility. Observation witnesses may supply constraint points; speeds and support promises name collision carriers. Every declared carrier and witness must have a finite sampled state. The physical path retains its complete mass, COM, inertia, joint effort and connected-tree admission. Sleeping native bodies need not generate new solved impulses: an absent sample is not a computed static pressure or an invented force.

`AutoMoviePhysicalPlayback.encode` packs completed display states, contact/recovery metadata, ownership transitions and support-wrench predictions. `decode` owns and checks archive bytes against an independently supplied current input identity and explicit byte/frame/segment budgets; `at(seconds)` then supports browser seek, playback, capture and audits without initializing WASM. Live caches and playback expose `ownershipAt(body, bone, seconds)`, resolving `dynamic`, `return` or `authored` from the same causal native-tick events, including contact-triggered activation and interrupted returns. `ownership` and `supportWrenches` also survive native checkpoint continuation and binary replay. Run simulation in a build process or Worker. A manifest bundled with an old archive is insufficient to prove current authored inputs. The generated production's `physics` command provides the Node precompute entry point.

The Node `recordViewerPlayback` review helper starts its WebM during navigation and preparation. Returned `elapsedSeconds` clock observations begin after clicking Play and are not video timecodes; a recording can contain preparation preroll.

Collision quality depends on the declared integration and constraint budgets. The historical actual Human free-drop qualification requested 120 Hz cached intervals, 32 native substeps, 64 solver iterations, 64 internal constraint sweeps, 0.0001 m contact error and 240 Hz contact frequency; its then-fixed floor still used the pinned native 60 Hz static setting. Lower internal iteration counts violated the small ankle carrier's limits; the ordinary defaults do not establish Human quality. Native defaults, alternative-solver comparison, measurements, current acceptance and unverified limits are recorded in the [campaign report](../../docs/campaigns/physical-performance.md). Its protocol-v8 periodic three-Human active reference and separate released-body measurements do not qualify the integrated fight or later cache epochs.

The adapter uses an immobile position-kinematic cuboid floor and submits its identical next pose every native step. Rapier 0.21's exposed frequency setter changes dynamic-contact softness while fixed contacts retain an independent, unexposed 60 Hz setting. This boundary makes the declared `contactFrequency` apply under load, with unchanged floor height, friction and infinite-mass behavior. Qualification still requires measured clearance, floor immobility and articulated outcomes; changing the boundary is not a guarantee of arbitrary-body stability.

Rapier's WASM determinism requires identical initial values and insertion order. AutoMovie's controller and interpolation also use JavaScript arithmetic; independent measured bit identity covers the tested build/platform family. Cross-machine AutoMovie equivalence is unmeasured. The finite immobile floor's bounds are required, and an escaping surface refuses instead of silently losing support. Profiles approximate physical envelopes; proxy contact success alone does not certify generated skin contact, injury or a complete film's scripted outcome.
