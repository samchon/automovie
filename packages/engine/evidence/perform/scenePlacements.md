## @evidence contracts/development/implementation.md#principled-implementation

An insertion-ordered Map joins all things with a staged world position so performShot validation and reference synthesis resolve positional targets from one convention.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One table owner admits both cameras and nodes without teaching each target consumer separate scene traversal rules.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Node precedence preserves the existing duplicate-id behavior while scene validation owns refusal; no camera is turned into a performing actor by being a positional target.

## @evidence contracts/development/common.md#meaningful-documentation

States world coordinates, camera inclusion, duplicate precedence, map ownership and borrowed translation values.

## @evidence contracts/development/implementation.md#efficient-algorithms

For C cameras and N nodes, O(C+N) time and storage build the lookup; each staged id must be visited once.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The shot gate and reference synthesizer share the completed table; translated vectors are borrowed rather than copied or recalculated.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The caller owns the map for the shot; scene translations remain scene-owned and no static scene cache or external handle persists.
