## @evidence contracts/development/implementation.md#principled-implementation

Regenerates the member with the engine's one instance-member function and places the model's own vertices with the member's transform, so the description is the member the viewer draws; the default rotation is the set heading as a normalized quaternion, the law the regenerator applies to a member with no rotation offset.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One owner for a single-instance subject, called by the subject describer only when the member is addressed, because a compact set stores a count rather than its members.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No set, slot or prototype is special-cased; a member the regenerator refuses is refused here instead of being described with guessed values, and an unknown model gives null bounds and no materials.

## @evidence contracts/development/common.md#meaningful-documentation

The documentation states how the member is regenerated and when it is refused, the model rule, the defaulting of prototype, rotation and scale, the bounds and units, and each parameter's role.

## @evidence contracts/development/implementation.md#efficient-algorithms
