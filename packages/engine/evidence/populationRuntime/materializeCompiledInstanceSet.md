## @evidence contracts/development/implementation.md#principled-implementation

Resolve the named route, prepend the default prototype once, regenerate slots into chunk/global summaries, then clone the compact laws and hash their canonical record. Host radius fallback remains approximate when measurements are absent.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

The compiler owns route resolution and compact snapshots; instanceSlot owns placement and the shared chunk fold owns summary arithmetic.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Default choice, fixed chunk size and fallback radius are declared existing policies, not per-content compensation; regeneration refusal propagates before a compiled record is returned.

## @evidence contracts/development/common.md#meaningful-documentation

Docs state route snapshot, complete prototypes, metre radius policy, point bounds and canonical SHA digest; callers own cloned output rather than an expanded member array.

## @evidence contracts/development/implementation.md#efficient-algorithms

Each of N slots is generated once for both summaries; along-route placement still costs O(NR), prototype selection/traits add their scans, and C chunks plus cloned route/prototype laws drive output storage.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

A single point feeds chunk and global folds in identical ascending order; the default prototype representation is reused in the compiled table and base fields. Mutable inputs prevent cross-call caching.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The compact record and cloned route/laws transfer to the caller; only current accumulators and returned chunks remain during compilation, with no task or native handle.
