Resolve every supported driver/node-channel reference through own semantic map entries and a literal placement prefix; enforce matching profile id and refuse missing/blank mappings, while pointer channels retain global addresses.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One mapping closure and exhaustive driver switch keep concrete binding separate from frame evaluation and authored profile policy.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Inherited constructor/prototype members never count as authored mappings; actual own reserved-name entries remain supported and no constraint is silently dropped.

## @evidence contracts/development/common.md#meaningful-documentation

Docs state pointer pass-through, prefix semantics and profile/mapping refusal; bounds and unchanged nested data remain borrowed in fresh limit/driver wrappers.

## @evidence contracts/development/implementation.md#efficient-algorithms

L limits and D drivers require O(L+D+R) reference visits plus output id text, with proportional mapped arrays and no scene-wide scan.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

A single mapping closure serves all fields in one binding; callers may retain completed bindings only while profile contents, own map and prefix remain unchanged.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The caller owns new limit/driver arrays, while authored nested bounds/curve data remain borrowed; no registry, graph, handle or task survives the call.
