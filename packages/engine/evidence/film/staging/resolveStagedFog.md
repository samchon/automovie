# src/film/staging/resolveStagedFog.ts#resolveStagedFog

## @evidence contracts/development/implementation.md#principled-implementation

Inverts the canonical FogExp2 transmittance law at the admitted positive axial depth. The unit-transmittance endpoint is canonical zero density. Located validation rejects an unrepresentably large density or coincident declarations.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Owns authored form selection and inverse FogExp2 calibration. The direct density gate and canonical color gate remain with their shared validators.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Uses the authored depth, transmittance and color without a visibility threshold, default weather, or silent conflict resolution.

## @evidence contracts/development/common.md#meaningful-documentation

Describes form selection, object identity, inverse law, camera-depth convention and difference from meteorological measurement.

## @evidence contracts/development/implementation.md#efficient-algorithms

Checks a fixed-size set of scalar and color fields and evaluates at most one logarithm, square root and division. Refusals may format authored values through the shared validators.

## @evidenceExclude contracts/development/implementation.md#reuse-equivalent-work

One stage declaration is resolved per call, with no cache over mutable authoring records.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

A valid reference produces one fog record sharing the supplied color object. Declared direct fog is returned by reference. Findings belong to the caller's collector.
