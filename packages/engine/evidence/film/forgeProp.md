# src/film/forgeProp.ts#forgeProp

## @evidence contracts/development/implementation.md#principled-implementation

Collects findings through ViolationCollector, delegates model validation and checks anchored digest representation. Iterative path coloring resolves articulation parent chains once and memoizes their first repeated node, preserving one located diagnostic per cyclic chain without repeated ancestor walks or depth-dependent recursion.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

The exported gate reads as the model contract, with the imported appearance and the articulation each in one private helper writing into the same collector, because both are reached only through a prop spec and report under its paths.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Never judges what an imported mesh depicts or guesses at registry and file contents it does not hold, and names no prop, part or profile; a malformed digest is reported once rather than again as a ledger mismatch, which is a reporting rule, not a compensation.

## @evidence contracts/development/common.md#meaningful-documentation

States every model, imported-appearance and articulation rule, what is left to the builder and why, that all violations are returned together, and that success returns the spec itself.

## @evidence contracts/development/implementation.md#efficient-algorithms

Indexes parts, sealed assets, LOD levels, articulation nodes and boneMap entries with maps/sets, plus validateModel and profileSemanticKeys costs and inspected text lengths. Iterative parent-chain coloring completes each unique node once in O(J) time and space, preserving authored diagnostic order without quadratic repeated walks.

## @evidenceExclude contracts/development/implementation.md#reuse-equivalent-work

A pure gate over one prop spec that coordinates no work across calls or consumers.

## @evidenceExclude contracts/development/implementation.md#bound-retention-and-release-resources

Retains nothing after return; success references the caller's spec, and failure owns a violation list bounded by a few violations per joint, asset, LOD level and mapped key plus the model's own.
