## @evidence contracts/development/implementation.md#principled-implementation

A fixed phase sequence in which each phase consumes only artifacts the previous one accepted, returning the first failing phase's diagnostics; resuming restages the program with the prior actors' translation, `atan2(x, z)` facing in degrees (the `facingDeg` convention `stageScene` reads, 0 facing +Z) and mount, because blocking must judge the authored stage before the prior state can be applied.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Sequences phases and owns only the resume merges; program and advice rules live in `validateShotProgramContract` and `validateShotPhysicsAdvice`, and staging, blocking, performance, realization and continuity sampling stay with their own functions, so this file decides order and diagnostic translation alone.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Names no shot, scene or fixture; the contract handed to realization takes the registration's id and a synthetic `<defineShot:id>` source because a direct compilation has no module path, and a realization failure tells the author to fix output rather than echo it into the contract.

## @evidence contracts/development/common.md#meaningful-documentation

States the phase order, the single builder call, which diagnostic each kind of throw becomes, and exactly which prior-beat facts open the stage, the scene and the opening snapshot, and how runtime plants merge.

## @evidence contracts/development/implementation.md#efficient-algorithms

Adds actor/node/plant merges and deep copies of event samples, poses and advice to the delegated build, staging, performance and realization costs. Copy work scales with the nested records and text copied. One prior-actor map and one replanted-node set serve the resume merges; the second stageScene call runs only with a previous beat. Author-supplied builders and runtime callbacks have their own cost.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Within one call each phase's accepted artifact is handed forward rather than recomputed, the prior-actor map is built once for all three resume merges, and one continuity input feeds both the opening and the closing snapshot; across calls nothing is reused, because the builder is author code whose result the engine cannot prove equal for the same context.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Holds intermediate phase artifacts for the call; success returns scene, motions, shot, continuity and realization plus deep-cloned event samples and advice. Scene fields and accepted motion objects can retain caller-owned references; the result does not retain the runtime capability container.
