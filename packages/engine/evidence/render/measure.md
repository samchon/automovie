## @evidence contracts/development/implementation.md#principled-implementation

Measure canonical primitive or bicubic realization, or stated mesh attribute/index lengths, into the declared geometry byte model; a request-owned model-id cache shares equivalent model costs and clears tier attribution when citations disagree.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

This canonical prototype measurement owns topology/attribute arithmetic while population multipliers and frame passes remain in inventory phases.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Primitive counts come from tessellate rather than a second formula table; model ids must uniquely denote unchanged definitions for the cache lifetime. Bytes describe the declared prototype buffer profile, not every native clone or instance stream.

## @evidence contracts/development/common.md#meaningful-documentation

Docs identify shared model cost, canonical tessellation and tier ambiguity; cached rows are mutable request-owned records returned by reference.

## @evidence contracts/development/implementation.md#efficient-algorithms

First measurement scans P parts and generated vertex/index output, retaining one cost/material-id set; later equivalent id citations are expected O(1) lookups. Primitive tessellation allocations are included in the first cost.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

One inventory-owned cache shares prototype measurement across nodes, prototypes and tiers; it is never reused across a different mutable subject or model definition.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The cache owner releases all cost rows at request end; temporary tessellations are not retained, and this function opens no native geometry handle.
