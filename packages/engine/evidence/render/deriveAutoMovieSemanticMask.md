## @evidence contracts/development/implementation.md#principled-implementation

Collect semantic entity/owner/node claims, including one face claim per surface graphic track joined by its render root name, refuse duplicate ids and palette excess, add bounded instance-slot claims, then allocate FNV-derived RGB colors in id order with forward probing and hash the complete canonical v2 payload.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Claim derivation, capacity and canonical payload identity have separate owners; logical containers paint no pixels and actual drawable node names join the viewer to their tightest semantic claim.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

The fixed RGB/background budget bounds output; instance sets that cannot fit retain set identity and explicit unaddressed gaps. Unbound declared simulation domains are not silently dropped and no fixture controls colors.

## @evidence contracts/development/common.md#meaningful-documentation

Docs explain id-order invariance, collision effects of additions, owner chains, simulated drawable naming, duplicate/capacity refusal and bounded slot coverage.

## @evidence contracts/development/implementation.md#efficient-algorithms

Entity/node/binding scans and sorting precede output-bounded slot expansion; N claims require O(N log N) ordering plus hash bytes and probing, whose worst case can approach O(N^2), rather than a guaranteed collision-free hash claim.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Shared node naming, capacity, FNV and canonical digest owners define one law; no palette cache survives changed claims, id collisions, ownership or fields.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Claim maps/sets are call-owned and the complete mask transfers to the caller; retained output is bounded by palette policy, with no color buffer, renderer handle or task.
