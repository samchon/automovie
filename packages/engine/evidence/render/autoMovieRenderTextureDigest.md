## @evidence contracts/development/implementation.md#efficient-algorithms

S source uses and M material slots build grouped records, then sort records/group positions and serialize B bytes; work is O(M+S log S+B) plus retained target/runtime rows, with O(S+B) call storage.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

A source record serves all uses in its equality class within this call; cross-call reuse requires unchanged facts and sharing relations, which object or asset identity alone cannot prove.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources
