# src/geometry/construction/AutoMovieSolidJoinNormalCheck.ts#AutoMovieSolidJoinNormalCheck

## @evidence contracts/development/implementation.md#principled-implementation

Retains the original two neighbouring columns, after/before point reads, centre first derivative, cross product and strict consecutive dot > 0 predicate at each share. The failed predicate distinguishes negative, zero and nonfinite dot without adding a finite admission; positive Infinity therefore still passes.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One observation owner returns a rails or unfolded-blend failure to Join. The comparison describes the already read operands, and a missing neighbour reports its requested address.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Changes no threshold, share, ordering or geometry and performs no diagnostic source/rail/kept query. A zero dot is not asserted to be a reversal or a zero vector, and NaN/Infinity remain explicit strings rather than JSON null.

## @evidence contracts/development/common.md#meaningful-documentation

Gives input ownership, radian neighbour spacing and the exact sampled predicate. Along is an unscaled world point difference in mm, first is mm per unit blend share, their normal is an unnormalized cross product and its norm/dot retain those product units.

## @evidence contracts/development/implementation.md#efficient-algorithms

For C columns and S shares, retains the existing 2C column calls and 3C(S+1) blend reads with O(CS) fixed-vector arithmetic. Only a failure computes two norms and serializes three fixed-size rail records plus the two compared observations.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The exact first vector feeds both cross and failed context; the original dot is read once. Three previous-share vector references avoid rebuilding a prior blend or allocating successful observation snapshots.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Borrows columns/readers for this synchronous call and retains only the preceding normal/along/first within each column. A returned failure owns one string; no source object, callback, snapshot history or external handle is retained.
