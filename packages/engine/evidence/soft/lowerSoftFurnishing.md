## @evidence contracts/development/implementation.md#principled-implementation

Domain admission, state membership and time/budget checks precede canonical rest or fixed-step replay, then the same solved particle field supplies surface geometry. Self-collision returns unsupported rest geometry rather than being presented as solved.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Lowering owns analysis status and joins shared validation, quantization, simulation and surface owners; the result does not install a renderer or live boundary host.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Requested unsupported self-collision is named, not hidden behind still geometry; numerical solver failures are not swallowed or represented as successful frames.

## @evidence contracts/development/common.md#meaningful-documentation

States status applicability, surface source, failure propagation and unwired host reach.

## @evidence contracts/development/implementation.md#efficient-algorithms

Validation and mesh derivation scan P particles; simulated mode adds O(P*K*(I+C)) replay, while rest mode still allocates anchored configuration and surface arrays. Storage includes O(P) result and temporary geometry.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The selected state and computed particle field serve one surface derivation; no prior frame is reused under mutable domain/state/time assumptions.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Fresh mesh/state arrays and analysis rows transfer to the caller; failed admission retains no geometry, and thrown simulation retains no playback cursor or render task.
