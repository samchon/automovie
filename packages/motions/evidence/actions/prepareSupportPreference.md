# src/actions/prepareSupportPreference.ts#prepareSupportPreference

## @evidence contracts/development/common.md#meaningful-documentation

Defines the stance-local shape and changing placement inputs.

## @evidence contracts/development/implementation.md#principled-implementation

Projection and FK of the authored angular configuration are translation invariant. A single zero-root observation supplies root-relative material points and the minimum collider height. Each key places those values using its current contact targets and predecessor.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

An unspecified stance returns its entry preference. Otherwise the angle-only shape and its bounds precede one rigid placement reader.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Retains the contact form, anchor averaging, grounded-contact test and complete collider floor. Every key still receives its own fit and refusal policy.

## @evidence contracts/development/implementation.md#efficient-algorithms

One FK and collider reduction per authored shape replace up to two FK reads per key. Placement is linear in the number of contact targets.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Each reader closes over its own stance geometry. Targets remain evaluated at each key, including target changes caused by newly laid support.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Fixed projected frames and one floor value release with the planning operation. Query roots and target reads are not retained.
