## @evidence contracts/development/common.md#meaningful-documentation

States when a strike, a defence or a stopped limb's ride is read back while it is planned, the composition that causes it and the one the author writes instead.

## @evidence contracts/development/implementation.md#principled-implementation

The cycle is a composition the author can repair, so it is a `participant` refusal on the `sync` axis with the composing fix, not a plain error.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One function builds the refusal for the punch, the kick, the defence and the ride, so the reason and the fix are stated once.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Each law still refuses at its own re-entry guard; nothing is retried, skipped or planned from a stale reading.

## @evidence contracts/development/implementation.md#efficient-algorithms

One object built on the refusing path only; no planning work is added.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The refusal reads only its arguments; nothing is cached or shared.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The refusal retains its strings only and is released with the thrown error.
