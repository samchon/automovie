Retains original vector/carry work and native hip FK; an explicit parent workspace shares equal FK prerequisites with the same current blade trunk observation. No measured speedup is claimed.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Retains no input or result. The lower borrows its optional reader only through synchronous return/failure, and fresh authored posture/goals contain no workspace or query history.
