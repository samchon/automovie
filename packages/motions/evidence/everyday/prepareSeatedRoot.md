## @evidence contracts/development/common.md#meaningful-documentation

States fixed body/heading provenance, degree/world-metre units, first-use geometry acquisition and fresh current root ownership.

## @evidence contracts/development/implementation.md#principled-implementation

Uses seated.root's same canonical heading quaternion, native seated.offset and rotated socket subtraction. Only the unchanged rigid offset prepares; each actual desired point still runs the original Vector3.subtract.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One lazy fixed rotated offset precedes one fresh root subtraction; the raw root method remains the standalone numeric path and the rise's fixed-heading entry reads consume this producer.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Keeps the original heading/offset arithmetic and fresh subtraction even at repeated or endpoint points. No joint, limb goal, contact, articulation, tolerance or cached achieved root is introduced.

## @evidence contracts/development/implementation.md#efficient-algorithms

Across Q points, canonical heading construction, body socket lookup and quaternion-vector offset rotation run once; every current point retains its three original subtractions and output vector. Runtime speedup is unmeasured.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The owning action establishes unchanged body/rest/socket and heading values. A changed heading or geometry requires another reader; desired points and returned roots are never retained or keyed.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The owning action retains its fixed body/heading and at most one private rotated offset until release. Every result is a fresh vector containing no reader, input point, posed map, FK/ROM source or query history.
