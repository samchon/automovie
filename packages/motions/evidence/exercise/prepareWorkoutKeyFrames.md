## @evidence contracts/development/implementation.md#principled-implementation

ExerciseKey.posed owns the same root-zero/yaw-zero raw representation as the original trunk search. Every actual candidate follows ordinary seeded admission and current range projection; callback-produced clinical data are never certified from JSON equality or replaced by an earlier shape.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One search owns bounded FK/ROM metadata and an optional fixed-name reader. Each key constructs its actual raw view, resolves normally and performs current requested FK before returning the observations used by real height/bounds consumers.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No caller-provided pose, resolved flag, altered joint, guessed target or sampled table bypasses admission. All original callbacks/candidates, current Eulers, range values, fits, FK and scalar observations remain, including changing or unsupported key context.

## @evidence contracts/development/implementation.md#efficient-algorithms

Fixed name indexing and genuine ROM/exact FK prerequisites prepare once across Q trials. Every trial retains complete current nonlinear projection and actual demanded FK; no ineffective source snapshot, JSON comparison or private-proof copying is built for arbitrary changing keys, and speedup is unmeasured.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Only unchanged body/rig/profile demand and native static projection/dependency metadata share. Current clinical keys always resolve normally; no earlier joint projection, angle, height, floor verdict or FK answer is substituted.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The synchronous search owns bounded FK/name/ROM metadata and its body until return or throw. No source pose, candidate history, output or reader enters the returned action/key; current raw views and fresh maps retain no workspace.
