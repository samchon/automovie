## @evidence contracts/development/implementation.md#efficient-algorithms

Scans the template's segments for one containing interval, reads one displayed pose and produces the requested phase references. A second linear pass checks whether a successor owns the displayed sample. The bearing-floor reader evaluates the entry sole sockets once.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

A held pose is identical at every phase by definition, so the pose take borrows the same pose at each phase.
