## @evidence contracts/development/implementation.md#clear-and-simple-structure

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Every actual articulation read, inversion probe, insertion roll rank/refinement/fit, full target Bend and original place/normal/curl/contact policy remains. Wrist-only observations omit solely the default elbow sweep whose result the lean discarded; no candidate, balance scan, bisection or tolerance changes.

## @evidence contracts/development/implementation.md#efficient-algorithms

One fixed surface/rest basis or insertion axis/grid serves Q actual requests. Wrist-only reach requests omit an unconsumed bounded Bend sweep and repeated hand offset work; all current frame/alignment arithmetic and insertion fits remain actual. Runtime improvement is unmeasured.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The plan fixes body/side/mechanism/initial place/clock and immutable tool geometry. A query at an actual second reads the articulated part where it is at that second, so a reach to a part moving during it intercepts the part where it is at contact (the hand's online correction toward a moving target, Brenner and Smeets); a plan-time query with no second executes the adjacent-float progress inversion to its stroke time. A still part reads the same place either way.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The operation owns fixed metadata and constant-size prepared hand/axis geometry until release. Each query releases its current placed frame and wrist/target scratch on return or throw, without retaining poses, times, fitted answers, FK loans or history.
