## @evidence contracts/development/common.md#meaningful-documentation

Gives every option, the default views, the output, what the record's section holds, and the exit status.

## @evidence contracts/development/implementation.md#principled-implementation

A case is a subject like any other: the harness supplies its data and its verdicts, and the shared host plans, draws, lays out, records and compares, so a motion case takes the request every subject takes.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Read options, build cases, open one host, capture each case, report.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Unknown cases throw; request options are refused by the shared reader; a failed verdict, an undrawn cell or a case the host could not capture fails the run, the last without stopping the other cases.

## @evidence contracts/development/implementation.md#efficient-algorithms

One page build and one browser for every case of a run; each case draws its instants times views times passes.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The host's built page and browser serve every case.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The host is closed on every outcome; each case's page is closed by the host.
