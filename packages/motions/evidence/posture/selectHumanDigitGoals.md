## @evidence contracts/development/common.md#meaningful-documentation

Defines observational frame demand, independent world-goal domain, canonical body premise and full fallback.

## @evidence contracts/development/implementation.md#principled-implementation

Digit fitting writes only its named three clinical joints after all limbs; an observation depends on it only when one of those joints is an actual skeleton ancestor. World goals introduce no other digit dependency.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

This selector owns only dependency/eligibility decisions; HumanDigitFit preserves ordered authored admission before omission and the existing engine solver handles every retained goal unchanged.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Unknown/attached/nonfinite goals, missing chain/surface data and unsupported fields return the complete request; no raw goal, coupling, soft-IK rate, sample or physical acceptance bound changes.

## @evidence contracts/development/implementation.md#efficient-algorithms

Builds O(B) parent metadata, visits requested ancestors and scans at most ten three-joint goals; independent unobserved digits require no iterative fit, while a reduced request still receives ordered authored FK admission.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Reads current goals and actual canonical ancestry, borrowing retained goal records unchanged; no pose, target, previous digit solution or numerical callback is cached.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Temporary parent/ancestor sets end with selection; the at-most-ten-entry output borrows original goals and no body, reader, solve result or query history is retained.
