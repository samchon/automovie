## @evidence contracts/development/implementation.md#principled-implementation

A fitted chain changes its three joints and a contacting leg may change its toes; an observation depends on it only when a changed joint is an ancestor. Leg/contact re-aim has no arm input, while an arm reads both thighs, rival/placed arms and coupled clearance, so any needed arm retains every fit.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

This selector alone owns the supported dependency proof; seeded retains ordinary root turning, complete joint clamping and unchanged actual fitting of selected goals.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

A goal with any field beyond its free point, bend, rotation and a leg's contact and planting returns the original full goal object for ordinary admission; retained foot contacts still run the original re-aim and toe correction, and no goals, thresholds, seeds or audit demands change.

## @evidence contracts/development/implementation.md#efficient-algorithms

Builds O(B) parent metadata and visits at most B ancestors for each of K requested bones, then tests four constant-size chains; omitted free limbs perform no target solve, without a measured speedup claim.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Uses only the current authored goals and actual skeleton ancestry; selected goal records are borrowed unchanged, with no previous request/result or mutable identity cache.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Parent/ancestor sets end with this synchronous selection; the returned at-most-four-member record borrows original goals only and retains no body, reader, numerical answer or external handle.
