## @evidence contracts/development/common.md#meaningful-documentation

Defines genuine translated-object provenance, complete ordered own-data snapshots, numeric/root/goal schema, callback refusal and replacement-safe checking.

## @evidence contracts/development/implementation.md#principled-implementation

The sole caller passes actual structuredClone/point-construction output, whose own data flags are known from construction. Closed containers/finite triples/vectors establish a complete graph; capture stores primitive/child values without rereading descriptors. Consumption compares only original native-object descriptors and values, independently of JSON serialization.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Construction records a bounded list of native nodes; the returned checker compares that list without following any new child. HumanPosturePreparation owns issuance, live rig checks, actual JSON observations and cold fallback.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No caller-set resolved state or JSON hash proves equality. Only the actual owned translator can supply the initial graph; extra metadata, functions, unsupported prototypes or inherited JSON hooks decline whole-pose evidence. A changed property/descriptor/order/child cannot certify cached numerical output.

## @evidence contracts/development/implementation.md#efficient-algorithms

O(J+G) construction stores one values/key array per native node, without per-field descriptor objects; only later consumer checks read current descriptors. No redundant issuance check is needed because a closed own-data graph with no inherited JSON hooks cannot execute a callback during its signature walk. Retention is O(J+G), speedup unmeasured.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Actual construction proves original native objects/data flags and pure serialization before public escape. Later Object.is scalar/child plus exact own metadata checks establish current prerequisites; source solve/rig proof remains separate. No prior mutable-output verdict is retained and no replacement child is observed.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

One weak candidate capability owns only its bounded original-node snapshot until that candidate is released. Replacement children are neither traversed nor retained, no public pose or reader is borrowed, and no timestamp/history/handle collection is added.
