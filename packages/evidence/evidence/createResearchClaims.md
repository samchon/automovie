## @evidence contracts/development/implementation.md#principled-implementation

A native Markdown file claim with detached evidence files keeps the study's text free of answers while each study still owes every research item; the reference root joins the given skills root with the installed `contracts/story` layout, which native Evidence resolves against the configuration directory.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One claim with fixed study and answer locations; the caller decides whether to enable it and where the shared skills tree is.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

The study, index and answer paths are the scaffold layout's documented locations, not fixture paths; the default root is the standalone layout.

## @evidence contracts/development/implementation.md#efficient-algorithms

Builds one fixed-size claim tree in constant time; it performs no discovery or file I/O.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

A fresh object is returned so one configuration's edits cannot reach another.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The caller owns the returned claim; nothing is retained.

## @evidence contracts/development/common.md#meaningful-documentation

The comment states the respondents, the contract, which tree it is read from and where the answers live; the option states its form and default.
