## @evidence contracts/development/design.md#principled-representation

The evaluator checks supplied limit values as nonnegative safe integers and compares the fixed metric population inclusively with supplied inventory numbers. It carries the selected tier unchanged; version, nonblank tier and closed metric keys are typed/caller premises rather than complete runtime admission here.

## @evidence contracts/development/design.md#minimal-and-owned-surface

A versioned tier and partial metric map express agreed cost limits without letting budgeting choose or disable renderer-owned passes.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Omitted metrics remain unbudgeted and no limit is inferred from current cost. Invalid fractional or nonfinite limit values throw, but untyped unknown metric keys with valid numbers do not enter fixed-metric evaluation; callers must preserve the declared vocabulary and supply valid measured inventory.
