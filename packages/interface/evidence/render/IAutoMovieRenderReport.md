## @evidence contracts/development/design.md#principled-representation

Budget evaluation emits one finding per fixed metric, reduces aggregate state by over then incomplete precedence and hashes fixed-position JSON tuples covering every finding field, including contributor sources and recovery, plus mask and target identity.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Fixed metrics and caller-selected top-K attribution bound new finding records while omitted counts and costs preserve remaining attribution; borrowed target assets and string bytes still determine full retained or serialized report size.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

All-unbudgeted within means no agreed threshold, not universal clearance. Explicit gaps cannot become measured success. Finite inventory values and current mask/target digests are caller premises: evaluation neither remeasures a frame nor independently checks attribution totals or reseals the borrowed target.
