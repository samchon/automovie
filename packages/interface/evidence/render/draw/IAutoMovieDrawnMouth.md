# src/render/draw/IAutoMovieDrawnMouth.ts#IAutoMovieDrawnMouth

## @evidence contracts/development/common.md#meaningful-documentation

States what the record is and when each member is present; each member states its unit.

## @evidence contracts/development/design.md#principled-representation

The actor and the value of each form the subject read at the drawn second, so the host sees what each figure was handed without reading pixels.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Written by the draw page's recorder, carried by `IAutoMovieDrawResult` and `IAutoMovieDrawnPass`, and read by render's lip-sync measure, which tells a jaw-driven figure from a viseme-driven one by which member is present.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

An unread form is absent rather than zero, because a zero jaw and an unread jaw mean different things to the measure.
