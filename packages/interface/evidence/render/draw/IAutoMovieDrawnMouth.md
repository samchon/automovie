# src/render/draw/IAutoMovieDrawnMouth.ts#IAutoMovieDrawnMouth

## @evidence contracts/development/common.md#meaningful-documentation

States what the record is, when the page writes it and when each member is present; each member states its unit.

## @evidence contracts/development/design.md#principled-representation

The actor and the value of each form its figures showed at the drawn second, so the host sees what each figure drew without reading pixels.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Written by the draw page's `AutoMovieDialogueMouthStage` from what each bound figure reports showing, carried by `IAutoMovieDrawResult` and `IAutoMovieDrawnPass`, and read by render's lip-sync measure, which tells a jaw-driven figure from a viseme-driven one by which member is present.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

An unshown form is absent rather than zero, because a zero jaw and an unshown jaw mean different things to the measure.
