# src/analysis/IAutoMovieAcousticRequest.ts#IAutoMovieAcousticRequest

## @evidence contracts/development/design.md#principled-representation

A Sabine diffuse-field study: absorption area, reverberation time `0.161 V / A`, room constant and receiver levels follow from the volume and the declared members, and the settings are digested so an identical request seals an identical run.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Run header fields plus one list per physical role, surfaces, partitions, sources and receivers, and the targets, so validation and the settings digest each read one field per concern.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Malformed members throw rather than becoming gaps or unsupported runs, empty optional lists turn their metrics into stated gaps, and no study id or subject is special-cased.

## @evidence contracts/development/common.md#meaningful-documentation

States every throw condition of the analyzer, which fields enter the settings digest and which go into the run header, the units, the at-least-one surface rule, and what each empty list makes a gap.
