# src/analysis/IAutoMovieDaylightRequest.ts#IAutoMovieDaylightRequest

## @evidence contracts/development/design.md#principled-representation

A study is beam, isotropic sky and point-luminaire illuminance over one workplane at one declared instant, and every field that changes the answer is digested so identical requests seal identical runs.

## @evidence contracts/development/design.md#minimal-and-owned-surface

The read-only context is referenced rather than copied into the request, and building-owned shades stay a separate list from context occluders, so ownership is kept by which field a solid arrives in.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

An unimplemented sky model yields an `unsupported` run and a study with no emitter yields `not-run`, rather than a substituted model or a zero illuminance claim.

## @evidence contracts/development/common.md#meaningful-documentation

States every throw condition of the analyzer, how the instant decides the run domain, what the settings digest covers, that only `isotropic` is implemented, and that the sky sample count has no upper bound.
