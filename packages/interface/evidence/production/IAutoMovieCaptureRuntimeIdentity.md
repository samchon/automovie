## @evidence contracts/development/design.md#principled-representation

Capture identity declares package/support content, executable provenance, platform, raster scale and observed graphics facts. Render job identities include this record in chunk hashing, but the production collector/validator is retired; truthful current observations and complete content closure remain host premises rather than properties proven by a digest of this record.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Package closure, browser selection, platform, launch mode and graphics are separate record groups, exposing which observation supplies each part of capture reproducibility.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Version strings alone do not prove byte identity, and system channels explicitly declare an unsealed boundary. Render planning validates its outer source/dialogue digests but does not independently inspect every capture package, browser executable or graphics observation in this metadata.

## @evidence contracts/development/common.md#meaningful-documentation

Describes package and browser-support digests with file and byte counts, executable selection and unavailability, host architecture, device scale, requested backend and actual graphics identity.
