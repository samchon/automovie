## @evidence contracts/development/common.md#meaningful-documentation

Names the project, registered source, cut occurrence, provenance, optional parent and replay mode which the production host uses on restart.

## @evidence contracts/development/design.md#principled-representation

A literal version and replay mode select the supported restart semantics; an optional parent binds a branch to immutable bytes of its original saved take.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Reuses film's source pointer convention and delegates file access, editorial admission and owner reconstruction to their respective runtimes.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

The payload stores references and scalar identity evidence; it carries neither sampled poses nor engine caches, and an authored replay makes no claim of native solver restore.
