## @evidence contracts/development/design.md#principled-representation

Engine validateTextureAssets reads these rows to authorize exact production/model or scene image uses and checks host-supplied header facts, stale uses and color intent. It does not hash bytes or admit all consumer kinds; current digest, path safety and acquisition history remain host premises after production inventory retirement.

## @evidence contracts/development/design.md#minimal-and-owned-surface

One ledger entry keeps current identity separate from optional original acquisition, generation, licence and ordered processing history, avoiding a false equation between processed bytes and original source bytes.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Descriptive source and licence fields cannot prove current byte identity or legal authority; model and motion provenance cannot select an unregistered appearance or animation take merely by being present.
