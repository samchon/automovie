## @evidence contracts/development/design.md#principled-representation

Closed code, severity and pipeline phase classify a finding while target and optional file locate it. Engine validators return these rows and compileDefinedShot translates realization findings into its failed result; arbitrary hosts must decide how returned errors block their operation.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Machine classification and human correction prose occupy separate fields, allowing clients to group findings without parsing messages or losing the exact author action.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

An unchanged retry cannot substitute for the stated correction, and a null file explicitly denotes a finding with no single file owner rather than inventing a misleading path.

## @evidence contracts/development/common.md#meaningful-documentation
