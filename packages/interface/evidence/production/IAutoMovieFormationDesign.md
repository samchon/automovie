## @evidence contracts/development/design.md#principled-representation

A count, layout, world anchor, heading and safe-integer seed define reproducible member positions. Count bounds, layout capacity, model group identity, LOD tier order and unique hero slots are caller premises; the engine materializer does not supply the retired production design admission.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Compact shared placement and its distance tiers are separated from sparse hero overrides and source-authored motion; capability labels coordinate review without becoming executable behavior.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Regenerated slots including heroes carry the declared model group, and capability labels confer no permission or proof. Materialization subtracts the authored hero array length globally but distinct hero slots per chunk, so unique valid overrides are required for consistent counts and are not established by this type.

Defines count and seed bounds, layout units, shared model group and LOD tier ownership, portable identity and the non-authorizing capability and hero semantics.
