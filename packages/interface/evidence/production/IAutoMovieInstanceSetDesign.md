## @evidence contracts/development/design.md#minimal-and-owned-surface

Keeps general instance placement separate from formation capabilities, hero promotion and motion channels; optional prototypes extend the default model group with explicit weighted choices, each with its own optional distance tiers.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

Model group references, LOD tier order, count limits, seed and layout capacity are authoring premises, not checks performed by this type or the compact compiler. Building populations receive the narrower validateBuiltPopulation check; world compilation regenerates slots and rejects missing routes and nonfinite sampled positions but does not replace the retired whole-design gate.

## @evidence contracts/development/common.md#meaningful-documentation
