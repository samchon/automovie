## @evidence contracts/development/common.md#meaningful-documentation

States the two kinds, which checks engine admission owns and which render or a host owns, and when decoding happens.

## @evidence contracts/development/design.md#principled-representation

A closed union on `kind` separates bytes carried with their digest and origin from a ledger asset path, so no record mixes both.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Engine admission checks the records, render's font-source function decodes them, and productions author them; the asset kind reuses the ledger for digest and licence instead of repeating them.

No optional `data` beside an optional `asset`; each kind's fields are all required.

# src/typography/IAutoMovieFontSource.ts#IAutoMovieFontSource.IEmbedded

## @evidence contracts/development/design.md#principled-representation

## @evidence contracts/development/design.md#minimal-and-owned-surface

## @evidence contracts/development/design.md#prohibited-design-shortcuts
