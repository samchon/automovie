# src/environment/IAutoMovieEnvironmentContribution.ts#IAutoMovieEnvironmentContribution

## @evidence contracts/development/design.md#principled-representation

Producers allocate owned identities from the instance id and return all positions and support surfaces in world metres. Named rigid frames follow the same placement. Object clips carry shot-local seconds and cite the emitted nodes.

## @evidence contracts/development/design.md#minimal-and-owned-surface

Reuses canonical stage, model, prop, architecture and world records. Omitted populations contribute no records. Anchors give the other modules places to attach without parsing geometry.

## @evidence contracts/development/design.md#prohibited-design-shortcuts

A module owns its records, including all internal references. The composer retains their identities and neither infers contacts from a mesh nor resolves arbitrary imported references by rewriting strings.

## @evidence contracts/development/common.md#meaningful-documentation

States the world frame and owned identities, the local anchor paths, optional population semantics, and the object clip clock.
