# @automovie/production

Orchestrates typed production compilation through the engine, authored reader editions, Oracle geometry queries and preview, receipt-backed render publication, and shot repaint. Preview and repaint use supplied project adapters. It has no network authoring surface.

What an authoring agent knows comes from its project and from what this package refuses: every refusal names the invariant it enforces and the correction that owns it.

## Use

```bash
npm install @automovie/production
```

| Entry | Purpose |
| --- | --- |
| `@automovie/production` | Production building (`openAutoMovieProduction`, `AutoMovieProductionBuilder`), reader editions (`AutoMovieProductionBinder`), Oracle queries and preview (`AutoMovieProductionOracleService`), project render-bundle publication (`AutoMovieProductionProject`), shot repaint (`AutoMovieProductionRepaintService`), and the diagnostic catalogue |
| `@automovie/production/validation` | Filesystem-free admission of scene and sequence artifacts (`validateSceneArtifact`, `validateSequenceArtifact`) |
