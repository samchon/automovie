# src/inspectAutoMovieVerificationReview.ts#inspectAutoMovieVerificationReview

## @evidence contracts/development/common.md#meaningful-documentation

States that the selected receipt's reviewer, activity, file, frame scope and decision govern the outcome.

## @evidence contracts/development/implementation.md#principled-implementation

The review owner admits the selected receipt's decision and clock. Bind its named subject and path to the current movie digest, then require the stated activity and frame coverage. The result reports the selected receipt, the activity and the reviewer's decision.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

One adapter reads the selected observation and maps its verified identity and coverage to a scoped result. Malformed JSON and a rejected receipt retain the selected evidence path for repair.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

A locator, a still where playback is named, an earlier hash or partial frame range cannot establish the decision this criterion requires. The check reads its selected receipt even when several decisions exist for the same bytes.

## @evidence contracts/development/implementation.md#efficient-algorithms

One observation read and one movie digest lookup. Status comparisons are constant time after admission of the receipt.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The injected evaluator reader shares a movie digest for an unchanged file during one verification run. The selected named decision is read each time.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The observation and output remain local to the call. The shared digest reader owns and releases the file stream.
