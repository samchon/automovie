## @evidence contracts/development/common.md#meaningful-documentation

Describes new marks, explicit rebinds and replay, how they are identified, and the CLI paths and outputs.

## @evidence contracts/development/implementation.md#principled-implementation

Matches the published report to the video name and actual SHA-256, then derives only the rational frame addresses of the same already decoded continuous grid. Reopening uses the saved digest and Render's frame planner. An explicit replacement selection establishes the new scope; the old receipt remains separate.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Admit the old receipt once when provided. Creation verifies the new publication, selects the frame window, and writes the mark. Replay checks the old identity, extracts context, and outputs the files.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

A stale or failed publication cannot certify a new mark. Missing decoded evidence and ambiguous occurrences are reported as limits. A stale file retains the old address and reports an absent shot only from a verified replacement cut for the same subject. A scoped human observation is explicit input and is not inferred from extraction.

## @evidence contracts/development/implementation.md#efficient-algorithms

Hashes the source once per mark and parses its render report. Frame bounds use binary search and cut attribution visits its entries once. Replay hashes the file again around extraction and selects at most four output images. Decoding cost depends on the source file.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Reuses timing proven by the publication audit only when the bytes, native grid and expected rate agree. Each replay checks the current bytes before reporting its stills.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Records are exclusive at their chosen paths. Replay owns only a fresh frame directory and removes it on failure. Kept receipts and at most four stills per successful replay belong to the production.
