# src/environments/furnishings/createEnvironmentProp.ts#createEnvironmentProp

## @evidence contracts/development/common.md#meaningful-documentation

States the shared occurrence identity, named anchors, ordinary placement and optional relation, articulation and appearance semantics.

## @evidence contracts/development/implementation.md#principled-implementation

The affordance frames authored on the rigid model are the only source of contact orientation. The shared model adapter places them with the same instance transform as the staged node and carries the existing prop specification.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Collects only the semantic anchors and delegates generic staging to environmentModel and relation admission to the environment's normal prop validator.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No bounding-box contact is inferred for a model without affordances, and an unclaimed support is an attachment position without a bearing assertion. An omitted articulation gives a rigid prop spec, preserving any authored rest affordance frames.

## @evidence contracts/development/implementation.md#efficient-algorithms

Reads the model's declared affordances once and uses one entry per affordance. Preparing and emitting the model otherwise follows the common environmentModel path.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The definition captures the model and the derived anchor entries once for all its occurrences. Instance ids, placement and contact transforms are computed per occurrence.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The returned definition retains only its model, prop claims and an anchor map bounded by the model's affordance count. It owns no external resources.
