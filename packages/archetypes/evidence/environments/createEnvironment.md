# src/environments/createEnvironment.ts#createEnvironment

## @evidence contracts/development/implementation.md#principled-implementation

Depth-first reference resolution computes each rigid metre frame from its parent before invoking its definition. Origins involve only placement dependencies. Named anchors first require the producing definition. A path stack names back edges. The stable occurrence path and optional seed are encoded as a pair. Stage data and prop claims run the existing support and prop gates. Every staged piece's support is then reported, not refused, by the engine's `environmentSupportReport` over the merged set, models, props and space, the wall mounts the items return and each building at its own placement frame's height.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Resolution owns pose and dependencies. Existing subject-field merge and space merge own ordered concatenation. The result separates existing stage inputs from runtime inputs at their consumer boundary. The composer only gathers the mounts and building heights the support report needs; the engine owns the measurement.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Modules author their own scoped ids and world geometry. The composer keeps references intact, rejects conflicting identities and shares model records only when the caller supplied the same prototype.

## @evidence contracts/development/implementation.md#efficient-algorithms

Item and anchor lookup use maps. Resolution visits each module once plus its reference calls, excluding producer work. Concatenation, identity and join indexes scan the emitted arrays once. Space polygon validation, prop geometry validation and the support report have their own shape and placement-dependent costs.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Within a recipe every resolved instance is used for all its references, and lookup and emitted frames are keyed by placement identity. Separate calls share no result because recipes and their producer dependencies can change.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Once the synchronous call ends, resolution state is discarded. The returned arrays retain their emitted records. The composer acquires no external handles and its construction callbacks are scoped to their invocation.

## @evidence contracts/development/common.md#meaningful-documentation

States the root and instance frame, seed, order, reference spelling, existing consumer split, rejection paths and the support report.
