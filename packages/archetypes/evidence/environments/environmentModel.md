# src/environments/environmentModel.ts#environmentModel

## @evidence contracts/development/implementation.md#principled-implementation

Each occurrence supplies one model sharing its original geometry but carrying the scoped id. Staging and any live prop cite that same model. Rigid world anchors and optional support derive from the same input frame.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

This bridge owns model identity and stage or prop publication. The support placer owns geometry and height conversion, and AutoMovieArchetypeFrame owns rigid frame composition.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

Absent supports and anchors remain absent. Authored mesh bytes and imported provenance remain with their owner. Admission is explicit for custom support and each rigid anchor.

## @evidence contracts/development/implementation.md#efficient-algorithms

Every instance places each supplied anchor once and copies the model header without traversing its geometry. Support placement carries its own validation and ring and height conversion costs.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

The definition reuses the supplied local model and authored records. Scoped results are built from the current local records for every occurrence, with no cache across calls.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

The definition retains the input recipe for its lifetime. Its returned records retain supplied geometry by reference and no host handle, file or task is created.

## @evidence contracts/development/common.md#meaningful-documentation

States per-occurrence identity, the frame, optional claims and reference ownership.
