## @evidence contracts/development/implementation.md#principled-implementation

Owns one browser renderer/RAF loop, runs the original producer under a validated display clock and publishes actual handled or ordinary completion through the existing observer boundary. Live CSS size and selected pixel ratio synchronize native backing/projection; changed viewports redraw the original completed producer even while paused or frozen.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

Clock and native camera transfer retain their existing owners; createViewerFrameControl owns the actual public controller and nested producer leases. Named context options distinguish original handled-frame hooks from native renderer creation and terminal mount shutdown.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No native render method is replaced, a handled frame without producer facts is not invented, and stopped controls cannot redraw a retired renderer; ordinary native drawing preflights the existing failed scene/shadow owners, preserving active settings and clock calculations.

## @evidence contracts/development/common.md#meaningful-documentation

Documentation gives handled-frame responsibility, explicit draw-before-completion, preserved guide clock, finite transfer time, terminal controls and public cleanup's native-proof limits.

## @evidence contracts/development/implementation.md#efficient-algorithms

Per-frame coordination adds fixed client-size/DPR reads and native-size comparisons plus producer/render/observer cost. Browser layout work remains real host cost. Only changed viewports resize backing and redraw the completed producer; no scene traversal is added to active draws, while shutdown delegates shadow traversal and fixed renderer/compositor retirement.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Handled record identity suppresses repeated idle publication and the current completed clock is preserved for guides; stop shares one sticky attempt and equal frame metadata is not independent pixel/source equivalence.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

At most one scheduled RAF and one outer producer freeze lease are retained; the same RAF observes layout/DPR, adding no observer or event listener. Stop cancels scheduling and retires the lease without resuming it before independent native cleanup. Initialization/frame failure attempts acquired owner cleanup, closed controls refuse new effects and borrowed model resources remain caller-owned. Public disposal is not independent OS/GPU kernel release proof.
