## @evidence contracts/development/implementation.md#efficient-algorithms

For V source vertices, T faces, E critical events and P contour publications, one source-cell admission, scalar-height sorting and PL classification cost O(V log V+T+E log E). Each requested slab scans P publications, queries and clips A closed-overlap candidate faces, and associates its local p ports, c cycles and i issues with direct scans; these can add O(p squared+c*p+i*component-count*issues-per-component). Copying N observed nodes and H halfedge occurrences adds O(N+H) time and retained metadata, since each node has at most two input vertex memberships and aliases are bounded by N. Selected critical bracketing can add O(e squared+e log V) for e events. Output size follows retained registries, components, ports, events and issues.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

One source-cell closure, sorted physical heights, PL classification and original source face index serve every pair; existing section fitting is never repeated.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Source arrays and private cell records live only for the synchronous call. Returned records copy face addresses and measured critical positions; no source geometry array is transferred or globally cached.
