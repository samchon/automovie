## @evidence contracts/development/implementation.md#principled-implementation

Complete unchanged cubic controls are reversed only by declared endpoint transport and affinely reparameterized to the engine's normalized course chart. The existing curve-grid operator generates new meshes and actual construction.

## @evidence contracts/development/implementation.md#clear-and-simple-structure

The original closed-section consumer remains independent. Open runs supply additional mesh parts, per-run results and separately identified closed-only omission observations.

## @evidence contracts/development/implementation.md#prohibited-implementation-shortcuts

No source positions, face indices, normals, positional weld, invented cap or source-specific rule is admitted. Numerical target misses and orientation warnings never delete an otherwise admissible run.

## @evidence contracts/development/common.md#meaningful-documentation

States maximal-run ownership, saved coefficient authority, normalized phase conversion, topology domains and unproven global continuity or embedding.

## @evidence contracts/development/implementation.md#efficient-algorithms

Graph admission and run discovery cost O(P+A) for pairs and saved arcs. Phase-guide union costs O(K log K) per run; the existing engine bounds grid output by the explicit per-run vertex budget.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

Every saved arc belongs to one maximal ordinary run, so one engine invocation owns each supported shared course rather than tessellating adjacent pairs independently.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Graph maps and converted course records are call-local. Returned model and actual construction own generated buffers; no source mesh, cross-call cache or external handle exists.
