## @evidence contracts/development/implementation.md#efficient-algorithms

With N final leaves and S returned splits, admission and final coverage use O(N log N) endpoint sweeps. Rebuilding sorted opposed-edge lists after each split costs O((S+1)N log N); two-pointer interface comparisons are linear because admitted same-bank intervals have disjoint interiors. Full rebuilds account for changed child identities and new perpendicular interfaces.

## @evidence contracts/development/implementation.md#reuse-equivalent-work

One endpoint-compressed range-count tree serves each coverage sweep. Each closure round reuses its edge lists to find the first conflict, and every propagated parameter is an existing exact endpoint rather than a new geometric calculation.

## @evidence contracts/development/implementation.md#bound-retention-and-release-resources

Call-local leaves, historical names, endpoint trees and edge lists expire on return or failure. Every split increases leaf count by one, bounded by maxLeaves; output owns its arrays and no caller state or external handle is retained.
