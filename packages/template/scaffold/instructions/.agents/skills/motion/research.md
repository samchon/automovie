# Motion and conditioning references

Use this when writing a production law for what is not a person, or for an action the installed human motion vocabulary lacks; for a person's ordinary movement the vocabulary has already made these choices. Take movement evidence from the [performance study](../story/planning/research.md#performance-study) and its retained references; the sources below inform implementation methods and failure checks only. Read the installed engine's README before adopting a method, because it may already provide one. Their experiments, embodiments and hardware neither validate this production nor supply an installed solver, so check an adopted principle through the current host and commissioned output.

| Primary source | Decision informed here |
| --- | --- |
| [Motion Graphs](https://graphics.cs.wisc.edu/Papers/2002/KGP02/mograph.pdf), Sections 3–4, and [parameterized motions](https://research.cs.wisc.edu/graphics/Gallery/kovar.vol/ParamMotion/motionFamilies.pdf), Section 1.1.2 | Reuse motion units through compatible transitions and meaningful bounded parameters; these captured-motion methods inform composition without supplying a procedural controller or contact solver |
| [Animation sync markers](https://dev.epicgames.com/documentation/unreal-engine/animation-sync-groups-in-unreal-engine?application_version=5.8) and [target warping windows](https://dev.epicgames.com/documentation/en-us/unreal-engine/motion-warping-in-unreal-engine) | Align meaningful phases and limit target adaptation to the relevant interval; synchronization and target fitting do not establish collision response, balance or an installed AutoMovie capability |
| [Full Body IK](https://dev.epicgames.com/documentation/en-us/unreal-engine/control-rig-full-body-ik-in-unreal-engine) and [Two Bone IK](https://docs.unity3d.com/Packages/com.unity.animation.rigging@1.3/manual/constraints/TwoBoneIKConstraint.html) | Pose a body from effector goals with per-goal strength, a bend hint and per-joint limits, keeping the input pose where no goal pulls; these engine features show the authoring model |
| [Footskate Cleanup](https://research.cs.wisc.edu/graphics/Gallery/kovar.vol/Cleanup) | Hold each foot plant exactly and blend the correction into neighbouring frames, because plants switching on and off pop the knee and root; the method cleans existing motion and may stretch legs slightly, which a rigid rig does not allow |
| [Semi-Procedural Locomotion](https://runevision.com/thesis/) | Adapt example gait cycles so each foot lands on the actual ground, with heel and toe aligned as one constraint; built for keyframed or captured cycles, it informs a production law for a gait the vocabulary lacks, such as an animal's |
| [Spatial Relationship Preserving Motion Adaptation](https://history.siggraph.org/?p=105435) | Close contact between characters or with objects, such as wrestling, dancing or entering a car, survives editing when their spatial relations are kept rather than their joint angles; an offline spacetime optimization, so it says what to preserve rather than how to solve it here |
| [Retargeting Matters / General Motion Retargeting](https://arxiv.org/abs/2510.02252) | Retargeting artifacts such as foot sliding, self-penetration and physically infeasible motion deserve inspection before expecting a downstream tracker or generator to repair them |
| [Shooting for Contact](https://arxiv.org/abs/2608.03116) | Kinematic similarity and dynamically feasible contact are different claims; use actual supported contact/physics evidence when the task requires it |
| [Spatiotemporal Retargeting](https://arxiv.org/abs/2610.30540) | Object interaction depends on preserving body–object relations at critical stages and key body parts; inspect those actual contacts instead of relying on a uniform average pose error. This recent research is a candidate method, not an installed capability |
| [Wan-Animate preprocessing](https://github.com/Wan-Video/Wan2.2/blob/main/wan/modules/animate/preprocess/UserGuider.md) | Inspect the actual pose/mask intermediate outputs, body-proportion retargeting and the selected mode's supported subject interactions before generation |
| [ControlNet](https://github.com/lllyasviel/ControlNet) | A conditioning mechanism has a concrete input contract; an arbitrary stick figure or depth-like image is not automatically a compatible signal |

[Retargeting](retargeting.md), [physical feedback](physics.md) and [frame evaluation](timeline.md) own the production procedure. [Control channels](conditioning.md) owns the hint's passes, and [video generation](../video/generation.md) service integration and take adoption. Preserve sources and contacts through conversion and inspect actual outputs; promising research does not justify live generation inside deterministic replay.
