# Motion diffusion

A motion model fills, varies or restyles motion; it does not decide it. The composed performance stays the source: [compose](../compose/SKILL.md) each person's actions first, so the beat's key poses, root path, contacts and timing are authored and exact, then let the model work only between and around them.

Use it when the user chooses it for a stretch the vocabulary performs stiffly, or for motion the vocabulary has no action for, such as a dance's flowing transitions:

1. Read the model's documentation and its [licenses](clips.md#licenses) before anything is generated.
2. Hint it from the composed performance under [hints](hints.md).
3. Freeze the result and check it under [clips](clips.md).
4. [Retarget](../retargeting.md) it onto the cast member's polygon man and accept it in its [catalog case](../catalog-cases.md) like any module.

Motion traced from footage, such as a dance video, follows [tracing](tracing.md), whether it becomes a clip, keys for the composed performance or a study's measurements. [Motion models](models.md) shows current examples.
