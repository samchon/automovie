# Refusals

The vocabulary refuses an unsupported composition when it builds the performance. Read the installed package's JSDoc for the specific cause.

## Repairing the named axis

Change the axis the refusal names and rebuild. Adjust preceding action where needed. For an infeasible force, use a studied force or return the outcome to the screenplay.

Of the feasible repairs, choose the one that realizes the beat. Keep the refusal visible until its cause is fixed.

## When no repair holds

For a feasible beat, fit a custom interval using the composition rules. Return an infeasible beat to the [screenplay owner](../../story/correction/repair.md#upstream-defects).

Report a package defect when documented use fails or its refusal gives no repairable axis. Include the composition and refusal or observed failure. Keep the case visible for repair at the package owner and continue independent work.
