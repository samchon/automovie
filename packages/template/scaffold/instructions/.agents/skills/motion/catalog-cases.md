# Catalog cases

Accept each entity and reusable motion module in the catalog before composing it into a film.

A case shows the film's capability from preparation through recovery with the relevant body, load, support, surface and partner. Exercise variants as case parameters. When a consequence depends on contact, include a miss to check that the consequence disappears.

The [catalog film](../development/source-layout.md#scenes-and-films) gives each required case a labeled interval and replays every case after a repair, so acceptance happens only there. A composition no registered film plays is scratch.

## Capture and review

Capture with the README command and add `joint` marks where available. Apply [motion judgment](judgment.md) against subject records and studies. Fix findings before recapturing or expanding.

Resolve a case once on load. Audit it separately from loading, playback and capture. Reuse reports only with the same inputs and package versions.

## What each case owes

Review each complete case against its subject facts and, for skilled practice, the cited exchange and its timing. Resolve visible defects before acceptance. The implementation determines the automated checks each case also needs.

| Case of | Automated checks |
| --- | --- |
| Installed actions used as documented | The package covers the actions' internal mechanics |
| A row or law the production registered, or a body it moves | Passing motion checks and a clean report |
| Anything else the production wrote, such as an entity or a retargeted clip | Passing tests |

[Testing](../development/testing.md#motion-checks) covers production-authored logic. The vocabulary's README names the report and its measures.

Route an installed action defect through [refusals](compose/refusals.md#when-no-repair-holds).

## Record

Record each accepted case's revision, inputs, tested conditions and inspected interval in `docs/acceptance/catalog.md`. Replay the matching case from the registered catalog before using it in a film. Reapprove the affected case when the module changes or the film uses it beyond those conditions.
