# Programming a performance

The screenplay decides what happens and when it matters. Start a scene from its screenplay and required [research](../story/planning/research.md#what-needs-a-study). Start a standalone case from its subject facts and promised behavior.

## The motion vocabulary

Read the installed parameters and operators under [reading a package](../automovie/SKILL.md#reading-a-package). Compose the [entities'](../development/entities.md) actions with the required participants, targets, outcomes, manner and timing.

The vocabulary owns body movement, fitting, supports and contact bounds, and its performance is kinematic.

## Order

1. Prepare the coarse [entities](../development/entities.md#coarse-first).
2. [Compose the performance](compose/composition.md). Repair a [refusal](compose/refusals.md) at its named axis.
3. Accept each module in its [catalog case](catalog-cases.md).

Use [motion judgment](judgment.md) for the catalog case and any film segments. Catalog acceptance completes programming for a standalone case. For a film, [accept a representative exchange](judgment.md#before-widening), then [stage](staging.md) and [review](segment-review.md) each segment before extending it. Hand accepted segments to [assembly](../production/assembly.md) or [video finishing](../video/SKILL.md), as commissioned.

Use [frame evaluation](frame-evaluation.md) for clocks, seeking and split renders. Render commissioned [control channels](control-channels.md) from the same performance.

When an installed action fails under its documented use, report the package defect and continue independent work. Keep production offsets, laws, simulation and generated clips out of that repair.
