# Programming a performance

Start a scene from its screenplay and a standalone case from its subject facts and promised behavior. For either, base skilled performance on the [study of the depicted practice](../story/planning/research.md#what-needs-a-study).

1. Prepare the coarse [entities](../development/entities.md#coarse-first).
2. [Compose the actions](compose/composition.md) the module will perform. Follow [refusals](compose/refusals.md) if the vocabulary cannot realize them.
3. Accept each module in its [catalog case](catalog-cases.md).

Catalog acceptance completes programming for a standalone case. For a film, [stage](staging.md) and [check the representative actions](judgment.md#before-widening), then stage and [review](segment-review.md) each segment before extending it. Continue under the commissioned route in the [production workflow](../production/workflow.md#commissioned-outputs).

Use [frame evaluation](frame-evaluation.md) for clocks, seeking and split renders. Render commissioned [control channels](control-channels.md) from the same performance.
