# Programming a performance

Start a scene by [reading the scene](staging.md#reading-the-scene), or a standalone case from its subject facts and promised behavior. For skilled practice, use the [performance study](../story/planning/research.md#what-needs-a-study).

For a commissioned film, start with the director's [first programming assignment](../production/director.md#first-programming-assignment).

1. Prepare the coarse [entities](../development/entities.md#coarse-first).
2. [Compose the actions](compose/composition.md). Follow [refusals](compose/refusals.md) if the vocabulary cannot realize them.
3. Verify the module in its scene interval or in a [separate case](catalog-cases.md) when needed.

A standalone case ends here. For a film, [stage](staging.md) the [central passage](judgment.md#before-widening), [review segments](segment-review.md) in order and hand off under the commissioned route.

Use [frame evaluation](frame-evaluation.md) for clocks, seeking and split renders. Render commissioned [control channels](control-channels.md) from the same performance.
