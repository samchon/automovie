# Programmed motion

For a scene, start from its screenplay and the study [research](../story/planning/research.md#what-needs-a-study) requires. A standalone case starts from its subject facts and promised behavior.

## The motion vocabulary

Read the installed parameters and operators under [reuse](../development/reuse.md#reading-a-package). Compose the [entities'](../development/entities.md) actions with the required participants, targets, outcomes, manner and timing.

The vocabulary owns body movement, fitting, supports and contact bounds. The default performance is kinematic.

## Order

1. Prepare the coarse [entities](../development/entities.md#coarse-first).
2. [Compose the performance](compose/composition.md), repairing [refusals](compose/refusals.md) at the named axis.
3. Accept each module in its [catalog case](catalog-cases.md).
4. [Stage](staging.md) and [review](segment-review.md) each segment before extending it.
5. Hand the performance to [assembly](../production/assembly.md) or [video finishing](../video/SKILL.md), as commissioned.

Use [frame evaluation](frame-evaluation.md) for clocks, seeking and split renders. Render commissioned [control channels](control-channels.md) from the same performance.

## Additional capabilities

Use the route the task needs. A faulty installed action follows [package-defect handling](../development/reuse.md#a-defect-or-a-gap).

| Need | Read |
| --- | --- |
| An action or moving body the vocabulary genuinely lacks after checking composition | [Vocabulary extension](laws/extension.md), then [motion laws](laws/SKILL.md) for a new law |
| A required response beyond the kinematic performance | [Physical feedback](physical-feedback.md) |
| A clip supplied by the commission or explicitly chosen by the user, or a changed rig | [Retargeting](retargeting.md) |
| Motion generation or tracing the user chooses | [Motion diffusion](diffusion/SKILL.md) |
