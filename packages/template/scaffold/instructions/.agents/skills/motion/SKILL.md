# Programmed motion

A scene starts from its screenplay and the study [research](../story/planning/research.md#what-needs-a-study) requires, a standalone case from its subject facts and promised behavior.

## The motion vocabulary

Read the installed parameters and operators under [reading a package](../automovie/SKILL.md#reading-a-package). Compose the [entities'](../development/entities.md) actions with the required participants, targets, outcomes, manner and timing.

The vocabulary owns body movement, fitting, supports and contact bounds, and its performance is kinematic.

## Order

1. Prepare the coarse [entities](../development/entities.md#coarse-first).
2. [Compose the performance](compose/composition.md), repairing [refusals](compose/refusals.md) at the named axis.
3. Accept each module in its [catalog case](catalog-cases.md).
4. [Stage](staging.md) and [review](segment-review.md) each segment before extending it.
5. Hand it to [assembly](../production/assembly.md) or [video finishing](../video/SKILL.md), as commissioned.

[Motion judgment](judgment.md) decides every acceptance in steps 3 and 4, and its [gate](judgment.md#before-widening) comes before the film widens.

Use [frame evaluation](frame-evaluation.md) for clocks, seeking and split renders. Render commissioned [control channels](control-channels.md) from the same performance.

## Additional capabilities

Most films stop at the order above. Take a route below only for the need it names.

| Read | For |
| --- | --- |
| [Vocabulary extension](laws/extension.md) | An action or moving body the vocabulary lacks |
| [Physical feedback](physical-feedback.md) | A simulated response the screenplay decides |
| [Retargeting](retargeting.md) | A clip the user chose or the commission supplies, or a changed rig |
| [Motion diffusion](diffusion/SKILL.md) | Motion generation or tracing the user chooses |

Vocabulary extension first checks whether composing again stages the beat, and leads to [motion laws](laws/SKILL.md) only for a new law.

A stiff or faulty installed action, composed as its README shows, is none of these needs. No offset, law, simulation or generated motion in the production covers it, because the flaw stays in the package and returns in every other use. Tell the user and continue with the work that does not depend on it.
