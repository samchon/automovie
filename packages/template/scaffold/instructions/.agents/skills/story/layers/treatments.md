# Treatments

Turn completed settings into decided events another author can execute: causes, choices, exchanges, costs, results, and the state and information later events inherit, under the [treatment principles](../../contracts/story/shared/principles/treatments.md) and [population duties](../../contracts/story/shared/obligations/treatments.md). Finish [discovery](../planning/discovery.md) first and write one H1 per event file with anchored H2s for its decisions.

Design from the first encounter with the promised experience through accumulating consequences, setup and payoff to the ending, including parallel developments and changes in audience knowledge.

Cite the settings each event uses, and decide the details that determine cause or result while leaving dialogue, blocking and final realization to their owners; [scripts](scripts.md) choose the partition. Study what [when to study](../planning/research.md#when-to-study) assigns to a treatment.

Read the whole sequence in screen order before evidence, because clear events can still omit a cause or payoff. A defective inherited fact is repaired under [upstream repair](../correction/repair.md#upstream-defects) before designing from it.
