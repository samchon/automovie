# Answer placement

Construction answers remain detached from creative bodies, in the unit and file locations the [document layout](../document-layout.md#documents) gives. The document's H1 identifies the exact body file or file-and-anchor address, followed by Evidence headings and supporting prose. The installed evidence package's documentation owns the native address and annotation syntax.

Detached documents do not support exclusion or exclusion-review rows. Put a permitted exclusion in the respondent unit's own HTML comment, or use the designated discovery carrier for a discovery negative. Place an H2's exclusion comment directly beneath it, before its subordinate H3 headings, and a file's before the file's first heading. State the inspected scope and exact inapplicability; a population exclusion requires the entire population to be inapplicable.

Review records and their fingerprints follow [narrative rounds](../../review/narrative-rounds.md).

A work- or language-specific question is adopted through [adoption](../../evidence/adoption.md), which also says where it lives; a unit answers for its own behavior and a designated population respondent for a whole-work duty.
