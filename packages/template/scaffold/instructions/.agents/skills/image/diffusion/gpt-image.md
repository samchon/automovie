# OpenAI GPT Image

Values were read from the linked documentation in November 2026; it owns them, so read it again when choosing.

- **Reached through:** the image API, from a script with the user's key.
- **Inputs:** an edit takes 1 to 16 images.
- **Seed:** none.
- **Prompt:** name the subject and the image's use, and order a complex request as scene, subject, details and constraints. Identify each input image by number and purpose. For an edit, say what changes and repeat what stays.
- **Layout:** camera words are cues for appearance, not guarantees, and exact placement in layout-sensitive compositions is a stated weakness, so check a shot frame against its render by overlay.

Documentation: [image generation](https://developers.openai.com/api/docs/guides/image-generation), [prompting guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide).
