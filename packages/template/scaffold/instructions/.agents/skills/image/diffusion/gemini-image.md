# Google Gemini image generation

Values were read from the linked documentation in November 2026; it owns them, so read it again when choosing.

- **Reached through:** the Gemini API or Vertex AI, from a script with the user's key.
- **Inputs:** up to 14 images, with separate caps on object and character images that differ by model version.
- **Seed:** Vertex accepts one but does not guarantee the same output.
- **Prompt:** refer to inputs by order, such as "the first image"; composition words such as "wide-angle shot" shape the frame.
- **With Veo:** Google's own workflow makes Veo's first frames, last frames and reference images with it.

Documentation: [image generation](https://aistudio.google.com/docs/image-generation).
