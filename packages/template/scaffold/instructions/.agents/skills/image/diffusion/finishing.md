# Finishing

Make an accepted image ready for use without changing what was accepted. Finish a copy and record the original as its input. Keep the original's content credentials, because a conversion can drop them.

## Upscaling

Upscalers are either faithful, enlarging what is there, or creative, inventing new detail that can change a face, a garment or lettering. Use only a faithful upscaler on a canon reference, a shot frame or a turnaround view, and overlay a shot frame on its render again afterwards.

## Transparency

Use the model's documented transparency mode and save a format that carries alpha, such as PNG or WebP. Check the decoded alpha channel: a painted checkerboard or plain backdrop is not transparency. Preserve alpha through later edits and check the returned file again.
