# Image models

Choose the image generator with the user, from the current examples below or any other they prefer, and record the choice in [project context](../production/project-context.md). Read the chosen generator's current documentation for sizes, input-image count, seed, license and price, because these change faster than this page.

A generator's route decides whose key it runs under and whether a seed repeats an image. Most hosted generators take a render only as an input image, so choose an open model or a hosted control endpoint when a shot frame must keep the hint's pose and camera exactly, as [conditioning](conditioning.md#routes) explains.

| Generator | Reached through | Shows how a generator can | Note |
| --- | --- | --- | --- |
| [OpenAI GPT Image](https://developers.openai.com/api/docs/guides/image-generation), with its [prompting guide](https://developers.openai.com/api/docs/guides/image-prompting) | A script with the user's key, or [Codex image generation](https://learn.chatgpt.com/codex/image-generation), which runs `gpt-image-2` within Codex usage limits and takes attached local images as references | Take several reference images, a mask as guidance and markup on the first image, and a transparent background | No seed; its Responses API may rewrite the prompt, while its Image API sends it as written |
| [Google Gemini image generation](https://aistudio.google.com/docs/image-generation) | A script with the user's key | Take references for several characters and objects, a pose reference, and edits over several turns | No seed; the output takes an input's size or a square unless set; every image carries a SynthID watermark |
| [FLUX](https://docs.bfl.ml/guides/prompting_editing_multi_reference) by Black Forest Labs | Its hosted API; the Klein models also as open weights under their own license | Take up to about ten numbered references, region boxes and instruction edits; open weights take a seed and a [trained LoRA](https://docs.bfl.ai/flux_2/flux2_klein_training.md) | Image 1 sets the output's aspect unless it is set |
| [Seedream](https://docs.byteplus.com/en/docs/ModelArk/1824718) by BytePlus | Its hosted API | Take many references and return a related set of images from one request | Check the reference and set limits of the current version |
| [Qwen-Image-Edit-2511](https://huggingface.co/Qwen/Qwen-Image-Edit-2511), which supersedes [2509](https://huggingface.co/Qwen/Qwen-Image-Edit-2509) | Open weights, Apache 2.0 | Edit from one to three input images; 2509 takes depth, edge and keypoint images directly | Qwen-Image-2.1, which outputs real transparency, has a research-only license |
| [ControlNet](https://huggingface.co/docs/diffusers/main/en/using-diffusers/controlnet), [IP-Adapter](https://huggingface.co/docs/diffusers/main/en/using-diffusers/ip_adapter), [image to image](https://huggingface.co/docs/diffusers/main/en/using-diffusers/img2img) and [inpainting](https://huggingface.co/docs/diffusers/main/en/using-diffusers/inpaint) on SDXL or FLUX checkpoints | diffusers or ComfyUI | Condition on depth, edge, pose and normal images, mask adapters per subject, inpaint, and repeat from a seed | Each checkpoint has its own license; InstantID's InsightFace weights and the OpenPose annotator are non-commercial |
| [MV-Adapter](https://github.com/huanngzh/MV-Adapter) | Open weights, Apache 2.0 | Generate two to six agreeing views from an image, or from an image and a mesh | For turnaround views |
| [Magnific](https://docs.magnific.com) | Its hosted API | Upscale faithfully or creatively, as separate tools | Only the faithful tool suits a shot frame |

[DreamBooth](https://huggingface.co/blog/dreambooth) and [AI Toolkit](https://github.com/ostris/ai-toolkit) document training a character LoRA on open weights.
