# Finishing

How an accepted image is made ready for its use without changing what was accepted. Finish a copy: the frozen original keeps its content credentials, which re-encoding drops, and the finished file's record names the original as its input.

## Upscaling

Upscalers are either faithful, enlarging what is there, or creative, inventing new detail that can change a face, a garment or lettering. Use only a faithful upscaler on a canon reference, a shot frame or a turnaround view, and overlay a shot frame on its render again afterwards.

## Transparency

Ask for an isolated subject in the prompt and set the generator's transparent-background option, saving as PNG or WebP. Check that the decoded file has a real alpha channel, because a drawn checkerboard or a plain backdrop is not transparency, and ask again on every later edit, because an edit can return an opaque background.
