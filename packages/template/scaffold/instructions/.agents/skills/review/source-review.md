# Source review

Review the current inputs in a [separate context](../story/workflow/routes.md#separate-contexts). Label self-review and unperformed checks.

Read the whole change with its callers, inputs, consumers, error paths and tests. Check it against the [development contracts](../contracts/development/SKILL.md) its declarations answer.

## Truth of answers

Verify each answer against its [contract item](../contracts/items.md#item-structure), the implementation and the sources it cites. Report any behavior, measurement or limit it claims without support.

## The actual consumer

Test changed and preserved behavior in the actual consumer. Trace displayed poses and joins to their supplying actions and overriding layers. Inspect the relevant surfaces in [diagnostic stills](../visual-debugging/capture.md#times). Use [video review](delivery-review.md#video) for media approval.

Read each beat and study. Require a commented value for every beat element. Check comments against the beat and study, values against comments, and the exchange at intended speed against the values.

Send omissions, bad comments and incorrect values to the film author, misperformed values to the action owner and writing defects through [film repairs](delivery-review.md#repairs).

Attribute playback and [listening observations](../audio/listening.md#user-listening) to the person who watched or listened. Report unavailable hosts or platforms.
