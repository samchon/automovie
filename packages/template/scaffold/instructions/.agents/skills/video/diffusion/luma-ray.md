# Luma Ray 3.2

Values were read from the linked documentation in November 2026; it owns them, so read it again when planning.

- **Takes the hint as:** one video to edit, up to 18 s through the API and 20 s in the app.
- **Output:** the input's length, 360p to 1080p.
- **Adherence:** motion and structure settings, body tracking and a face hold in the app; strength presets from adhering to reimagining, and per-signal controls for pose, depth, normals, trajectory and face, in the API.
- **References:** no canon references; up to 64 keyframes at chosen frames, made under [shot frames](../../image/SKILL.md#shot-frames).
- **Prompt:** up to 6,000 characters, no negative field.
- **Sound:** none documented.
- **Continuing a take:** an edit takes exactly one video, and extend continues a generation without a source video, so a continuing edit places the previous take's last frame as its first keyframe.

Documentation: [video to video](https://lumalabs.ai/learning-center/articles/ray-3-2-video-to-video), [editing](https://docs.agents.lumalabs.ai/guides/videos/editing), [generation](https://docs.agents.lumalabs.ai/guides/videos/generation).
