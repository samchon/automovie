# fal H3 Max 3D to video

Values were read from the linked documentation in November 2026; it owns them, so read it again when planning.

- **Takes the hint as:** a gray layout of up to 15 s and 32 shots. It keeps the camera, object count, paths, timing and cuts closely, but exact geometry and paths are not guaranteed.
- **Output:** the input's length, at 480P, 768P or 1080P.
- **Adherence:** no setting.
- **References:** up to 8 images.
- **Prompt:** up to 2,000 characters of scene intent, saying what the render's forms are.
- **Sound:** none documented.
- **Continuing a take:** no input for a previous clip; continuity comes only from giving every request the same references.

Documentation: [3D to video](https://fal.ai/h3-max-3d-to-video), [API](https://fal.ai/models/minimax/h3-max/3d-to-video/api).
