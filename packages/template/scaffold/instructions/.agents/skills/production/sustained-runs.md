# Sustained runs

Keep one run record for sustained work or requested observation.

## Actual state

Before dispatch or resumption, inspect the current inputs, outputs and run record. Record scope, roles, runtime, model, effort, session and process IDs, findings and next action. Link evidence and omit secrets. Keep production decisions in their existing records.

## Execution

Assign one writer per changing body and one owner for each film's screenplay, composition and camera. Send entity, motion and sound defects to their module owners.

Give additional authorized workers disjoint write scopes. Use reviewers who meet the [independence criteria](../review/independent-reading.md).

Before declaring a stall, check processes, artifacts and errors. Record failures and resume from the last valid output. When inputs change, start a new result and repeat affected checks.

Send package or scaffold defects to their owner with a reproducer. Continue independent work. After repair, reinstall and verify the failing entry point before resuming that stage.

## Observation

Run and record periodic checks at the requested interval. Check processes before replacing them. Report meaningful progress, completion, failure or blocking decisions.
