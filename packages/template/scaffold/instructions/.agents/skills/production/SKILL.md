# Production

Carry the commission from its adopted scope to the handed-off output. Read the request and [project context](profile.md) first, because the commissioned output decides which skills run and what completes the work.

## Commissioned outputs {#commissioned-outputs}

| Output | Complete when |
| --- | --- |
| Screenplay | Its text passes the [writing workflow](../story/workflow.md#completion); no source or media is owed |
| Standalone asset | Its views and controls pass the asset part of [delivery review](../review/delivery.md); no narrative is owed |
| Whole motion hint | Every main scene is programmed and the whole timeline is assembled; no generator is owed, and stills or pilot clips do not complete it |
| Direct 3D film | The programmed film is rendered at its commissioned detail; no diffusion is owed |
| Generated film | Accepted takes of the chosen video model are assembled; the motion hint behind them is a separate output |

[Delivery review](../review/delivery.md) accepts each one, and a report discloses what was not produced.

## Route the work

Each task has one owner, in the [writing order](../story/workflow.md#route-and-parents):

| Work | Owner |
| --- | --- |
| Research, canon and the screenplay | [Story](../story/SKILL.md) |
| Entities, source, integrations and tests | [Development](../development/SKILL.md) |
| Performance, staging, camera and the motion hint's control channels | [Motion](../motion/SKILL.md) |
| Generated images | [Image](../image/SKILL.md) |
| The video model, its prompts and its takes | [Video](../video/SKILL.md) |
| Sound | [Audio](../audio/SKILL.md) |
| Judgment of the work | [Review](../review/SKILL.md) |

This skill keeps what spans them:

| Task | Read |
| --- | --- |
| Establish scope, the delivery profile, decisions and setup authority | [Project context](profile.md) |
| Run, observe or resume sustained work | [Campaign execution](campaign.md) |
| Cache and resume expensive stages | [Stage caches](stages.md) |
| Save generated, acquired and pipeline media with their records | [Media](media.md) |
| Sync instructions or reorganize the production | [Ownership and customization](customization.md) |
| Assemble the film, render it once and hand it off | [Assembly and handoff](finishing.md) |
