# Evidence

Connect each required achievement to the work that can establish it. The [contracts](../contracts/SKILL.md) say which respondent answers which checklist; this skill adopts requirements, configures the graph and writes source answers.

| Read | To |
| --- | --- |
| [Adoption](adoption.md) | Adopt or change a requirement and choose its respondent |
| [Configuration](configuration.md) | Configure the graph for the commissioned route and work |
| [Answering](answering.md) | Write or audit source and test answers |

Creative answers follow [answer writing](../story/answers.md), whose evidence answerer owns their truth. [Source review](../review/source-review.md) judges whether source answers are true, and [delivery review](../review/delivery-review.md) whether the commissioned output works.
