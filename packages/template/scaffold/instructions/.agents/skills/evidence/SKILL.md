# Evidence

Connect each required achievement to the work that can establish it. The [contracts](../contracts/SKILL.md) say which respondent answers which checklist; this skill adopts requirements, configures the graph and writes source answers.

| Task | Read |
| --- | --- |
| Adopt or change a requirement and choose its respondent | [Adoption](adoption.md) |
| Configure the graph for the commissioned route and work | [Configuration](configuration.md) |
| Write or audit source and test answers | [Answering](answering.md) |

Creative answers follow [answer writing](../story/evidence/answer-writing.md). A passing graph shows that the selected answers and citations exist; [review](../review/SKILL.md) judges whether they are true, and [delivery review](../review/delivery.md) whether the commissioned result works.
