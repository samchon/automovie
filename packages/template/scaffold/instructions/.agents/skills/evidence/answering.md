# Answering

Answer [development contracts](../contracts/development/SKILL.md) in source and test doc comments. Read the declaration, callers, inputs, consumers and the applicable [contract items](../contracts/items.md#item-structure).

Open cited sources and current artifacts yourself. Verify quotations, revision and scope. Send unsupported claims and their failed criteria to their owners.

Use a permitted exclusion with a concrete reason when an item is inapplicable. Report missing or failing outputs as gaps.

Repair the code at its owner under [development](../development/SKILL.md) and update its answers in the same change.

## Film composition

To check [screenplay realization](../contracts/development/composition.md#screenplay-realization), replay the cited exchange at speed and compare cue, action and outcome with the screenplay. Route discrepancies, including defects exposed by faithful staging, through [film repairs](../review/delivery-review.md#repairs).

Keep the code answer grounded in the declaration. Attribute playback observations to their viewer in the [film record](../review/delivery-review.md#acceptance-record). If playback is unavailable, identify the interval that still needs viewing.
