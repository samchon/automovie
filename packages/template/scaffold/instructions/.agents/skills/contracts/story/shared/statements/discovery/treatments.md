## Treatment requirements {#treatment-requirements}

1. Uncovered event connections, agency, information release, accumulation, source mediation and formal progression that change actual event choices were looked for.
2. Positive document conventions were inspected for deciding or deferring events, paragraph organization, connections and disclosure.
3. Document form is distinguished from the order in which the audience receives events.
