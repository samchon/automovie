# Script requirement discovery

The discovery result covers the complete executable scene and partition population under the [common discovery boundary](common.md#requirement-ownership).

## Script requirements

Did discovery make the work's own execution and presentation rules checkable in each scene that uses them?

Check partition, action, speech, silence, inserts, access, transitions and exits. For each convention, identify the change it makes to a scene and how a reader could refute it. Include consequential block and action-line placement, release boundaries, headings, direction register, view and sound notation. Identify the owner of the form the screenplay inherits.
