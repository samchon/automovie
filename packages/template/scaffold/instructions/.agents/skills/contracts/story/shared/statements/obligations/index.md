# Settings index population statements

Contract: [obligations/index.md](../../obligations/index.md).

## Canonical navigation {#canonical-navigation}

1. Each sibling level states its organizing axis. Time, region and subject arrangements may vary by level when explained.
2. The index has no overlapping promises, missing or stale files, duplicate authority, or scattered subjects without owner routes.
3. Several access routes may link one canonical subject without copying its facts. Independent facts stay addressable and dependent attributes together.

## Reference order {#reference-order}

1. Work promises and prerequisites precede dependent detail and synthesis, with an overview and exact routes for circular dependencies.
2. The top level is scannable, and depth is justified by readers' questions. Section, file and fact are a useful default, not a compulsory schema or group count.
3. Reference order does not change audience event or reveal order.
