# Story contracts

## Writing or checking a unit

Shared entries for body units are [scope](principles/common.md) and, for narrative layers, [progression and parent differentiation](principles/narratives.md). See also [parent checks](#testing-the-parents) for units with parents.

| Unit | Open for its own content |
| --- | --- |
| Short brief facet | [Needed decisions](principles/brief.md) |
| Long settings facet | [Usable facts](principles/settings.md) |
| Treatment event | [Decided event and information design](principles/treatments.md) |
| Script scene | [First-draft scene progression](principles/scripts.md) |
| Screenplay section | [Performance, beat decisions, dialogue and expression](principles/screenplay.md) |

If checking a settings index group, use its [group purpose](principles/index.md) question.

## Checking a complete layer

Shared entries for complete layers are [scope and ownership](obligations/common.md) and [continuity, promises and distribution](obligations/narratives.md) for treatments, scripts and screenplay.

| Population | Open for the whole |
| --- | --- |
| Short brief | [Coherent brief](obligations/brief.md) |
| Long settings | [World and scope](obligations/settings.md) |
| Treatments | [Event design and handoff](obligations/treatments.md) |
| Scripts | [Partition and scene coverage](obligations/scripts.md) |
| Screenplay | [Full realization, recurring forms, voices, rhythm and version](obligations/screenplay.md) |

If checking the settings index as a whole, use [canonical navigation](obligations/index.md).

## Checking a study

[Depicted practice and traceable sources](principles/research.md) for selected studies.

## Finding uncovered requirements

Start with [requirement ownership](discovery/common.md). For canon, add the [brief](discovery/brief.md) or [settings](discovery/settings.md) question for the route. For authored narrative, add [narrative requirements](discovery/narratives.md) and the [treatment](discovery/treatments.md), [script](discovery/scripts.md) or [screenplay](discovery/screenplay.md) question that matches the inspected layer.

## Testing the parents

Use the upstream question for the [treatments](upstream/treatments.md), [scripts](upstream/scripts.md) or [screenplay](upstream/screenplay.md).

## Checking review records

Check a unit's review record under [independent reading and literal audit](principles/review.md). Check the verdict for the complete round under [review obligations](obligations/review.md).
