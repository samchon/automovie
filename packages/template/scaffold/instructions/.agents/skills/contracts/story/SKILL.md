# Story contracts

The [writing workflow](../../story/workflow/SKILL.md) sets the layers and passes each route runs; standalone asset work has no narrative population. A stage the user waived is recorded with its scope and never claimed as passed.

Assign principles to authored H2s, obligations to whole populations, discovery to inspected scopes and review questions to review records. Follow the production's Evidence configuration for selection and the installed package for mechanics.

## The short route

A short has no settings, settings index, treatments or scripts, and its studies answer no research contract under [evidence configuration](../../evidence/configuration.md#story). A short answers these:

| Contract | Asks about |
| --- | --- |
| [Shared ownership principles](shared/principles/common.md) | The assigned scope, filled with this work's choices |
| [Brief principles](shared/principles/brief.md) | Needed decisions |
| [Final screenplay principles](shared/principles/screenplay.md) | Audiovisual realization and beat decisions |
| [Narrative principles](shared/principles/narratives.md) | Progression and layer contribution |
| [Realized speech principles](shared/principles/realized.md) | Speakers and action order |
| [Independent review principles](shared/principles/review.md) | Grounded reading and complete finding classes |
| [Shared ownership obligations](shared/obligations/common.md) | Ownership at the right layer |
| [Brief obligations](shared/obligations/brief.md) | A coherent, current brief |
| [Final screenplay obligations](shared/obligations/screenplay.md) | Delivery and version accountability |
| [Narrative obligations](shared/obligations/narratives.md) | Continuity, promises and distribution |
| [Independent review obligations](shared/obligations/review.md) | Complete rounds and verdict |
| [Common discovery](shared/discovery/common.md) | Requirement ownership, for any inspected population |
| [Brief discovery](shared/discovery/brief.md) | Requirements of the instructions, references and planned films |
| [Screenplay discovery](shared/discovery/screenplay.md) | Requirements the screenplay owns |
| [Narrative discovery](shared/discovery/narratives.md) | Requirements the narrative layers own |
| [Screenplay upstream](shared/upstream/screenplay.md) | The parents, tested while writing it |

## Long work

Long work answers the short route's table without the brief rows, and adds these:

| Contract | Asks about |
| --- | --- |
| [Research principles](shared/principles/research.md) | Studied practice and sources, answered by each study |
| [Settings principles](shared/principles/settings.md) | Usable facts |
| [Settings index principles](shared/principles/index.md) | Reference groups, section by section |
| [Treatment principles](shared/principles/treatments.md) | Decided events and information |
| [Script principles](shared/principles/scripts.md) | Performable, staged scenes |
| [Settings obligations](shared/obligations/settings.md) | Promise, scope, a coherent world and its records |
| [Settings index obligations](shared/obligations/index.md) | Whole-index navigation |
| [Treatment obligations](shared/obligations/treatments.md) | Whole event design and handoff |
| [Script obligations](shared/obligations/scripts.md) | Partition and complete execution |
| [Settings discovery](shared/discovery/settings.md) | Requirements the settings own |
| [Treatment discovery](shared/discovery/treatments.md) | Requirements the treatments own |
| [Script discovery](shared/discovery/scripts.md) | Requirements the scripts own |
| [Treatment upstream](shared/upstream/treatments.md) | The parents, tested while writing them |
| [Script upstream](shared/upstream/scripts.md) | The parents, tested while writing them |
| [Common expression](shared/naturalness/common.md) | Expression, in each script unit |
| [Realized speech expression](shared/naturalness/realized.md) | Speech expression, in each script unit |
| [Script expression](shared/naturalness/scripts.md) | Script expression, in each unit |
| [Common expression obligations](shared/naturalness/obligations/common.md) | Expression, across the scripts |
| [Realized speech expression obligations](shared/naturalness/obligations/realized.md) | Speech, across the scripts |
| [Script expression obligations](shared/naturalness/obligations/scripts.md) | Execution, across the scripts |

Research and realized speech have no obligations. Only scripts construction answers the expression questions. The screenplay settles its speech in construction under the realized speech principles and has no expression family.

## Every route

Start with common discovery when the story skill writes the selected populations' discovery result.

A defect an upstream question finds is repaired at the earliest semantic owner, with its affected descendants.

Read each item's statements before answering. Find them at the contract's path under `shared/statements` and under the same item anchor.
