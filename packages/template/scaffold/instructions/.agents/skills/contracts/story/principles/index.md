# Settings index section principles

Each section of the settings index answers for its contained file group. A settings fact H2 is not this respondent.

## Group purpose

Does each group answer a distinct reader question, put overview and prerequisites first and lead to one owner per subject?

Use names readers would search for. Say what each entry contains, why it belongs and where a shared subject is owned. Keep related attributes together and independently used subjects addressable. A large collection may route to its parts. Keep world entities distinct from work promises and production instructions.

Give circular dependencies an overview and exact routes. Avoid duplicated facts, file lists or H2 inventories. Reference order leaves chronology and audience reveal order intact.
