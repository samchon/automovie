# Script principles

Each script H2 answers for an executable scene of one continuous place and time within the script's chosen partition. Scripts already contain full action, dialogue, staging and a viewing position.

Statements: [statements/principles/scripts.md](../statements/principles/scripts.md).

## Executable scene

Can the scene be performed as written, from its opening through action, exchange and reaction to an observable exit state? Keep place, positions, view and sound executable and consistent.
