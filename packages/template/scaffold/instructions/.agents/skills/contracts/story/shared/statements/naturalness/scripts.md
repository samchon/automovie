# Script expression statements

The detailed statements of the [script expression principles](../../naturalness/scripts.md), one section per item. Check the work against each before answering, as [items and statements](../../../../../contracts/SKILL.md#items-and-statements) describes. This document is not an evidence target.

## Execution rhythm {#execution-rhythm}

1. The scene holds no uniform beat mold, gesture on every line, decisive dialogue buried in exposition, summary substituted for exchange, repeated performance label, or long explanation that hides where a response happens.
2. Urgency, comedy, weight and sustained stillness get the arrangement that serves them, not decorative variation or a prescribed line count.
3. Executable instructions and precise staging, audiovisual state and viewing positions are kept.
4. Interpretive labels are replaced with a performable operation within the inherited scene.
5. Content and expression are completed in this construction while inherited facts, knowledge, appearance, event results and reveal order are preserved, and a defective treatment is repaired at its actual owner.
6. Actual passages are classified, and any permitted exception proven, under [common expression](common.md#reads-as-written).
