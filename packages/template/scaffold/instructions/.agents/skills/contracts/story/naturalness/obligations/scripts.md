# Script expression population obligation

The complete script construction population answers once for execution rhythm across scenes and release units.

## Execution distribution

Compared across the whole, does the arrangement of entry, action, speech, silence and exit change as the pressure changes? Scenes that change only their people or objects leave the audience experiencing the same scene.

Compare entries, exits, speaking turns, directions, views, silence, block duration and action-response order across the whole. Repeated scene headings, useful parentheticals and unnamed performers' position cues can serve execution. Test a fixed view, ritual, continuous action or sustained stillness by what it achieves. Use [common expression obligations](common.md#recurrent-frames) to repair recurring causes together while preserving staging and partition.
