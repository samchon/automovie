# Treatment upstream statements

The detailed statements of the [settings repair exposed by treatments](../../upstream/treatments.md), one section per item. Check the work against each before answering, as [items and statements](../../../../../contracts/SKILL.md#items-and-statements) describes. This document is not an evidence target.

## Settings repair {#settings-repair}

1. The exact settings owner of each defect is identified.
2. That body was corrected locally before writing from the repair, and the answer names the owner, the defect and the corrected passage.
3. Where no repair was needed, the answer identifies concrete parent decisions exercised unchanged and how the event tested them. A generic assurance, or an answer without an exact parent, establishes no negative.
