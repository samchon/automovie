# Common expression population obligation

The scripts construction population answers once at file level. Inspect the whole population. Record convergence candidates, locations, repairs and grounds for retention. Name the inspected scope if there are none.

## Recurrent frames

Across every scene and release unit, does each recurring form serve the circumstances it appears in? A functionless convergence can fail even when each occurrence reads naturally alone.

- Compare sentence shapes, directions, endings, gestures, modifiers and reactions with their circumstances. Synonyms and different props can mask the same repeated operation. Counts locate passages to read.
- Read the complete work in its language for translated syntax, awkward combinations, unnecessary pronouns, flattened registers and endings that give different scenes the same rhythm. Preserve adopted tense, voice, period language and dialect.
- For a retained refrain, habit, contrast or formal regularity, compare a workable version without it and identify what it loses. Repair the cause across all members. Rotating synonyms, syntax or endings to equalize counts leaves the cause intact.
