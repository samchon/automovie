# Brief principles

Each brief H2 answers as one facet of its subject, owning the anchored H3 decisions beneath it. It does not answer for every film or scene.

## Needed decisions

Does the record name its subject, decision, scope and applicable limits so each screenplay can use it consistently?

Identify cast members by depicted practice level, body, appearance and wardrobe. Add a style or tell when the story uses it. Describe a place by the routes, sightlines, barriers, light and landmarks the action depends on. Give an independently used prop its identifying features, use and relevant initial state. Distinguish similar objects when exchanging them would change the scene.

Cite the practice study and sources for external claims under the declared [factual basis](../../../story/planning/requirements.md#factual-basis). Keep story-defining measurements here. The code derives other values from [research](../../../story/planning/research.md).
