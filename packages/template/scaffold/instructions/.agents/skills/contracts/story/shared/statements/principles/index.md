## Group purpose {#group-purpose}

Purpose:

1. The title and explanation use the words the reader would search for, including established world names where appropriate, not contract labels or author work categories.
2. Each file entry says what is found there and why it belongs here, with a route to a shared subject's canonical owner.
3. The group repeats no file names, copies no facts or H2 lists, and mixes no unrelated reference purposes.
4. Work promises and production instructions may have their own reference group without posing as world entities.

Order:

5. A subject's related attributes stay together. Exception: a large collection may divide into independently used subjects with explicit links to their containing whole.
6. Unrelated institutions, objects and people have separate reference homes when readers use them separately.
7. A cyclic dependency gets an initial overview and exact references, not duplicated facts.
8. Reference order changes neither story chronology nor audience reveal order.
