# Settings index section statements

## Group purpose

Purpose:

1. The title and explanation use the words the reader would search for, including established world names where they fit, not contract labels or authoring categories.
2. Each file entry says what is found there and why it belongs here, with a route to a shared subject's canonical owner.
3. The group repeats no file names, copies no facts or H2 lists, and mixes no unrelated reference purposes.
4. Work promises and production instructions may have their own reference group without posing as world entities.

Order:

5. A subject's related attributes stay together, and unrelated institutions, objects and people that readers use separately have separate homes. Exception: a large collection may divide into independently used subjects that link to their containing whole.
6. A circular dependency gets an initial overview and exact routes, not duplicated facts.
7. The group's reference order changes neither story chronology nor the audience's reveal order.
