# Script discovery statements

Contract: [discovery/scripts.md](../../discovery/scripts.md).

## Script requirements

1. Uncovered rules were looked for in partition, action, audience access, speech and silence, inserted forms, transitions and exits.
2. Each rule found changes actual scene execution and can be refuted in its selected hosts.
3. Positive conventions were inspected for entry and exit, action-line placement, block content and withholding, release boundaries, direction register, scene headings, views and sound notation.
4. Notation is distinguished from the meaningful view decision itself.
5. The form the final screenplay inherits is identified with its canonical owner.
