# Settings index section principles

Each section of the settings index answers for its contained file group. A settings fact H2 is not this respondent.

Statements: [statements/principles/index.md](../statements/principles/index.md).

## Does this group help a reader find the right owner? {#group-purpose}

Do its title and explanation name a distinct reader question, with files that belong together for that purpose, each owning one independently used subject, prerequisites and an overview before dependent detail? A group named after a contract label or the author's work category sends the reader to the wrong place, and a reader who must reassemble a subject from several files will rebuild it differently each time.
