# Settings index section principles

Each section of the settings index answers for its contained file group. A settings fact H2 is not this respondent.

Statements: [statements/principles/index.md](../statements/principles/index.md).

## Group purpose

Do its title and explanation name one distinct reader question, with files that belong together for it, each owning one independently used subject, and prerequisites and an overview before dependent detail? A group named after a contract label or an authoring category sends the reader to the wrong place, and a subject the reader must reassemble from several files is rebuilt differently each time.
