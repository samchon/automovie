# Settings index section principles

Each section of the settings index answers for its contained file group. A settings fact H2 is not this respondent. Check each item's [statements](../statements/principles/index.md) before answering it.

## Does this group help a reader find the right owner? {#group-purpose}

Do its title and explanation name a distinct reader question, with files that belong together for that purpose? A group named after a contract label or the author's work category sends the reader to the wrong place.

## Are its files coherent and ordered for reference? {#group-order}

Does each file own one independently used subject, and do prerequisites and an overview precede dependent detail? A reader who must reassemble a subject from several files will rebuild it differently each time.
