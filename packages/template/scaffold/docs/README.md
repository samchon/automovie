# Production documents

This is the production's self-contained document root. The declaration in `lint.config.ts` selects applicable populations; installed `@automovie/evidence` documentation describes graph semantics. The installed package types define supported production kinds.

Create directories when they receive actual content. Installed contracts are project-owned under [Static-document updates](../README.md#static-document-updates).

| Path | Owner |
| --- | --- |
| `discovery`, `naturalness`, `upstream`, `principles`, `obligations` | Reusable contract targets |
| `language` | Selected language contracts |
| `contracts` | Production-specific targets |
| `accounts` | Aggregate obligation owners |
| `settings` | Production facts, identities and shared conventions |
| `research` | External findings used by the production |
| `maps`, `models`, `spaces`, `materials`, `instances`, `motions`, `systems` | Domain design owners |
| `treatments`, `scripts`, `screenplays` | Film narrative owners |
| `final/screenplays` | Final expression preserving construction identity |
| `briefs` | Bounded audiovisual delivery |

Implement completed decisions in typed source and record observations with the owner making the claim. [Project ownership](../README.md#ownership) defines executable source and configuration placement.
