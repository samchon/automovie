# Evidence conformance owner map

The builder owns structural validity; the author owns literal semantic truth. Route a failure through its canonical owner below.

| Failure | Canonical owner |
| --- | --- |
| Malformed syntax, duplicate attachment, invalid path, stage, population, selector, cardinality, or exclusion | `@automovie/evidence` and the typed declaration reject mechanically invalid relationships. [Diagnostics](staging.md#diagnostics) routes their repair. |
| Generic or copied reason, wrong target or category, wrong semantic role or host kind, unsupported or wrong-event statement, false quotation, locator, notation, or absence | [Literal semantic pass](../review-verification/semantic-review.md#literal-semantic-pass) checks exact predicates, literal support, exchange, and the configured negative scope. |
| Target, host, population, or semantic statement changes | Evidence lint checks current structural identities; [Semantic evidence inspection](../review-verification/semantic-review.md) renews the literal judgment. |
| Tool-created or normalized semantic prose | [Semantic evidence inspection](../review-verification/semantic-review.md) requires the author's literal judgment; tools only locate rows and report diagnostics or alarms. |
| Evidence rewrite changes authored bytes | [Protected authored content](../review-verification/semantic-review.md#protected-authored-content) checks non-evidence content and exact evidence rows before semantic judgment. |
| Confirmed content or ownership defect | [Diagnostics](staging.md#diagnostics) selects the earliest repair owner. [Author process Self-Review](../review-verification/self-review.md) closes the affected consequences before work resumes. |

A builder-clean graph remains subject to semantic review; semantic truth never excuses malformed structure.
