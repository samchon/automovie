# Script expression revision principles

Each revised script H2 answers for the clarity and rhythm of its already executable scene. Revision preserves the scene's construction decisions.

## Do execution blocks carry the scene's pressure naturally? {#execution-rhythm}

Do block length, speaker changes, directions, interruptions, silence, and simultaneous action make the actual action and reaction easy to perform at the required pressure and pace? Inspect a uniform beat mold, gesture on every line, decisive dialogue buried in exposition, summary substituted for exchange, repeated performance labels, or a long explanation that hides where a response happens. Urgency, comedy, weight, and sustained stillness need the arrangement that serves them rather than decorative variation or a prescribed line count.

Keep executable instructions and precise staging, audiovisual state, and viewing positions; removing their vocabulary because it sounds technical would destroy this layer's work. Replace interpretive labels with the inherited performable operation where one exists, and return a missing semantic decision upstream. Expression revision may clarify the same staging and result but cannot quietly alter the partition, core action, knowledge, appearance, or reveal order. Compare the actual candidates and meaningful alternatives as required by [common expression principles](common.md#reads-as-written).
