# 3D Modeling

Make the asset serve its intended shots or modeling task, including the required controls and rendering budget. Read the production's brief and current source, then the installed package documentation for the capabilities the task needs.

1. Choose direct construction, recovery, existing assets, or a combination using the [asset guide](../../../docs/guides/assets.md). Keep the user's chosen workflow unless an observed capability limit prevents it.
2. Establish the source and control ownership before authoring the asset and its performance. Use the [asset questions](../contracts/assets.md) for review; [contracts](../contracts/SKILL.md) decides whether to select formal evidence and which units answer it.
3. Inspect the actual rendered result under the conditions the task requires. Gather the complete affected inspection round before correcting its causes together, then repeat that round.

The guide owns workflow choices and inspection planning. Installed APIs own data formats and callable behavior; completed generation, fitting, compilation, or tests alone establish no visual result.
