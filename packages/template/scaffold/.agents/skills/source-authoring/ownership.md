# Source ownership

The project [Ownership](../../../README.md#ownership) section owns source placement, allowed files, and the source-first execution boundary. Review observations remain in evidence citations and Git rather than a second project ledger.

Author deterministic values and functions under the source branch selected by the completed design. A helper can live elsewhere under the same source root without becoming an independent production owner; its calling owner still answers for the result.

Follow [Compilation](compilation.md) for deterministic derivation and shared consumers. The authored owner that adopts an external input retains its provenance.

A model owns reusable geometry and articulation. Instances own placement and bounded variation. A library owner returns its declared reusable model, map, or environment without inventing a shot or clock. Film and brief source additionally own the staging and time-dependent program their completed documents require.

Preserve stable authored identities and source-to-design citations. A source export must not borrow another owner's address or conceal newly invented design facts behind an implementation detail. [Evidence staging](../evidence-graph/staging.md) owns the selected source population and citation relationship.

Examples teach operations and supply no production content. Adapt the required technique into the owning branch and verify it against that branch's actual design.

Repair the earliest source owner under [Debugging](../review-verification/debugging.md); rendered bytes are outputs and cannot repair it.
