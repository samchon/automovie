# Documentation

Technical documents, instructions, evidence explanations, and doc comments follow [Writing](writing.md). Creative bodies follow the production's adopted language, voice, and form under [story contracts](../contracts/story/index.md). Preserve fixed quotations and creative choices such as purposeful repetition, nonstandard speech, and punctuation rather than applying technical prose rules to them.

What a public declaration's comment must say is the contracts [Authoring interface](../contracts/common.md#authoring-interface) question. Package READMEs, types, and JSDoc own API details; link to them rather than restating them here.
