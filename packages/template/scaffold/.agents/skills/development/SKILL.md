# Development

Read the production's current source and the installed package APIs before choosing an implementation. Keep authored controls close to the assets, shots, and edit they control, with one owner for shared values. External acquisition produces fixed inputs before playback.

- Read [Repair](repair.md) when changing existing behavior or fixing a defect.
- Answer the [contracts](../contracts/SKILL.md) selected for the declarations you change.
- Read [testing](../testing/SKILL.md) when choosing behavioral checks.

Finish a source change with `npm run lint`, `npm run evidence`, and `npm test`. Verify the affected consumer through [review](../review/SKILL.md), including actual renders and playback for audiovisual changes. Gather the whole round before repairing its findings.
