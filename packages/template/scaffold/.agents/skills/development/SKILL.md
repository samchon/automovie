# Development

- Read [Repair](repair.md) when changing existing behavior or fixing a defect.
- Answer the [contracts](../contracts/SKILL.md) checklist of every exported declaration you write.

## Checks

Finish a source change with `npm run lint` and `npm run evidence`. Verify a visual change under the 3D modeling skill's [Visual Debugging](../3d-modeling/visual-debugging.md); a passing check never shows that a result looks right.
