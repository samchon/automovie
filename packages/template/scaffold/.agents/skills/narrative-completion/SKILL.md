# Narrative completion

Complete the selected path's passes before relying on their results. Long work follows settings construction → treatments construction → scripts construction → scripts naturalness → screenplay construction → screenplay naturalness. Short work enters at screenplay construction; standalone assets have no narrative passes. Only an explicit user waiver omits an expression pass.

Use [construction completion](construction.md) when a complete draft is ready for evidence and review. Use [expression handoff](expression-handoff.md) after [rewriting](../rewriting/SKILL.md), including its initial transfer to the body. [Evidence configuration](../evidence-configuration/SKILL.md) owns stage selection; [review](../review/SKILL.md) owns independent judgment and closure. A disabled pass permits drafting and grants no completion.

Run the installed production checker for the submitted layer and pass, then read the complete report and unfiltered validation. A target check establishes only its target. Captured reports describe their actual inputs; reevaluate after source or filesystem changes. Readiness can identify a body ready for review while completion still fails, and cannot grant artistic acceptance. Installed `@automovie/evidence` documentation owns commands, fields, and exit behavior.

Keep completed passes in their evidence stage. Existing closed layers follow [upstream repair](../upstream-repair/SKILL.md), preserving failed reports and actual exit statuses. Whole-work completion requires the selected passes, unfiltered validation and a clean package build, followed by [delivery review](../delivery-review/SKILL.md) of the actual commissioned output. A screenplay or diffusion hint commission does not imply a finished post-diffusion film.
