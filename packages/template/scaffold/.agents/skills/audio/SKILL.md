# Audio

Choose the source with the user: supplied recordings, a hosted service, and local tools are alternatives. Reuse the production's chosen tools and assets; consult [Audio](../../../docs/guides/audio.md) when acquisition or local setup is needed.

Acquire audio before finalizing its timing, adopt the resulting bytes with their provenance, then connect them through the installed package APIs and this production's host. Generation stays outside deterministic replay. Source changes follow [development](../development/SKILL.md), and the [contracts guide](../../../docs/guides/contracts.md) owns how production commitments are recorded.

Listen to the adopted takes and the delivered soundtrack with picture before claiming completion. Report unavailable playback or missing delivery wiring as an unresolved check.
