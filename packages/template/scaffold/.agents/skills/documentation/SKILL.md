# Documentation

Good writing is the same for every reader: deliver the core point concisely and clearly.

## Writing

- Write only what the reader needs and would not otherwise know. Cut padding, repetition, preamble, filler, and closing summaries.
- One point, one sentence, one place. Give the reason when it is not obvious.
- Say what to do rather than what to avoid; when a prohibition is needed, name the concrete pattern.
- Plain language with one term per concept, and no emphasis capitals, em-dashes, emoji in prose, promotional adjectives, or hedging.

## Paragraphs And Lists

A paragraph is one topic, written on one source line. Use a list for parallel items and ordered steps, prose for an argument whose conditions and exceptions depend on each other, a table for repeated mappings, and a code block for exact commands.
