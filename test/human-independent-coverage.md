# Independent Human verification coverage

This matrix separates a tested geometric observer from evidence that it detects an actual generated person's defect. Passing portable controls does not admit a whole person. Legacy `test_human_anatomy_*`, `test_human_curve_*`, mouth and binding functions remain separate evidence because their observers transitively import production Human construction.

`Validated` means the same independent observer passed a correct analytic/raw-source shape, rejected defects in actual buffers, and responded to an independently prescribed change. `Observed` means a finite value was retained without enough acceptance authority. `Unavailable` means required registration, numerical support or an independent limit is absent. `Unimplemented` means this independent suite has no observer for the obligation.

## People and stages

The four references are f1, f2, m1 and m2. Each has an original registered raw head/body carrier and a saved default bind skin. Tall, short, wide, narrow and masculine inputs have saved bind/pose buffers but no independent raw-source answer. Generic buffer, placement and deformation observers can read those five; reference-relative shape acceptance cannot.

The saved output round generated each person once and cached success/failure for all test consumers. Original loft keys and dense intermediate stations were retained without decreasing curve or section density. Final-skin observations, sampled loft composition, saved posed geometry and public refined appearance remain distinct stages. A result at one stage never fills another stage's cell.
