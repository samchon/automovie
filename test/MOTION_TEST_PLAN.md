## Evidence and implementation

The baseline records in inventory.csv carry the original operation, available independent basis, retained red witness and corresponding immutable compiled entry. For every destination, read the records sharing its spec_file. Extract only distinct functional obligations. Reuse a passing specimen only when its result is independently derivable. When the source file disappeared before the snapshot its frozen compiled case and imported helper still establish the operation. Trace the named helper to the exact assertion. A historic failure is a regression candidate, not a proven engine cause. Compare criterion, units, input and emitted geometry before changing either implementation or test. Preserve tolerances justified by a spec or study. Finite input representation explains the near-sixty-degree case without making unrelated geometry permissive.

A unit sample is a numerical operation with explicit inputs. A minimum composition adds only the actor, prop, parent phase or second channel intrinsically required for that observable. Do not call a legacy suite, render a scene, drive a film, or hide multiple independent physical programs in one helper. Choose one analytic positive, the adjacent negative and a boundary per decision. Put multiple bodies or seeds in that unit only where stature, reach or random dispersion can change its answer. Use closed forms for kinematic geometry. Integrate only a requested physical interval. Observe the external skeleton, marker, prop or public verdict rather than reading the planner's target.

Independent checks use metres, seconds and radians with unit-aware tolerances. Length scaling of a dynamically similar gait implies time proportional to sqrt(length/gravity). Replay and seed independence alone cannot establish dispersion. Compare the distribution of the actual output parameter with the specified distribution; separately keep feasible bounds and semantic endpoint. For rotations, compare the action on basis vectors or an absolute quaternion dot. Mirror the full body frame before comparing left and right coordinates. Geometry in the bind rig is immutable, and world-space observation must use current posed FK.

## Public reach and failure disposition

Enumerate 64 base action registrations and all 546 public row names over the 44 family entries as inexpensive registry/schema inputs. The 98 distinct base/extension dispatch owners are routing identities. Distinguish a present registry entry, resolved fixed/default parameters, public plan admission and a physical outcome. Only a geometry case proves the latter two. No obligation is satisfied by checking that an object exists or contains a function. Dispatch only through the public grammar when the expected behavior depends on dispatch. Preserve accepted and rejected inputs with the public verdict, offending parameter, time and geometry. Aliases that change an effector, held-frame target, phase, role, support or published reach predicate must have their difference asserted at that owning unit.

Failures that collapse to the same function still need their distinct witnesses. In particular preserve the reachable forehead and distant refusal, presented hands on both sides, two-stage pickup versus drinking, loaded coupled balance, pike orientation jump, gait markers, claim overlap, collider active interval, opt-in physical phase and unowned-callback boundary. Use passive props and generic marker geometry for staged-action contracts. These tests concern the animation software.
