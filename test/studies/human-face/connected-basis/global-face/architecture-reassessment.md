# Facial representation reassessment

## Decision and status

On 2026-09-22 the user required a fresh investigation of the architecture after repeated local fixes failed to resolve the face editor. This supplements [#2533](https://github.com/samchon/automovie/issues/2533) and [#2535](https://github.com/samchon/automovie/issues/2535) in the same [Draft PR #2534](https://github.com/samchon/automovie/pull/2534). Body implications belong to [#2536](https://github.com/samchon/automovie/issues/2536). This record stands alone without `.wiki`.

Checkpoint `28db475a38a831879cc40fcf0f68c29c52e15af8` establishes numerical personal state, editor replay and common generation. It does not establish adequate anatomical coupling or hairstyle coverage. Its GitHub build, test and deploy checks passed; the local full-suite timing failures remain separately recorded in [the migration receipt](numerical-hair-migration.json). All eighteen published study documents completed native preview/export and real-GPU capture in their saved expression states. This is not a sweep of their expression spaces. Observed visual defects prevent acceptance.

**Stop using personal parameter adjustments and additional isolated corrective fields as the main route to anatomical correctness.** Reassess the evaluation model before expanding its parameter inventory. The proposed replacement separates identity geometry, articulated performance, soft-tissue attachment and hair construction into explicit stages with shared correspondence. Choosing the shared geometry source remains subject to the comparison below; replacing its name or increasing its coefficient count is insufficient.

## Verified causes and hypotheses

| Surface | Evidence in the current implementation | Consequence |
| --- | --- | --- |
| Facial motion | `createHumanFaceBasisBuilder` adds shape and expression displacements, adds corrective displacements, then `applyHumanFaceRigidGroups` independently projects selected components to rigid motion. | Teeth can retain their dimensions while neighboring lips, tongue and oral lining retain a different motion. The earlier measured crossings and photographs are not addressed by the rigidity invariant alone. |
| Joint placement | The current basis has fitted rigid groups but no shared articulated jaw chain with identity-dependent joint frames and tissue weights. | A fitted proper rotation is not evidence of a physiological joint path or coupled tissue motion. |
| Hair construction | `createHumanFaceHairBuilder` integrates each sampled root directly into a rendered strip. `evaluateHumanFaceHairDirection` combines a global flow, root-dependent part bias, lift and curl. | There is no intermediate description of hairstyle volume or guide neighborhoods. Changing strip count/width changes apparent coverage without establishing the intended hairstyle volume. |
| Hair scale | `integrateHumanFaceHairCurve` uses the same `width` for contact clearance that `buildHumanFaceHairMesh` uses for strip width; clearance also includes half the integration step. A point root fans immediately into the full strip. | Physical fiber size, aggregate rendering width and numerical integration error are mixed. Increasing card width to hide gaps also changes the generated path; broad hairline triangles follow from this representation. The replacement needs explicit scale separation and a convergence check. |
| Hair boundaries | Current actual exports show broad steps at hairlines and posterior gaps. The posterior scalp triangles and root population are present. A Daniel counterexample with only its part field removed substantially reduced the central gap while retaining identical roots. | The field and strip coverage require examination together. Neither missing roots nor the part field alone explains every observed defect. |
| Control validity | Individual finite ranges are admitted for shape/expression channels. | Membership in a numeric box does not imply a valid combination of jaw, lips, lids, eyes and tongue. A coupled validity domain is missing. |
| Simple controls | The current residual-preserving group conversion is deterministic authoring arithmetic. | It preserves edits but does not establish empirical age, anatomy or population semantics. That evidence must be supplied separately. |

These are distinct claims. Numerical serialization, reproducibility, physical geometry and useful authoring are separate acceptance conditions.

There is also an identity-independent counterexample to treating endpoint addition as articulation. Interpolating between a rest point and its rotation uses `A(t) = (1-t)I + tR`. In the plane perpendicular to the rotation axis, its length scale is `sqrt(1 - 2t(1-t)(1-cos(theta)))`; at half weight this is `abs(cos(theta/2))`. Thus a 30-degree rotation shrinks transverse distances by about 3.4% at half weight. Correcting an isolated dental group afterwards restores that group's distances but does not apply the same rotational trajectory to attached tissue. The replacement must evaluate the rigid transform and its tissue attachments together; denser sampling of the same linear path does not change this counterexample.

## GNM source audit

The official repository was cloned at `a424b5153eec9154f3dfa5ee7f214e5817918d54`. Its `gnm/shape/data/versions/v3_0/gnm_head.npz` is 53,305,389 bytes with SHA-256 `67fef851c2e74ecad590dccf1b336afbb6bf0ae7cf981e5efeaf2160f178e745`. This is one shared model, not personal data. No GNM asset or implementation has been added to the application.

Direct non-pickle NumPy inspection finds 17,821 vertices, 35,324 triangles, 253 identity coefficients and 383 expression coefficients. The four joints are `neck`, `head`, `left_eye`, `right_eye`; there is no jaw joint. The stored pose-corrective regressor is entirely zero. The paper's table lists 382 expression dimensions, so consumers must bind to the actual versioned data rather than copying that table.

An independent SVD audit evaluated the documented bind-pose expression sum, with zero identity and joint motion. Each of the 383 expression coordinates was evaluated at -1, -0.5, 0.5 and 1 on each 1,440-vertex dental group. Proper-rigid registration was first checked against an analytic rotated/translated tetrahedron and a nonrigid scaled negative control. Upper-group maximum RMS residual was `1.5763507821070616e-17` source units. Lower-group maximum was `0.00011397858832435184` source units at `lower_face_region_001 = -1`. This is a check of the published linear representation, not execution of its full runtime, a clinical magnitude threshold, a tooth-only measurement or a collision test: the groups include gums.

The [audit receipt](gnm-representation-audit.json) preserves those observations. They rule out adopting GNM unchanged on the assumption that all internal parts already have rigid articulation. They do not rule out using its shared anatomy as a source or imply that the current basis is superior.

## Replacement architecture to evaluate

1. **One fine document.** Versioned shared-basis coordinates, anatomical dimensions, performance controls, procedural appearance and hair operations are the personal state. Easy controls compile into this state using explicit, reproducible transformations and preserve independently edited fine values. No personal vertex residual, guide array or image lookup is admitted.
2. **Identity before performance.** Evaluate neutral morphology and all dependent component locations together. Bind eyes, teeth, tongue, oral lining, lids and scalp to that same result. Shared attachment data belongs to the model and must be reproducible from its source.
3. **Articulation before tissue detail.** Jaw and eye transforms own rigid motion. Associated tissue follows the same articulation before local expression and pose detail are evaluated. The evaluator must not repair a tooth in isolation after the rest of the mouth has already taken another path.
4. **Coupled validity.** Joint limits, dental occlusion, eye/lid contact, lip aperture and tongue/teeth clearance are jointly evaluated on the same state. Establish the supported domain and the response to conflicting controls; do not silently clamp an unrelated control or hide visible tissue. Shared correctives are permitted only with an identified residual cause and evidence of behavior between their samples.
5. **Hierarchical procedural hair.** Numerical scalp regions and hairline define coverage; regional style operations generate a volume/guide field; generated strands follow that field; strips or other rendering geometry are derived from those strands. Density, physical width and rendering resolution have distinct meanings. Fine hair at boundaries is generated from the same boundary definition. Gathered styles need a general numerical gathering operation, not a named person's stored curves.
6. **Common measurements.** Compare candidates on identical neutral, identity-extreme, intermediate and combined-control cases before fitting the eighteen examples. Check rigid distances, attachment error, signed clearance, valid triangle area, symmetry/equivariance, deterministic replay and preservation of intended motion. A lower error in one region cannot compensate for breaking another constraint.

This is a design direction, not an implemented or proven solver. GNM, FLAME and the existing MPFB prior remain candidates for the shared neutral/identity source. The immediate comparison must settle the articulated model and coupling; another round of personal tuning would not answer that question. Final visual acceptance still requires actual editor and exported output after the shared model passes those checks.
