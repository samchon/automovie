# Instruction writing

Apply the [writing rules](../documentation/SKILL.md). Write for a reader new to the project.

## Task instructions

State the deliverable, recipient, acceptance checks and choices reserved for the user. Describe project-specific rules the code cannot show. Include a reason or example when it resolves ambiguity. Prescribe a method when it prevents a known failure.

State the default first and give each optional route its enabling condition. For each creation step, state its output and the decisions it owns. Link to the contracts that check it.

Use package types and JSDoc for API facts and the package README for entry points.

Keep history in Git. Disclose consequential delegated choices.

## Contracts and checks

Put rules that every Evidence-selected declaration, document or record must meet in the responsible [contract](../contracts/SKILL.md) item.

Give each statement one checkable assertion with its exceptions. Say whether failure lists are exhaustive. Where both matter, judge omission and excess together.

Group judgments that share the task, respondent, proof and repair owner. Give the overall outcome its own item. Record the support and limits of new quality claims before adopting them.

Use a hook or executable check for universal rules where practical. Update the check and its instructions together. Reuse tested helpers for repeated deterministic work. Link the command from the relevant resource and draw examples from its existing callers.

## Model configuration

Keep model, effort and tools in run configuration. Consult the [GPT-6.2 prompting guide](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.2-astra#prompting-best-practices) for model-dependent changes.

Group model instructions by technique. Keep provider examples together and defer parameters to provider documentation.

For direct Responses API integrations, follow the [prefix guidance](https://developers.openai.com/api/docs/guides/keep-prefix-unchanged) for durable instructions and appended updates.
