# Documentation

Good writing is the same for every reader: deliver the core point concisely and clearly. Only the reader, and so what the reader needs, differs by document; agent prompts add the rules in the [prompting skill](../prompting/SKILL.md).

Every document follows [Writing](writing.md), in English. That file is shared verbatim with generated productions, so repository-only rules stay here.

## READMEs

A README is for the package's user: what it is, when to use it, installation, the smallest working setup, and its public surface. Take every code example from code that runs.

## Doc Comments

JSDoc follows [Writing](writing.md), and interface types close with `@author Samchon`. What a public declaration's comment must say is the contracts [Meaningful documentation](../contracts/common.md#meaningful-documentation) chapter.
