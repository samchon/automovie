# Documentation

## Wording

- Keep the details the reader needs to understand, act or verify the result.
- Use shorter or clearer wording whenever it preserves meaning, clarity and necessary detail.
- Use a metaphor only when it makes the point clearer.
- Make one point per sentence.
- Use one term per concept. Define unfamiliar terms on first use or link to their definitions.
- Keep stock phrases, repeated openers, promotional adjectives and hedging out of prose.
- Keep emphasis capitals, bold, em dashes and emoji out of prose.

## Structure

Keep each list item and table row on one source line of at most 120 characters. Count link text without its destination.

### Paragraphs

Start a new paragraph whenever the topic changes. Saving a line break has no value.

### Lists

Use lists for parallel points or ordered steps. Use prose for connected explanations. Use a sublist only when several short details belong under one item and cannot fit on its line.

### Tables

Use tables for compact comparisons. Put explanations that exceed a cell in prose after the table.
