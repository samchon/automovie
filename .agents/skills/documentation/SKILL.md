# Documentation

## Accuracy

Verify claims, names and references against their sources. Distinguish facts from estimates and inferences. State what is unknown or omit the claim.

For instructions, state the conditions, exceptions and checks the reader needs. Include the reason if it changes how to apply the rule. Rewrite wording that permits conflicting readings.

## Wording

- Keep the details the reader needs to understand, act or verify the result.
- Use shorter or clearer wording when meaning, clarity and detail stay intact.
- Use a metaphor only when it makes the point clearer.
- Make one point per sentence.
- Use one established term per concept.
- Define or link unfamiliar terms on first use.
- State the action. Name the behavior when a prohibition is necessary.
- Avoid stock phrases, repeated openers and promotional adjectives.
- Keep emphasis capitals, bold, em dashes and emoji out of prose.

## Paragraphs

Use prose when the reader needs the reasoning behind a conclusion or the relationships between points.

Lead each paragraph with its point. Start a new paragraph whenever the topic changes. Saving a line break has no value.

## Lists and tables

Keep each list item and table row on one source line of at most 80 characters. Count link text without its destination.

### Lists

Use a list for points that make sense on their own or for short steps the reader must follow in order.

A sublist can show a hierarchy or break up a long item.

### Tables

Use a table when the reader needs to compare the same details across several items. Put longer explanations in prose after the table.
