# Parameters

## Detailed Parameters

Modeling reads only detailed parameters: named measurements, named physiological motions including facial expressions, and closed-set choices, never a vertex, curve, cage, or patch.

Each parameter channel varies one named trait. A normalized offset is zero at a declared neutral with a stated positive direction, and paired features carry explicit left and right values.

## Simple Parameters

Simple parameters, such as ancestry, cuteness, or slimness, are deterministic converters into detailed parameters and never reach modeling. A saved document stores the resolved detailed parameters.

## Admission

Admit only values and combinations a living body can take, deriving each dependent bound from the structure that limits it. Reject an impossible state with its cause and leave the caller's values unchanged.

## Output

Human's only contract with `interface` is its output model; it never enters films through a model recipe.
