# Supervision

Use the [supervision cycle](../multi-agent/SKILL.md#supervision) for authorized Human workers. The supervisor researches, plans, assigns and inspects. Workers implement and verify their assigned parts.

## Before dispatch

- [ ] Complete the [research](SKILL.md#research).
- [ ] Group findings by cause and plan coupled curves, frames, connections and bindings together.
- [ ] Give each file or tool one writer in the [same checkout](workspace.md#ignored-paths).
- [ ] Brief each worker on scope, measured cause, method, owners, checks and evidence paths.
- [ ] Record the report deadline and superseded instructions.

Reopen the plan when a shared dependency changes. Resume existing workers when possible.

## Every ten minutes

Audit at the start and at the user's fixed interval through tests and renders. Record scheduled, actual and next times. For each active worker, record pass, fail or unobserved for the checks that apply, with evidence and next action.

- [ ] Read the worker's diff, output and latest save against scope and ownership.
- [ ] Check the [single watch](testing.md#running), viewer and running jobs.
- [ ] Open reference comparisons on both sides and with neighbours in the [three passes](screenshot.md#the-three-passes).
- [ ] Match measured failures to their diagnostics and passing controls.
- [ ] Check changes against the relevant skill. Correct violations at their owner.
- [ ] Research unresolved causes before ordering another variant.
- [ ] Read checks at the measured revision. Identify baseline failures and unavailable coverage.
- [ ] Send findings, acceptance, next work and deadlines to each worker.
- [ ] Report observed work and open decisions to the user.

If no new frames exist, open an unreviewed pair or arrange capture. Reuse unchanged evidence by recorded version.

## The cycle

On a late audit, inspect immediately, record the gap and keep the next fixed deadline. Pause workers if supervision becomes unavailable. On a user stop, stop workers and alarms and preserve work and evidence.

## Stop conditions

Correct these before proceeding.

- An unmeasured cause, unresearched variant or separate fixes for one shared cause
- A band, rail, net or relief hiding a curve defect
- An unplanned rebuild of a working neighbour
- Missing independent test evidence or a revert that only quiets a dependent
- Conflicting writers, stale generated files or ignored executable logic
- Missing watch or admission checks, or a commitment that fails the delivery gate

## Before delivery

- [ ] Retain an accepted whole-figure capture and deviation round at its source revision.
- [ ] Compare all changed regions in the same round and fix regressions before adopting a baseline.
- [ ] Verify checks at the delivery revision and state what was unobserved.
