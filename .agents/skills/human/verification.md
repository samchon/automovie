# Verification

## Gate Identities

Calibrate and judge form on lean 20-year-olds: a slim, model-grade woman and man, and a low-fat muscular woman and man for muscle relief. Fat, sagging skin, and wrinkles hide wrong form, so other people only confirm the converter's range after these four pass.

## Judgment

Every Human part is generated from curves, so every judgment of it shows its [construction](../3d-modeling/visual-debugging.md#construction).

Apply [Correction Rounds](../3d-modeling/visual-debugging.md#correction-rounds) to the joined gate identities and their nearest references, assigning each cause and shared boundary to an owner.

Keep numerical, clinical, and visual judgments distinct, and preserve the last valid state when an operation fails.

When two consecutive matching renders show no gain, change the source, correspondence, or representation, not a solver or tolerance.

When the code-and-formula route seems unable to reach the quality bar, stop and report it; never substitute data or another route.

## Reporting

Attach the screenshots behind a visual claim where the user reads them, and report progress as stages and renders, never as a percentage.

## Files

`.shots` holds only the current task's inputs, references, working artifacts, and viewer runtime files; identify a file's use before deleting it.

Save completed viewer displays to `.shots/output`, keeping only the images the current judgment needs, the active before-and-after pair included, and keep metadata and logs outside it.
