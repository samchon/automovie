# Anatomical Principles

These chapters address values and controls that stand for a living human body, in addition to the common and modeling chapters. A human form has no source mesh to simplify and no generative image model to correct it. The parameters are the source of truth, so the cited measurements and anatomy are the only standard a result is judged against.

## Anatomical Source

Apply to declarations that carry an anatomical value, range, proportion, landmark or tissue behavior.

Ground each value in a primary measurement, a dissection study or an established physiological account, and take the value from the source as written. Record whether the value is measured, derived from measurements by a stated relationship, fitted to a stated population, or set by convention. Fit only to a population a source measured, never to one person, photograph or render. Keep the source's conditions with the value, namely its population, age, sex, ancestry, posture and measurement definition, and apply the value only within them.

Identify the source by author, year and venue, the quantity it measures under its own definition, its population and conditions, and the kind of the value. Separate what the source states from what the declaration infers. Cite only a source that was read, because a remembered figure is not a citation. State where the source is weak or absent or where the declaration departs from it, and what the declaration does there.

## Permitted Range

Apply to declarations that admit, bound or combine anatomical values.

Admit only values, and combinations of values, that a living human body can take. Derive each bound that depends on another quantity from the structure that limits it, such as a joint's range of motion, a tissue's extensibility or a neighboring structure's clearance. Reject a state outside the range with a reported cause and leave the caller's values unchanged. Check combinations separately from single values, because every value can be permitted while their combination is impossible.

Identify each bound, the dependencies between quantities, and how the declaration decides the admission of a combination. Explain the behavior at and beyond each bound.

## Parametric Authority

Apply to declarations that define or convert an input through which a caller shapes a human form.

Make every input a named anatomical measurement, a named physiological motion or a choice from a closed set. An input may be as specific as the source allows. No input addresses a vertex, a curve, a strand or a surface patch, and no input sculpts. Define each conversion between a simple input and a detailed input as a deterministic function of documented anatomical relationships, and state its inverse or why none exists.

Identify the measurement, motion or choice set each input stands for and the conversions into and out of the detailed values. Explain why no input can address geometry directly.
