# Scaffold

A production's own `AGENTS.md`, `README.md`, selected `docs` contracts, and typed declaration own its meaning; read them and the installed package APIs before interpreting, authoring, or reviewing it. Repository instructions never override them. The scaffold [README](../../../packages/template/scaffold/README.md#ownership) defines what the scaffold owns and how a production adopts static-document updates.

- `@automovie/evidence` pins the shipped contract filenames and their ordered H2 anchors. Change targets, selectors, citations, and consumers together, and never shrink a population to hide debt.
- Keep shipped contracts independent of any production's content. Maps own broad-world content and site interfaces; spaces own building and site topology inside them.
- Look for a shipped contract's sources in [references.md](references.md) first, and read each passage you cite.
- For changed installation behavior, observe a generated consumer's installed entry point, preserved content, and repeatable adoption.
