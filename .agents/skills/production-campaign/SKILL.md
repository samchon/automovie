# Production campaign

Carry the commissioned work through its actual authoring and delivery owners. The production's [campaign guide](../../../packages/template/scaffold/.agents/skills/production/campaign.md) owns its run record, dispatch, and film and module ownership; its specialist skills own creation and acceptance. This skill owns how the coordinator of a campaign run from this repository launches, watches and connects those workers and compares productions. Keep these rules here: the scaffold ships to everyone who installs AutoMovie, and its productions are not bound to this repository's process launching or observation. Repository [issue campaigns](../issue-campaign/SKILL.md) own broad engineering audits and issue publication.

Keep the scope and current baseline explicit. A single film's observed execution establishes that film's behavior, not comparative quality across productions, and instruction edits alone establish no improvement in a screenplay or film.

Read the procedure for the current task.

- [Run](run.md): preparation, CLI launch, run records, write scope, missing capabilities, comparison and Git ownership.
- [Observe](observe.md): the observer subagent's ticks and the revival of a stopped run. Give it to the observer as its brief.
- [Review](review.md): fixing a submission, launching an independent reviewer, relaying verdicts and rebuttals.
