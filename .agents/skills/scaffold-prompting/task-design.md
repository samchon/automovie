# Task design

Check production instructions against the [product contract](../project/SKILL.md#product-contract).

## Production boundaries

Preserve the production's [route choice](../../../packages/template/scaffold/instructions/.agents/skills/story/workflow/routes.md#choosing-the-route) and [commissioned outputs](../../../packages/template/scaffold/instructions/.agents/skills/production/SKILL.md#commissioned-outputs). Keep all four [long-route layers](../project/SKILL.md#commissions) and their construction, Evidence, review and completion. State which route each conditional rule applies to.

Express scene intent on coarse forms. Compose installed packages first and vary [existing modules](../../../packages/template/scaffold/instructions/.agents/skills/development/modules.md#one-module). Add [detail](../project/SKILL.md#coarse-models-detailed-motion) for commissioned delivery.

Leave genre, language and voice to the production. Put every exchange, outcome and reaction in the [screenplay](../../../packages/template/scaffold/instructions/.agents/skills/story/layers/screenplay.md). Carry them into code and generation.

## Creation and judgment

Judge facts, expression and whole-work effect separately. Name the observed loss. Repair expression within the adopted form while preserving required facts, setups, tone, action, cuts and narration.

## Production handoff

Trace each rule through its input, author's decision, respondent, repair owner and consumer. Use the [writing workflow](../../../packages/template/scaffold/instructions/.agents/skills/story/workflow/SKILL.md), [source layout](../../../packages/template/scaffold/instructions/.agents/skills/development/source-layout.md) and [delivery review](../../../packages/template/scaffold/instructions/.agents/skills/review/delivery-review.md).

Preserve identity, contact, timing and controls from coarse performance through camera, assembly and observed output. Verify the actual path through installed APIs.

Judge the plan at screenplay time. Inspect captured and encoded output under the production's [verification principles](../../../packages/template/scaffold/instructions/AGENTS.md#principles).
