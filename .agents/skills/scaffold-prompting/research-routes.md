# Primary research routes

Read the relevant original before adopting a new instruction, and keep its support separate from the production judgment. These sources inform design; none proves that a changed prompt improved a film.

| Source | What to examine | Application limit |
| --- | --- | --- |
| [Anthropic: Prompting Claude Opus 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5) | Clear goals, current context, explicit operating boundaries and observed harness behavior | Model-specific guidance needs verification on the actual author and task; it supplies no film-quality acceptance |
| [AFTRS: Screenwriting](https://medialab.aftrs.edu.au/wp-content/uploads/2021/07/AFTRS16_Screenwriting.pdf) | Resource-aware short-film design, characters, dialogue, rewriting and the handoff from script to production | This teaching resource's duration and cast suggestions are not universal limits for shorts, abstract films or other adopted forms |
| [ScreenSkills: Script supervisor](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/technical/script-supervisor-film-and-tv-drama/) | Script breakdown, timing, dialogue, action, eyelines and prop continuity across actual takes | A role description supports those responsibility boundaries, not a required document template or a native Evidence guarantee |
| [OpenBMB: VoxCPM](https://github.com/OpenBMB/VoxCPM) | Current installation, model inputs, fixed recordings and speech generation | Inspect the installed version's actual signature and execute it; a remote example, seed or model load does not establish usable speech or synchronized delivery |
| [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html) | Actual trimming, timestamp rebasing, resampling and retiming behavior | An encoder's success cannot establish retained action, intelligibility, synchronization or final playback quality |

Use the production's existing source, motion, audio and delivery records for observations. Keep a local tool failure and its correction with that tool's owner; do not turn one production's workaround into a mandatory scaffold rule.
