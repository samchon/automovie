# Tripo

Hosted API. Values were read from the linked documentation in November 2026; it owns them, so read it again when choosing.

- **Input:** text, one image, or 2 to 4 views keyed front, left, back and right of one object under the same light; the front cannot be left out.
- **Beyond the mesh:** segmentation into parts, retopology, texture coordinates, format conversion, a rig check with automatic rigging, and animation retargeting.
- **Output terms:** read the plan's terms; the free tier's are not stated consistently.

Documentation: [quick start](https://developers.tripo3d.com/en/docs/quick-start), [multiview to model](https://developers.tripo3d.com/en/docs/generation-multiview-to-model/standard).
