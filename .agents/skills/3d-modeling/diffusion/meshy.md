# Meshy

Hosted API. Values were read from the linked documentation in November 2026; it owns them, so read it again when choosing.

- **Input:** text, one image, or 1 to 4 images of one object, the first read as the front.
- **Rest pose:** A-pose or T-pose at generation.
- **Topology:** a face count of 100 to 300,000 and quad or triangle faces apply only when remeshing is enabled, which is off by default on most model versions. An uploaded GLB, glTF, OBJ, FBX or STL mesh can be remeshed alone.
- **Rigging:** a textured biped humanoid, as a GLB facing +Z with at most 380,000 triangles, with walk and run clips.
- **Output terms:** free-plan outputs are CC BY 4.0 and need credit; paid plans give a private license.

Documentation: [image to 3D](https://docs.meshy.ai/api/image-to-3d), [multi-image to 3D](https://docs.meshy.ai/api/multi-image-to-3d), [remesh](https://docs.meshy.ai/api/remesh), [rigging](https://docs.meshy.ai/api/rigging), [pricing](https://docs.meshy.ai/pricing).
