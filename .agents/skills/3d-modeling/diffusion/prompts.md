# Text prompts

Use text alone only when no image or shape is available. With other inputs, follow the model guide and describe only missing information.

Unless the guide specifies an order, name the subject, materials, style and technical constraints in that order. Specify concrete shape, material and scale.

Use the model's negative field for exclusions when available, or state them plainly. If the model starts from a generated image, write the prompt for that image.

Sources: [Meshy prompting](https://docs.meshy.ai/en/webapp/guides/prompting), [Tripo text to model](https://developers.tripo3d.com/en/docs/generation-text-to-model/standard), [Rodin Gen-2.5](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5), [Meshy pose and hands](https://help.meshy.ai/en/articles/16102152-fix-character-pose-face-and-hand-issues-in-meshy).
