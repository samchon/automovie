# Rodin

Hyper3D's hosted API, Gen-2.5. Values were read from the linked documentation in November 2026; it owns them, so read it again when choosing.

- **Input:** text, or 1 to 5 images, the first of which sets the materials.
- **Beyond the mesh:** five quality tiers and textures of 2K to 12K.

Documentation: [API](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5).
