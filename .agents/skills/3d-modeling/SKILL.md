# 3D Modeling

An asset is something the engine owns: built from named parameters, reproducible, rigged on the shared skeleton when it moves, and judged on screen. The user chooses whether a form is authored directly or rebuilt from a diffusion model's output:

- Read [Authoring](authoring.md) when building or changing a form from parameters and formulas.
- Read [Diffusion](diffusion.md) when a diffusion model's image or mesh is the source of a form.
- Read [Visual Debugging](visual-debugging.md) before judging any visual result or claiming a visual change works.
