# 신체 저작 요구사항 {#body-requirements}

신체 저작은 목 절단면 아래 전신을 하나의 연결된 수치 기저 위에서 형태, 관절과 실측 단위 채널로 저작하는 경계다. 이 요구사항군은 [일반 actor 계약](../README.md) 안의 상세 신체 형태 저작이며, [얼굴 저작](../facial-authoring/README.md)과 같은 소스 메시의 나머지를 다룬다. 사진과 같은 체형의 자동 복원, 의복, 머리카락, 물리 시뮬레이션과 애니메이션 타임라인은 확장하지 않는다.
