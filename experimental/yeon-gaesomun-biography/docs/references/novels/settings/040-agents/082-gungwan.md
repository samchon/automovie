# 돌사성 공격의 군관

## 돌사성 공격의 군관 {#gungwan}

**정의·범위**

군관은 돌사성 공격에 이름이 기록된 신라 장군이다.

**확정 내용**

직업을 뜻하는 보통명사 군관과 달리 이 대목에서는 인명으로 쓴다. 현재 예정 서사에서 김인문·품일·문영과 함께 공격했다는 보고의 당사자로만 등장한다. 직접 얼굴과 목소리를 만들거나 누가 먼저 성문을 넘었는지 확정하지 않는다.
