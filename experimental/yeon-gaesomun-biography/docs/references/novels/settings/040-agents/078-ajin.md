# 아들의 칼을 받는 아진

## 아들의 칼을 받는 아진 {#ajin}

**정의·범위**

아진은 귀돌의 어머니인 창작 인물로 610년생이며, 아들이 돌아오지 않은 뒤 찬오가 가져온 칼을 받는다. 부친은 본편 전에 죽어 직접 참여하지 않는 가족 조건이며 별도 인물 사건으로 늘리지 않는다. 아진은 수송 성공을 들어도 아들의 노동과 귀환을 대신 받지 못한다. 찬오에게 자기 아들이 마지막까지 어떻게 걸었는지 묻지만 그가 보지 못한 사실까지 알아내지는 못한다. 이후 생계는 이웃과 친족의 계절 품앗이를 받아 경작을 이어가는 것으로 정하며, 왕의 포상이 모든 손실을 해결한 것처럼 지우지 않는다.

**확정 내용**

키 153센티미터, 굵은 손과 짧은 목, 둥근 턱이다. 갈색 눈과 옅은 검은 눈썹, 낮은 코와 넓은 입, 그을린 황갈색 피부를 가진다. 검은 머리에 회색이 섞이고 뒤로 말아 묶는다. 회갈색 옷에 짙은 갈색 앞치마를 두른다. 목소리는 중간보다 낮고 쉰 결이며 울음을 참을 때 끝말이 잠긴다. 찬오가 자기 부상을 숨기려 하면 손을 먼저 보고 앉힐 자리를 마련한다.
