# 의자왕의 공세와 패망

## 의자왕의 공세와 패망 {#uija}

**정의·범위**

의자왕은642년 대야성을 비롯한 신라의 여러 성을 공격한 백제 군주이며660년 당·신라 연합군에 왕조를 잃는다.

**확정 내용**

고구려 수뇌부는 자기 전쟁 밖에서 남방 강약을 판단할 때 의자왕의 공세와 패망에 관한 서로 다른 보고를 받는다. 백제 부흥의 왕 부여풍과 합치지 않는다. 현재 예정 서사에는 의자왕의 독립 궁정 장면과 직접 대사가 없으므로 얼굴과 음성은 창작하지 않는다.
