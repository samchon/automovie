# 인계터의 운반 병력

## 인계터의 운반 병력 {#yang-o-porters}

**정의·범위**

당의 인계 병력은 마정의 명령으로 포대를 내려 놓고 건조한 곳으로 옮기며 주둔지에 넘기는 무명 역할 집단이다. 신라 수송대와 같은 사람으로 합치지 않는다. 이들의 독립 전사나 배신, 개별 가족은 현재 예정 서사에 없다. 배급을 기다리던 병사 가운데 인계 업무에 붙인 사람이며 이미 굶주리고 추위를 겪어 작업 속도가 평시와 같지 않다. 받았다는 보고와 실제로 옮겼다는 보고는 마정이 구별한다.

**확정 내용**

공통 조형은 볕에 탄 피부와 검게 묶은 머리, 검은 띠를 두른 회갈색 옷, 수선한 가죽 덧옷과 손을 감은 천이다. 포대를 받는 짧은 응답은 숨이 차고 쉰 소리로 돌아오며 현재 장면에서 고유한 한 명의 목소리를 요구하지 않는다.
