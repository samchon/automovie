# 사민과 잔류가 갈라 놓는 생활

## 사민과 잔류가 갈라 놓는 생활 {#forced-migration}

**정의·범위**

고구려의 멸망 뒤 주민이 강제로 당 내지에 옮겨지는 사건을 사용한다.669년의 수치는 『삼국사기』 원문38,300호를 소개하되38,200호·28,200호·30,000호 등의 이본과 구별한다. 호를 사람 수로 읽어3만8천명이 이동했다고 쓰지 않는다. 정확한 전국 인구와 한 호의 인원도 이 기사에서 역산하지 않는다.

**확정 내용**

평양 주민이 전부 끌려가고 귀부한 요동·국내성 주민은 전부 남았다는 단순한 양분은 하지 않는다. 중앙의 인구와 지휘 집단을 분산하려는 이동이 있고 남은 주민도 있다. 당에 협조한 지휘자의 관계가 어떤 가족을 보호할 수 있지만 모든 가구의 이동을 막는 보증은 아니다. 해은은 가족과 함께 내지로 옮겨지는 가구, 미란과 속로의 공동체는 동부에서 남은 사람들이 다시 군역과 통치를 요구받는 가구로 구성한다.

해은의 도착지는 하남의 농촌 지역으로 정한다. 정확한 현대 마을을 실제 이주 명단에 남은 거주지라고 주장하지 않는다. 평양에서 가져온 수선 도구와 몇 조각의 천은 남지만 같은 거래 상대와 일자리는 없다. 석부는 고구려에 남아 싸운 뒤 무장을 빼앗긴 생존자이며 자기 지역에서 노동을 요구받는다. 남은 사람이 나라가 보존되었다고 느끼거나 옮겨진 사람만 고구려의 멸망을 느끼는 구도가 아니다.
