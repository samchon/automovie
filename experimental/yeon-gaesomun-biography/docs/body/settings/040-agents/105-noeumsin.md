# 북한산성을 공격한 뇌음신

## 북한산성을 공격한 뇌음신 {#noeumsin}

**정의·범위**

뇌음신은661년 술천성 공격에 실패한 뒤 북한산성으로 옮겨 간 고구려 장수다.

**확정 내용**

성을 공격할 장비가 있어도 제한된 병력과 기간으로 모든 요새를 함락할 수는 없다는 보고의 당사자다. 생해의 다른 이름으로 합치지 않는다. 현재 예정 서사에는 공격 결과의 보고만 있으며 고유한 얼굴·음성이나 별도 전공을 정하지 않는다.
