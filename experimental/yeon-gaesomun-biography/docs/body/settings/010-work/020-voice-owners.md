# 역사가의 목소리와 말씨

정전 안내: [이 대상의 위치](../outline/index.md#010-work--020-voice-owners).

## 사실을 보존하며 표현을 고치는 범위 {#fact-preserving-expression}

적용 범위와 사실 보존의 지시는 [표현 지시](../../../instructions/009-expression-quality.md#fact-preserving-expression)가 소유한다. settings와 treatments는 construction에서 명료성과 내용을 함께 완성한다. scripts와 screenplay는 각각 자기 construction 원본을 보존한 표현 개고를 거친다. 인물·관계·수치·결과·불확실성을 지우는 간결화는 허용하지 않는다.

## 후세에서 사건을 적는 역사가 {#chronicler}

평가·예고·원경과 근경·여러 진영의 접근은 [역사가와 장면 계약](../../../../.agents/skills/contracts/story/work/obligations/narratives.md#chronicler-and-scene)이 소유한다. 각 인물이 실제로 아는 사실과 보고 경로는 해당 세계·인물·작전 정전에서 확정한다.

## 읽히는 말씨와 인물 사이의 거리 {#speech-registers}

한국어 번역 말씨·높임·호칭·통역은 [관계의 말씨](../../../../.agents/skills/contracts/story/language/principles/realized.md#korean-register)가 소유한다. 물리적 음성·발화 습관·관계에 따른 변화는 각 인물 정전이 소유한다. 관객이 모두 한국어로 듣는다고 등장인물의 역사적 언어가 같아지는 것은 아니다.

## 이름과 날짜를 부르는 방식 {#names-and-calendar}

이름·왕호·중국 인명과 지명·서기·음력·나이·단위의 표현은 [값 표기](../../../../.agents/skills/contracts/story/language/principles/common.md#korean-values)가 소유한다. 실제 값과 변환 근거는 각 사실의 정전에 있다. 별도의 양력 변환을 하지 않은 작품 달력은 음력이다.

## 웃음이 붙는 곳과 멈추는 곳 {#irony-and-weight}

건조한 아이러니·블랙 조크·패러디·풍자의 표적과 정조는 [역사가와 장면](../../../../.agents/skills/contracts/story/work/obligations/narratives.md#chronicler-and-scene)이 소유한다. 사용하는 실제 선례와 인용의 존재·문구·시대적 접근성은 해당 역사 사실의 owner에서 확인한다.

## 확인한 기록과 구성한 장면의 간격 {#record-and-reconstruction}

외부 사실과 불확실성은 각 settings H2에서 출처·판본·채택 경계를 찾는다. 원본의 출처 설명을 이어받은 것과 이번 제작에서 외부 원문을 다시 연 것은 다르며, 새 확인 범위는 [요구 탐색](../../../../.agents/skills/contracts/story/work/discovery/results.md#research-boundary)에 적는다. 장면의 구체 대사와 내면은 기록된 발언이라고 오인시키지 않는다.
