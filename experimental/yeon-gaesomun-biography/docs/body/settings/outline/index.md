# 《대막리지》 정전 안내

형제 부는 참조 대상의 종류로 나눈다. 작품 약속에서 세계와 제도, 참여자, 운용 조건, 장소와 물건으로 간다. 같은 대상의 상세는 유일 owner에서 찾는다. 이 순서는 본편의 사건·공개 순서가 아니다.

## 사람과 공동체의 독립된 처지 {#040-agents}
