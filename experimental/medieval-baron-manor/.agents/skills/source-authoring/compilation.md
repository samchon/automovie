# Compilation

Compile and execute the production's typed source. [Ownership](../../../README.md) owns the project layout and file boundary. A library producer returns the declared model, map, or environment directly; film and brief producers additionally realize the selected staging, motion, camera, sound, and timing. Do not introduce a serialized project store between a producer and its consumers.

Keep package and compiler settings in `package.json`. The source compiler checks the complete source program, including any command or browser modules the production authors. Select the execution tooling required by those modules and keep its entry points under the source root. A browser producer must not import Node-only modules at runtime.

Validate the typed result at its consuming package boundary. Preserve identity, ranges, references, deterministic geometry, actor and object motion, camera and event timing, and the declared result population. An invalid input or result must remain a diagnostic rather than being replaced by an empty successful output.

Use the same producer and explicit input values for measurements, preview, and delivery. Record the exact source revision and invocation basis with an observation. A result from earlier source cannot answer for a changed producer, and an output's existence does not establish its currentness.

## A clean compile is not a look

Compilation establishes type and declared structural agreement. It does not establish appearance, natural motion, legible composition, or a completed review.

Open the exact required images, play the required intervals, and examine the complete declared production population under [Review verification](../review-verification/SKILL.md). Preserve missing, failed, unsupported, and unobserved outcomes. A successful command cannot turn any of them into accepted work.
