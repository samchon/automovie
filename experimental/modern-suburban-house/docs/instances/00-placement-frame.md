Furniture/fixture membership is exactly one object per reservation whose `kind` is furniture, fixture, storage or covering, supplied by [room design](../spaces/rooms/common.md#common-room-plan). Retain the reservation id (for example `common-dining-table`); objects standing in use areas, such as chairs/stools, remove `-use` from the use-area id (for example `common-island-stool-1`). Derive membership only from src/spaces/rooms/*.ts `reservations` records and this H2's rules; keep no separate coordinate table. Adding/removing a reservation in a room document adds/removes the same-named object; create no unreserved furniture. Route/swing areas and human-only use areas receive no objects. When one model's members fill multiple reservations, the room H2 names all reservation ids/prototypes and records the reservation→object relationship as many-to-one. This exception applies only to pantry L-shelves, the kitchen-island sink, shower taps/head and garage-door rails. Models owns prototype geometry; each room H2 links the corresponding models H2 per member. The contract is [one-to-one room reservation/object correspondence](../contracts/reservation-fill.md#reservation-fill). Source owners are placement modules under src/instances/. Observe that every reservation id has one object and no unreserved objects exist.

The parent frame of room furniture/fixtures is the right-handed Y-up world of [coordinate settings](../settings/00-production.md#coordinate-units), in m/rad. Prototype-local +Z is the front approached by users. Each models H2 declares its local origin (plan center, floor center of the wall-contact rear edge, horizontal center of a wall-mounted lower edge, etc.). Object position is the reservation point corresponding to that origin: plan-center origins use x/z midpoints; rear-edge origins use the midpoint of the edge opposite the front; wall-mounted origins use the wall-side edge midpoint. Y is the reservation y lower bound: main floor-standing objects use ground floor 0.00 m or upper floor 3.06 m, garage objects use its own floor -0.15 m, and wall attachments retain their declared lower height above that host floor. Room objects rotate only by Y-axis yaw: front +Z gives 0, +X π/2, -X -π/2 and -Z π. Front faces the adjacent use/swing area; each H2 specifies direction where none exists. Scale is always 1; size differences use declared model parameters or separate prototypes. Only roof-slope shingles add pitch from the [roof-face basis](03-exterior-repetition.md#shingle-course-law). Identical inputs yield identical transforms independent of traversal order.
