# Compiled observation set

This target records the production-specific review denominator derived from the compiled building topology.

## The review denominator is derived from topology {#review-denominator-derived-from-topology}

The exterior population contains the setting, every exposed elevation, every exposed footprint corner, every exposed roof and underside, and every opening and entrance. Every compiled room contributes one threshold, four inside corners, and four in-room cardinal directions. Ids, positions, dimensions, and bindings are read from the compiled result. A frame answers one question only; the section axonometric is inspection-only and never reduces this population.

Authority: the user's 2026-09-16 brief. A hand-picked hero view is not a complete review.

Review question: does the current compiled topology generate every required exterior, opening, and room observation without relying on a favorable author-selected view?

Sources: user brief, 2026-09-16; [NASA systems engineering handbook appendix on verification methods](https://www.nasa.gov/reference/system-engineering-handbook-appendix/)
