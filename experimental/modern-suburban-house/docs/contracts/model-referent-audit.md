# 상류 부재 참조의 제작자 대조

이 주택에서 reviewed settings·spaces가 models에 인계하는 부재 전체에 적용한다.

## 상류가 부르는 부재의 제작자를 확인한다 {#model-referent-audit}

reviewed settings·spaces가 언급한 물리 부재는 장소와 역할을 가진 제작 H2 또는 명시적 비메시 owner를 가져야 한다. 어휘 표의 후보만으로 해당 장소의 제작자라고 판정하지 않으며 새 어휘가 어휘 밖에 남으면 계측 한계로 드러낸다.

Review question: 상류의 각 명명 부재에 그 장소의 설계 제작자가 있으며 계정 어휘가 새로운 참조를 누락하지 않는가?

Sources: 사용자 판정 v-099 F1, v-114 N2, v-120 R1.
