# Ancient civic temple model contract

This production-local target binds the model population to the reviewed temple graph and the settings identity without turning the model layer into a second space, material, or instance owner.

## Temple blocking model boundary {#temple-blocking-model-boundary}

Authority: the reviewed temple settings and spaces graph, interpreted by the model author within the production's blocking fidelity ceiling. Applicability: the independently owned fixed prototypes for column, door, fountain-basin, fountain-stream, altar-plinth, roof-tile, records-table, records-shelf, records-chest, storage-shelf, storage-chest, storage-basket, votive-display, ceramic-vessel, lamp, and bench. Success is a deterministic prototype set whose stable silhouette, scale anchor, hierarchy, visible surface owners, and negative spaces make each named role readable while preserving the compiled space and opening topology. Failure is a prototype that changes a room boundary, opening, route, landmark relation, or material-owned surface; silently substitutes a stronger fidelity than the blocking pass promises; or leaves a named role without a reviewable geometry boundary. Any missing space, placement, finish, or repeated-membership decision returns to its owning layer rather than being invented here.

Review question: can every promised temple object be built and reviewed as a bounded prototype without the model author inventing topology, placement, material response, or population behavior?
