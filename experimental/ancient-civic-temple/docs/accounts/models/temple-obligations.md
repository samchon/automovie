# 신전 모델의 관절과 검토 판 결산

두 생산 계약 항목은 모델 population 전체의 역할 배정과 관찰 계획을 결산한다. 각 원형의 축척·UV0는 별도 원칙에 따라 자기 모델 H2가 답한다.

## 관절 역할 배정 {#articulation-allocation}

<!--

[양개 문짝](../../models/openings.md#double-door-leaf)과 [외개 문짝](../../models/openings.md#single-door-leaf)만 공개된 hinge 상태를 가진다. 닫힘·열림은 같은 판의 두 상태이며 새 모델 형상이 아니다. [공통 관절 의무](../../contracts/obligations-models.md#temple-articulation-map)는 나머지 47개 원형을 강체로 둔다. 수위·불꽃·배치의 시간 변화는 후속 systems·motions·instances의 일이다.

## 중립 검토 판의 역할 {#neutral-review-allocation}

<!--
@evidence contracts/obligations-models.md#temple-model-review-board 49개 원형 H2의 크기·접촉·개구를 한 중립 판에서 비교한다. 여섯 전체 방향에 부재 접합의 맞은편 근접 방향, 두 문짝 상태, 말린·묶음·펼친 두루마리와 3×3 기와 반복을 더한다.
-->

[중립 검토 판](../../contracts/obligations-models.md#temple-model-review-board)은 개별 원형을 같은 배경·광원·포락·카메라 비율로 비교한다. 여섯 전체 방향과 각 H2의 접촉·빈 공간·경계 및 치수 변형의 맞은편 근접 시점, 두 문짝 상태, 두루마리 변형과 기와 3×3 반복을 관찰 주소로 둔다. 실제 건물 안의 배치와 접촉은 [spaces 관찰](../../spaces/observations.md#geometry-observations)이 맡으므로 이 판의 단독 형상 검토를 건물 납품 검토로 세지 않는다.
