사용자 지시: 한 도시 구역이 공동으로 쓰는 중소형 신전이다. 저작자 결정: 특정 유적·연대·신격의 복원이 아닌 고대 지중해를 연상시키는 가상 건물이다. 작은 봉헌·문서 보관·관리 활동이 제실과 함께 존재한다. 왕궁·대신전·성벽·도시 전체·군중은 포함하지 않는다. 역사 정설을 단정하는 설명이나 고대 언어의 가짜 비문을 만들지 않는다.

사용자 지시를 그대로 유지한다. 직사각형 단층 외곽 안에 중앙 중정 하나를 둔다. 현관은 중정으로 곧장 이어지고 하나의 연속된 주랑이 유일한 순환 루프다. 후면 축은 작은 제실, 좌측은 공동 봉헌실, 우측 전후 일렬은 관리실·기록실·봉헌물 보관실, 후면 우측은 작은 서비스 마당이다. 저작자 결정: 우측 세 방의 순서는 정면에서 후면으로 관리실→기록실→보관실이다. 중정·주랑·현관·제실·봉헌실·세 업무방·서비스 마당은 전부 같은 storey에 속한다. 방마다 주랑으로 직접 통하는 실제 문을 두며 방 간 연속 출입을 유일한 경로로 삼지 않는다. 숨은 방·단절 통로·복층·중정 추가를 금지한다. 서비스 마당에는 주랑 직접 문과 외부 서비스 문을 둘 수 있지만 두 번째 순환 복도를 만들지 않는다. 좌우·전후 방향은 [좌표](00-delivery.md#coordinates)를 따른다.

저작자 가정: 정지된 개관 상태의 건물이며 인물 mesh는 없다. 성인 보행자 한 명의 검토용 이동 포락은 폭 0.6m·깊이 0.4m·높이 1.9m로 삼는다. 봉헌물 운반 포락은 사람을 포함해 폭 0.8m·깊이 0.8m·높이 1.9m다. 인체 통계나 모든 이용자에 대한 보증이 아닌 공간 점검용 설계 입력이다. 주랑은 두 보행자가 교차하고 작은 운반물이 지나갈 수 있어야 하며 기둥·문짝·집기를 뺀 유효폭 최소 1.5m를 유지한다. 방 문 유효폭 최소 0.9m, 유효높이 최소 2.1m, 정문은 두 짝이 열렸을 때 유효폭 최소 1.4m다. 평면에서 이동 방향을 바꿀 수 있지만 회전 구간도 같은 포락이 고정 부재를 통과하지 않아야 한다. 운반 포락은 손으로 든 작은 봉헌물에 한정하며 큰 가구의 최초 반입이나 바퀴 달린 운반 수단의 통과까지 입증하지 않는다. 문턱·계단의 저작 허용값과 서비스 반입 조건은 [바닥과 지상 접근](#ground-access)을 따른다. 인원 수용 정원과 군중 시뮬레이션은 선언하지 않는다.

서비스 마당의 [작은 손수레](35-objects.md#handcart)는 움직이지 않는 외부 소품으로만 허용한다. 바퀴 굴림·문 통과·적재 성능을 입증하는 운반 수단으로 쓰지 않으므로 위의 바퀴 운반 통과 제외와 충돌하지 않는다.

저작자 결정: 지상 단층이며 지하실이나 내부 계단층은 없다. 정문 접근, 제실 제단 주변, 중정 가장자리의 낮은 석단과 방별 낮은 문턱을 허용한다. 이 석단은 같은 지상층의 국소 높이차이며 새 층이나 숨은 공간을 만들지 않는다. 저작자가 채택한 형상 범위는 석단 한 단 높이 0.10~0.15m, 유효 디딤 깊이 최소 0.30m, 문턱의 인접 바닥 대비 높이 0~0.02m다. 이것은 보행 경로의 설계 입력이며 고대 시공 관행·현대 법규·모든 사람의 이용 가능성을 주장하는 수치가 아니다. 주랑의 보행 바닥은 하나의 연속 높이이며 중정 가장자리의 얕은 단은 눈으로 읽혀야 한다. 연결 경로가 단차를 만나면 source가 실제 발 디딤 면과 연결 구간을 가져야 한다. 닿지 않는 semantic connector는 통행으로 세지 않는다. 서비스 반입 경로는 외부 문부터 마당·주랑·보관실까지 끊기지 않고 문턱 허용값을 넘는 높이차를 만들지 않는다. 이 경로에 계단이 필요해지면 작은 봉헌물 운반 조건과 지면 높이를 earliest owner에서 함께 재검토하며 연결선만 그어 통과로 선언하지 않는다. 외부 도로의 정문 접근 석단과 서비스 경로를 같은 통행 조건으로 혼동하지 않는다.
