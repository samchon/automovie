# Settings repair exposed by treatments

Each treatment H2 answers about its actual settings parents and inherited instruction choices. This is an audit of parents tested by creation, not permission to invent missing settings inside treatments. Repair follows the [closed-pass boundary](../../../../screenwriting/repair.md#closed-passes).

## What did event design prove missing or unusable upstream? {#settings-repair}

Identify the exact settings owner for any false, missing, contradictory, overdetermined, or unusable cause, authority, chronology, relationship, power, resource, knowledge boundary, consequence, work promise, spatial condition, appearance, or object state exposed by this event design. State the conflict and earliest repair location. When no repair is needed, identify the concrete parent decisions exercised unchanged and how this event tested them. A generic assurance of inspection or an answer without an exact parent cannot establish that negative.
