# 여덟 부가 지나는 시대

[개요](../outline/index.md#010-work--020-periods)

## 정점에서 돌아가 마지막 귀환까지 {#periods}

아래 여덟 부는 시대와 인물의 활동 범위를 찾는 참조 구획이며 실제 공개 편수를 뜻하지 않는다. 사람 정전의 부 번호도 이 표의 시기 범위를 가리킨다. 현행 공개 편성과 편집 예산은 [제작 지시](../../../instructions/001-adaptation.md#provisional-delivery)가 정하며, 사건의 실제 배열과 장면 구획은 treatments와 scripts가 소유한다. 참조 구획을 여러 공개 단위로 나누거나 합쳐도 첫 공개 단위의 고정 경계와 전 생애의 범위는 유지한다.

## 마지막 관과 남은 사람 {#ending}

1821년 5월 5일 죽음과 1840년 12월 15일 귀환은 별개의 끝이다. 8부는 죽음에서 작품을 끝내지 않고 누가 생애를 다시 쓰고 이용했는지까지 다룬다. 마지막 근경에는 앞선 유배와 기록의 장면에서 이미 만난 베르트랑 또는 마르샹을 세운다. 최종 선택은 treatments가 하되 새 익명 관객으로 결말의 무게를 대체하지 않는다. 앵발리드의 1840년 임시 안치와 1861년 완성된 묘는 다르며 후자를 화면에 쓰지 않는다. 마지막 작가 해설도 사실과 창작의 경계를 밝힌다. 군중 수와 유증액처럼 갈리는 수를 확정해 영광의 크기로 삼지 않는다.
