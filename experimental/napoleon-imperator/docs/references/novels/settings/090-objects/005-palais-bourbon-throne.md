# 팔레 부르봉의 황제 옥좌

## 팔레 부르봉의 나폴레옹 옥좌 {#palais-bourbon-throne}

**정의·범위**

1805년 입법원 회기에서 황제가 앉도록 만든 특정 옥좌의 제작자·형상·재료·치수와 몰락 뒤 변경을 정한다. 튈르리의 옥좌와는 다른 물건이다.

**확정 내용**

황제가 입법원 회기에 참석할 때 앉던 옥좌는 팔레 부르봉의 입법원을 위해 만들었다. 호민원 의원이나 입법원 의원의 자리가 아니라 황제의 자리다(재단, 개체 기술). 1805년 베르나르 푸아예가 설계하고 조각가 피코와 가구장이 자코브데말테가 만든 도금 목재 옥좌다. 팔걸이는 사자 머리 키메라이고, 좌석과 등받이는 은실로 정의의 문양을 수놓은 석류색 벨벳이다. 처음에는 월계관 속 "N"과 독수리가 있었는데 몰락 뒤 독수리가 솔방울로 바뀌고 왕관이 더해졌다. 크기는 160×110×82cm이며 지금은 장식 미술관에 있다(재단, 개체 기술).
