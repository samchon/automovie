# 카르보나리

## 나폴레옹기 남부 이탈리아 카르보나리 {#carbonari-napoleonic}

**정의·범위**

이름을 든 정치 집단의 등장 범위·헌법 요구와 기원설의 미결을 찾는다.뮈라의 개인 의지와 동일하게 정의하지 않는다.

**확정 내용**

카르보나리는 남부에 1811년쯤 나폴레옹과 뮈라가 다툴 때 처음 나타나 헌법을 밀었다. 프리메이슨 기원은 "그럴듯하다"로 쓰고, 첫 날짜는 다툼이 있다.

**참조·미결**

Sources: 기존 [Carbonari](https://en.wikipedia.org/wiki/Carbonari)의 단서다. 원 조직 규약·회원 명부를 새로 읽지 않아 출범일과 프리메이슨 기원을 확정하지 않는다.
