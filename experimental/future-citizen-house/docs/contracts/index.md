# 생산별 계약 목록

현재 production-specific contract는 [시민 주택 공간 보존 계약](citizen-house-spatial-requirements.md) 하나다. 다섯 reference는 settings·spaces·materials가 해석하는 추가 질문이다. 재료 초안의 마감·좌표·관찰 결정은 docs/materials의 실제 H2가 소유하며 이 목록은 그 설계를 대신하지 않는다.
