# 생산별 계약 목록

현재 production-specific contract는 [시민 주택 공간 보존 계약](citizen-house-spatial-requirements.md) 하나다. 다섯 reference는 settings·spaces·models·materials가 해석하는 추가 질문이다. 가구의 part 경계와 재료의 마감·좌표·관찰 결정은 각 설계 H2가 소유하며 이 목록은 그 설계를 대신하지 않는다.
