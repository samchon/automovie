납품의 집·실내·대지는 spaces와 spaceSources의 직접 제작 대상이다. 별도 캐릭터·film·photoreal 서비스·외부 다운로드 자산을 추가해 비용이나 구현 범위를 숨기지 않는다. 정확한 제작 형상과 반복 수는 spaces가 결정하고 public engine이 해석할 수 없는 결과는 source의 열린 문제로 남긴다. package 설치와 server 시작은 coordinator 담당이므로 미설치 의존성이나 꺼진 server를 현재 지원 결과로 인정하지 않는다.

모든 설정 의무는 위에 연결한 실제 H2에서 결정한다. 이 account가 방 치수·표면 배치·장치 출력의 두 번째 owner는 아니다. 설정에 없는 실제 사람의 안전성·장치 성능·현재 GPU 결과를 선언의 충족으로 추정하지 않는다. 새 공간과 renderer는 아직 미구현이며 전체 production 승인은 계속 열려 있다.
