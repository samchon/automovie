납품의 집·방·문·계단·외피·대지의 건축 geometry와 건축 모듈 반복은 spaces 설계와 spaceSources 구현 대상이다. 전체 인테리어 중 가구·설비·소품의 재사용 가능한 형상과 part/face 주소는 models, 방별 배치와 물체 반복은 instances, 발광 과정은 systems, 건축·물체 면의 finish 결합은 materials가 결정하고 각각의 source 분기가 구현한다. 이 분담은 [설정 소유 지도](../../settings/001-production.md#settings-coverage-map)와 [표면 분해](../../settings/003-spatial-basis.md#surface-decomposition)를 소비한다. 현재 방 source의 물체는 후속 source review까지 보존하는 임시 경로이지 spaces/spaceSources의 영구 물체 소유권이 아니다. 별도 캐릭터·film·photoreal 서비스·외부 다운로드 자산을 추가하지 않는다. public engine이 해석할 수 없는 결과는 source의 열린 문제로 남기고 package 설치와 server 시작은 coordinator가 맡는다.

모든 설정 의무는 위에 연결한 실제 H2에서 결정한다. 이 account가 방 치수·물체 배치·장치 출력의 두 번째 owner는 아니다. 건축 source와 WebGL2 viewer는 구현되어 독립 판정의 관찰에 사용됐지만 후속 물체 이관·재료 구현·전체 관찰은 완료되지 않았다. 새 트리의 GPU 결과, 실제 사람의 안전성, 장치 성능은 이 선언만으로 검증되지 않으며 전체 production 승인은 열려 있다.
