기존 settings는 납품·가족·공간 기준의 세 역할을 가졌지만 실제 그림을 재현할 장치, 초기 상태와 operator 접근이 미정이었다. 현재 네 파일은 기존 생활 가구와 두 층의 그래프를 보존한 채 이 결손을 채운다. 001의 제작·표현 수준·권한은 집 전체에 영향을 주므로 독립 수정 단위로 분리했고, 002의 추가 주체와 검사 조건은 구체 상태·사용 가정을 소유한다. 003은 방 경계 좌표를 복사하지 않고 설계 owner를 링크하며, 004는 구조 계측과 frame의 차이를 실제 관찰 조건으로 만든다.

이 account는 settings의 선언 배분만 답한다. 창호·가구·source·뷰어·GPU의 현재 실현이나 최종 외관을 승인하지 않는다. Evidence fingerprint는 인용 대상의 변경만 드러내므로 host의 review 문장은 현재 원문을 다시 읽어 독립적으로 판정해야 한다. 과거 review 선언만으로 재승인을 추정하지 않는다.
