Reference

The reference is for whoever writes against AutoMovie’s packages: a developer extending them, or the coding agent of a production. It states the commands, the configuration, the formats and the APIs. The guide explains what a production is and how a film is made with one.

The API documents , generated by TypeDoc from every library package’s source, lists each export with its type and documentation; these pages say how the parts fit together, and each package’s README lists its entry points.
