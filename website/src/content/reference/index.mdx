# Reference

The reference is for whoever writes against AutoMovie's packages: a developer extending them, or the coding agent of a production. It states the commands, the configuration, the formats and the APIs. The [guide](/docs) explains what a production is and how a film is made with one.

The packages' own types and JSDoc are the final word on each API, and each package's README lists its entry points; these pages say how the parts fit together.

| Page | Holds |
| --- | --- |
| [Packages](/reference/packages) | What each package owns and the boundaries between them |
| [CLI](/reference/cli) | The `automovie` command: create, add, capture, inspect, render and review |
| [Evidence configuration](/reference/evidence) | `evidence.config.ts`, the answer formats, exclusions, diagnostics and exit codes |
| [Composing actions](/reference/motion/composing) | One person's chain, the operators, cues, several people and refusals |
| [Objects and archetypes](/reference/motion/objects) | Affordances, `HumanObject`, archetypes, articulations and rides |
| [Layers](/reference/motion/layers) | Breath, gaze and affect over an action, and their windows |
| [Extending the vocabulary](/reference/motion/extending) | Rows, data-table entries and laws, and what each owes |
