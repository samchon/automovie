# Motion as code

The cast, sets, performance, staging and camera of a production are TypeScript the agent writes against typed packages. A person's performance is composed from the action vocabulary of `@automovie/motions`. A motion is therefore a module: tested once, accepted on stills, and reused by any scene and any body.

## Actions are laws

An action, such as walk, approach, look, gesture, sit, pick up, punch or guard, is a law that brings the hands, feet and body onto their targets. It is scaled to the body that performs it, so one composition fits people of different stature and proportion. An action can be interrupted mid-motion, and the performance refuses an interruption the action does not allow.

Each action's JSDoc names its source in the motor-control, gait or sports literature and marks the values that are provisional. [Motions](/motions/) shows every family of the vocabulary performed.

## A body

A person's body comes from `@automovie/human`: a canonical skeleton and a contact profile with the mass and contact shapes of each segment, generated by code from typed parameters. `createHumanBody` derives the body the motion laws perform with:

```ts
import { AutoMovieHumanCanonicalBody, type IAutoMovieHumanParameters } from "@automovie/human";
import { createHumanBody } from "@automovie/motions";

declare const parameters: IAutoMovieHumanParameters;

const prepared = AutoMovieHumanCanonicalBody.prepare(parameters, { mass: 72, id: "a" });
const body = createHumanBody(prepared.skeleton, prepared.profile);
```

`@automovie/render` draws the same prepared body as the polygon man, plain rigid primitives over its joints.

## A performance

`HumanPerformance` places a composition on the film clock and samples it:

```ts
import { HumanChain, HumanPerformance } from "@automovie/motions";

const performance = new HumanPerformance({
  seed: "scene-12",
  performers: [
    { subject: "a", body, at: { x: 0, y: 0, z: 0 }, yaw: 0, proficiency: { level: "trained" } },
  ],
  composition: HumanChain.subject("a").walk({ to: { x: 0, y: 0, z: 4 } }).stand({ seconds: 2 }).node,
});

const pose = performance.pose("a", 1.5);
```

Positions are world metres on the floor, and `yaw` is degrees about +Y with 0 facing +Z. Besides `pose`, a performance gives `posture`, `bones`, `prop`, `segments` and `aim` at any second. The input also takes props, cue tracks of speech and music, layers and registered laws, which the next pages describe.

## The same frames every time

Poses depend only on the composition, the seed and the bodies. Nothing is regenerated: a defect is found on a still, corrected at its cause in the module and recomputed, and the correction is judged at the same second and camera.

These inputs vary a take without changing what is done:

| Input | Changes |
| --- | --- |
| `seed` | When each step falls and how far each arm swings |
| `proficiency` | Timing, path and balance, at `novice`, `amateur`, `trained` or `elite`, without widening any joint's range |
| `body` | The scale and proportion the same chain is performed at |

A refusal never depends on the seed, so a composition that plans under one seed plans under every seed. [Scenes](/scenes/) shows each scene replayed with other seeds, bodies and proficiency.

## Verifying a performance

A composition that plans can still perform badly. A scene is checked on three things before it is accepted:

1. `HumanVerdicts.of(performance)` reads every physical bound that holds for human motion, such as a hand passing into the body, a foot skating or a joint leaving its range, and places each finding on the performer and the action. Only a clean report is accepted.
2. `HumanSignature` reads what human-movement studies measure, such as the trunk's inclination, a joint's flexion, the centre of mass and the cadence, for a unit test to assert.
3. Stills of the performance show a pose that reads wrongly, which numbers do not.

```ts
import { HumanSignature, HumanVerdicts } from "@automovie/motions";

const report = HumanVerdicts.of(performance);
if (!report.clean) throw new Error(HumanVerdicts.describe(report));

const reader = HumanSignature.of(performance, "a", body, 0);
const lean = HumanSignature.trunk(reader, 1.5) - HumanSignature.trunk(reader, 0);
```

## From module to scene

A production accepts each entity and reusable motion module in a catalog case before any scene composes it. A case isolates one module with its target, partner response and outcome, and the catalog film, `src/composition/films/catalog.ts`, gives it a labeled interval and replays every case after a repair. Accepted cases are recorded in `docs/acceptance/catalog.md`.

A scene then only composes accepted modules. A defect the scene shows is fixed in the module and its case, never patched in the scene. Each scene composition cites the screenplay sections and beats it realizes, as [Writing scenes](/docs/screenplay/writing-scenes) shows.

[Composing actions](/reference/motion/composing) describes the composition grammar.
