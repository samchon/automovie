Pieces that compose

  • 59 actions
  • 358 named rows in 26 families

  • One body, any person

A person's performance is a chain of these pieces; a scene is several chains at once, with objects placed among them. The guide shows how.

How a film is made

  1. Brief You tell your agent what to make; it records the fixed conditions and your decisions.
  2. Screenplay The agent writes what the audience sees and hears, beat by beat, naming each action as one the vocabulary performs.
  3. Staging and motion as code It composes each person's performance from these pieces, places sets and objects, and frames the camera.
  4. The hint video AutoMovie computes the same frames every time, with pose, depth and outline passes, for a video model or a direct render.

Start

npx automovie create <directory>
cd <directory>
pnpm install

Open the directory in your coding agent and tell it what to make. Getting started says more.
